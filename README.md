# 每日日报合集 (Daily Reports Hub)

MIT 开源、公开仓库。汇总三类每日 / 周期性产出：

| 目录 | 内容 |
|------|------|
| `工具小程序/` | 微信工具类小程序对标巡检：锁定新冒头工具小程序，判断是否个人 / 小团队在做，记录功能、收入口径与可信度 |
| `AI热点日报/` | AI 资讯 + 热点梗 + 小而美产品 三段式每日简报 |
| `产品拆解/` | 高变现 / 高增长的工具类产品拆解（功能结构、变现路径、可复制点） |

## 数据分级约定
- **A** = 多家权威媒体交叉佐证
- **B** = 单一媒体 / 行业报告
- **C** = 开发者自述 / 营销文（仅方向参考，禁止当事实引用）

所有收入数字均标注来源与「推算 / C 级」，不臆造。
