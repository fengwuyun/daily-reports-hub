## 产品一：Town（Townie）

### 1. 产品名称 & 一句话定位
**Town** —— 给每个员工配一个「Townie」（自带 @town.com 邮箱的 AI 工作助理），连接邮箱/日历/Slack/WhatsApp/文档，学会你的工作方式后主动干活、并能在员工之间互相协作。**一句话：企业级「互联个人工作助理」SaaS。**

### 2. 产品定位与目标用户
| 项 | 内容 | 来源 |
|---|---|---|
| 目标用户 | 知识工作者 / 专业团队（尤其财务、会计、法务等高频跨系统协作岗位）；团队版面向需要共享工作流的中小企业到企业 | TechBeat 2026-10-19、Gokhshtein 2026-10-20 |
| 解决痛点 | 工作上下文散落在邮件、日历、IM、文档里，每次都要从零开始；重复性准备（会议、收件箱、跟进）耗时 | eesel.ai、The Rundown 2026-10-16 |
| 核心交互 | 每个用户一个 Townie，跨账户搜索/推理；「Routines」一次性配置的周期任务（类 Zapier 自然语言自动化） | eesel.ai 定价页、The Rundown |
| 差异点 | Townie 之间可互相通信、与顾客通信；新增「Shared Workflow」自动把业务信息推送给相关 Townie，替代人工同步 | TechBeat、Gokhshtein |

### 3. 核心价值主张（凭什么付费/留存）
- **持久上下文（Persistent Context）**：不是每次空 prompt，而是携带你的指令、偏好、历史工作，越用越懂你。
- **互联 Agent 协作**：Townie 互相协调、对接外部客户，**把孤立助理变成组织内协作网络**，价值和切换成本随使用加深。
- **强制连接门槛=付费墙**：不连邮箱/日历就不能用——这一步流失约 30% 用户，但换来了 **>15% 的试用付费率**（来源：腾讯新闻 2026-10-21 引用 Greze 表述）。「先知道你是谁、每天怎么工作，才能主动建议我能替你做什么」。
- **创始人信用**：CEO Jean-Denis Greze 为前 Plaid CTO，Tony Vincent 来自 Google，金融/系统接入可信度强（来源：TechBeat、腾讯新闻）。

### 4. 盈利与营收模式
**模式：按席位订阅 + credits 用量额度（额度用尽按 credit 超额计费）。** 价格来自 Town 定价页（eesel.ai 2026-10-06 核对）：

| 套餐 | 月付 | 年付（月均） | 额度/月 | 关键权益 |
|---|---|---|---|---|
| Free | $0 | $0 | 30 条聊天 | 周报、全集成、7 天 Pro 试用 |
| Starter（个人） | $15 | 仅月付 | 1,250 credits | 日简报、Auto-inbox、2 个自定义 routines |
| Pro（个人） | $59 | $49 | 5,000 credits | 无限 routines、全触发器、自动会议简报 |
| Power（个人） | $119 | $99 | 12,000 credits | 优先模型路由、更高并发 routines |
| Power Plus（个人） | $239 | $199 | 40,000 credits | 抢先体验、2 工作日 SLA 邮件支持 |
| Team | $71/席 | $59/席 | 6,000/席（共享池） | 共享空间、共享 routines/skills、团队管理、10 个邮箱 |
| Team Plus | $179/席 | $149/席 | 18,000/席（共享池） | 优先模型路由回归 |
| Enterprise | 定制 | 年承诺 | 按用量 | 无限席位、专属 Slack、自定义数据留存/驻地、安全评审+定制 MSA |

- **单位经济**：credit 超额单价约 $0.032–$0.044/credit（套餐越贵单价越低）；credits 消耗按「助理干活、聊天、工作流运行」计，但**不公开单动作精确扣点**（eesel.ai 指出这是「meter 不透明」风险）。
- **收入结构**：个人订阅（低价获客）+ 团队/企业席位（高客单、共享池绑定）+ Enterprise 定制（高毛利、长合同）。年付省 20% 诱导预付费。
- **已披露营收**：上线数周后即「数百万美元 ARR」；总融资 ≥$160M（$55M A 轮 a16z 领投 2026-06 + $108M B 轮）。**具体估值/营收/客户总数未披露（不确定）。**

### 5. 关键成本结构与资源
| 成本项 | 说明 |
|---|---|
| 模型推理 | 多模型路由（连 Gmail/日历/Slack 等需大量调用 LLM），优先路由到不同模型，推理成本为核心变动成本 |
| 系统接入/合规 | 深度连接企业邮箱、日历、文档、IM，需处理权限、数据留存、企业安全评审（Enterprise 含定制 MSA） |
| 人力 | 工程+研究为主；创始人带过基础设施团队，扩张偏研发 |
| 渠道/合规 | 企业销售 + GTM；金融/会计场景对合规、数据驻地与审计要求高 |

### 6. 获客与增长策略
- **低价/免费入口获客**：Free + $15 Starter 降低尝试门槛，靠「连接即付费墙」自然筛选高意愿用户。
- **口碑 + DAU 自然增长**：早期用户「每天离不开收件箱管理」式强留存（eesel.ai 引用 X 用户原话）。
- **团队版裂变**：共享工作流让一个员工的 Townie 价值外溢到同事，天然推动团队采购（席位扩张）。
- **融资驱动品牌**：Plaid CTO 出身 + a16z/Forerunner/Menlo 背书，媒体与人才吸引力强。
- **冷启动逻辑**：先攻「工作场景信任门槛低于生活场景、付费意愿高」的财务/会计团队（腾讯新闻）。

### 7. 竞争壁垒
| 壁垒类型 | 说明 |
|---|---|
| 网络效应 | Townie 互联、团队共享工作流，用户越多协作价值越大 |
| 切换成本 | 深度接入邮箱/日历/文档，且持续积累个人工作上下文，迁移成本高 |
| 数据/上下文 | 持久上下文+品牌记忆，越用越懂用户 |
| 创始人/资本 | Plaid CTO 信用 + 顶级 VC，形成人才与品牌壁垒 |
| 短板 | 企业 AI 助理赛道拥挤（Lindy、Microsoft Copilot、Reclaim、Motion）；credit meter 不透明是信任隐患 |

### 8. 可复刻该模式的关键步骤与所需条件
**可落地步骤清单：**
1. 选一个垂直工作场景（如「销售助理」「财务助理」「短剧投手助理」）而非泛化，降低冷启动难度。
2. 用 OAuth 接入 2–3 个高频系统（邮箱/日历/IM 或业务系统），先做「主动简报 + 周期 routines」。
3. 设计「连接即付费墙」：免费额度仅限基础聊天，连系统后才解锁核心价值 → 提升付费率。
4. credits 用量计费 + 分层订阅（Free/Pro/Team），年付折扣锁预付费。
5. 先做「单人助理」跑通留存，再加「共享工作流」触发团队席位扩张。

**必备资源/门槛：**
- ✅ **低成本可起步**：单人助理 MVP（接入 Gmail/日历 + 定时简报）用现成 LLM API 即可，1–2 人能跑。
- ⚠️ **门槛中**：多系统稳定接入、权限与数据安全管理、credit 计量体系。
- ❌ **门槛高**：达到「互联 Agent 网络效应」所需规模、企业级合规（MSA/数据驻地）、顶级品牌与资本背书——这是 Town 真正难抄的部分。

## 产品二：Melius

### 1. 产品名称 & 一句话定位
**Melius** —— 面向广告/创意团队的「Agents Lab for Creative Work」：在一个节点画布上协调多个 AI 模型，把「创意简报 → 成片/成图/成音频」全流程自动化。**一句话：模型之上的 AI 创意生产编排平台。**

### 2. 产品定位与目标用户
| 项 | 内容 | 来源 |
|---|---|---|
| 目标用户 | 广告代理商、品牌方、市场/增长团队、电商、导演/独立创作者 | DevCuration、GPTFrance |
| 解决痛点 | 单点生图/生视频工具割裂，专业团队要在多个 prompt 框、编辑器、素材库之间来回搬上下文；品牌一致性、复用、审批难 | DevCuration 2026-10-06 |
| 前身与 pivβ | 创始团队先做「AI 广告投放优化」，6 个月后认定空间不足，**删掉整个代码库重做**为创意生产；2026-07 出 stealth | FounderMag、VentureCapitalTracker、TechCrunch |
| 当前形态 | 共享节点画布，Agent 规划并执行创意工作流，用户保留对每一步的可见与控制 | DevCuration |

### 3. 核心价值主张
- **编排层而非模型层**：不押注自研最好模型，而是把 117+ 模型（Recraft、Qwen Image、FLUX、GPT Image、Seedance、Kling 等）统一在一个工作台，按任务路由最优/最省模型。
- **品牌记忆 + 资产复用**：Agentic Asset Manager 让 Agent 自动找/组织/复用素材；即将上线 Elements 层保存品牌资产/产品参考。
- **可审计创意流程**：节点画布让 Agent 指令可见可改、每次生成前显示 credit 成本，降低「黑箱」焦虑。
- **可被其他 Agent 调用**：提供 MCP / API / CLI，成为别人工作流里的一环（生态嵌入）。
- **速度验证**：出 stealth 3 个月内破七位数 ARR、数千团队使用（公司口径，未独立验证）。

### 4. 盈利与营收模式
**模式：credits 订阅（按生成量计费），分层 + 团队共享池 + 企业定制。** 价格来自 GPTFrance 定价页（美元，年付月均 / 月付）：

| 套餐 | 月付 | 年付月均 | 额度/月 | 适用 |
|---|---|---|---|---|
| Free | $0 | $0 | 有限试用 | 体验 |
| Creator | $20 | $17 | 20,000 credits（≈300 图或 14 视频） | 个人创作者，全模型、无限用 Agent、自定义语音导入 |
| Growth | $50 | $43 | 50,000 credits（≈745 图或 35 视频） | 最多 3 个 Agent 技能 |
| Professional | $110 | $93 | 110,000 credits（可扩到 300,000） | 最多 10 技能、Slack Agent、AI 搜索 |
| Team | $70/席 | $56/席 | 70,000/席（共享池，最少 2 席） | 团队协作 |
| Enterprise | 定制 | 年承诺 | 定制 + 优先队列 | 大客户 |

- **收入结构**：个人/小团队订阅（高频低客单）+ 团队共享池（中客单、席位扩张）+ Enterprise（高客单、定制）。
- **credit 计量**：每模型按复杂度/算力消耗不同；余额与历史在团队设置可查；可单独买 credit 包不升套餐。
- **融资与营收**：2026-10-06 披露 $25M 总融资（$5M seed 由 General Catalyst 领投 + $20M Series A 由 CRV 领投）；天使含 Vercel CEO Guillermo Rauch 等；**估值未披露（不确定）**；ARR 为公司自报「七位数运行率 / 两个月内破 $1M」，未经第三方核实（不确定）。合作方列举 Doors.com、Slash、SkinnyDipped、Shown Media。

### 5. 关键成本结构与资源
| 成本项 | 说明 |
|---|---|
| 模型推理（最大变动成本） | 调用 117+ 第三方模型（图像/视频/音频），按算力计费；credit 定价需覆盖且留毛利 |
| 工程/研发 | 16 人团队（纽约 Chelsea），节点画布、Agent 框架、MCP/API/CLI |
| 素材/算力基础设施 | 视频生成算力贵，是成本与定价关键约束 |
| 增长/销售 | $25M 明确用于招聘、GTM 扩张、Agents Lab 研发 |

### 6. 获客与增长策略
- **产品重置叙事**：「6 个月推倒重来」故事强化创始人适应力，利于融资与媒体。
- **模型广度获客**：117 个模型一站式接入，用户不必多处订阅，直接转化多工具用户。
- **节点画布演示效应**：单画布跑通「篮球鞋 campaign」等多模型协作案例，强视觉传播。
- **生态嵌入**：MCP/API/CLI 让 Melius 成为其他 Agent 的创意执行层，借生态获客。
- **天使/KOL 背书**：Vercel CEO 等天使带来开发者与创意圈信任。

### 7. 竞争壁垒
| 壁垒 | 说明 |
|---|---|
| 编排/工作流 | 创意全流程节点画布 + 审批历史，比单点生成工具嵌入更深 |
| 品牌记忆/资产复用 | Elements（即将）沉淀品牌资产，复用形成切换成本 |
| 模型无关 | 可路由最优/最省模型，不被单模型绑定 |
| 协作面 | 资产管理/审批/复用从个人创作扩到组织级系统记录 |
| 短板（Bear） | 模型能力趋同 → 价值向软件层迁移的同时，也面临 Adobe/Canva 捆绑 Agent 功能、Higgsfield/Krea/Flora 等同赛道 feature compression；先发优势未稳 |

### 8. 可复刻该模式的关键步骤与所需条件
**可落地步骤清单（对短剧素材生产尤其可借鉴）：**
1. 不训练模型，先做一个「多模型统一接入层」，把主流生图/生视频/配音 API 聚到一个调用层。
2. 用「节点/画布」或「脚本 → 多镜头视频」工作流包装，让用户用自然语言描述创意简报。
3. credits 计费：按模型实际算力消耗折算额度，分层订阅 + 团队共享池。
4. 加「品牌/角色资产库」：把短剧角色、场景、画风做成可复用 reference，解决跨镜头一致性（短剧刚需）。
5. 暴露 MCP/API，让别人能把你的创意生成接进自己的投放/剪辑流程。

**必备资源/门槛：**
- ✅ **低成本可起步**：用现有模型 API + 一个统一管理/计费前端，1–2 人可做 MVP（这正是 Melius 早期形态）。
- ⚠️ **门槛中**：多模型稳定接入与成本对账、credit 计量、节点画布 UX。
- ❌ **门槛高**：117 模型商务接入、品牌记忆层、企业级协同/审批、对抗 Adobe/Canva 的渠道与资本——这些决定能否从工具升级为「系统记录层」。

## OPC 视角可行动建议（给 Oscar）
1. **Town 的「强制连接付费墙」值得抄**：任何助理类产品，把「接入你的真实工作/业务系统」设为解锁核心价值的开关，能显著抬高付费率（>15%）。可平移到「短剧投手助理」——要求连投放后台/数仓才解锁智能诊断。
2. **Melius 的「模型之上编排层」正是短剧素材痛点**：短剧需要跨镜头角色/画风一致，现有单点生图工具解决不了。做「短剧创意 Agent 编排」（角色库 + 分镜脚本 → 多模型成片 + 一致性校验）是低门槛、强需求、且与 Oscar 业务强相关的可切入方向。
3. **两者共同启示**：当底层模型商品化，**真正的钱在「上下文/工作流/品牌记忆」这一层**。OPC 选方向时，优先找「模型之上、用户资产沉淀其中」的位置，而非再做一个通用生成器。
