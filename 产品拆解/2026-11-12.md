## 今日精选理由

选 **Sand.ai（三呆科技）/ VidMuse** 与 **Mercor** 两个产品，均落在最近 7–30 天窗口内（Sand.ai 11-05 完成 2 亿美元 A+ 轮、Mercor 11-10 宣布 7.5 亿美元 D 轮），且商业模式清晰、对照性强：

两者一"产品订阅"、一"市场抽成"，拆解后可直接对照 Oscar 在海外短剧素材、数据产品、Agent 化三条线上的可复刻路径。已避开此前约 60 个已拆产品。

## 关键结论速览

1. **Sand.ai**：用"开源模型（MAGI-2，114B MoE）+ 低成本推理（0.5 元/10 秒 1080p）+ 创作者订阅产品（VidMuse Pro $39/月）"跑通"基础模型→应用→收入"闭环；两月 ARR 破千万美元是**年化流水口径**，实际 H1 营收仅 1739 万元、净亏 1.52 亿元（网宿公告，未审计）。估值买的是"成本曲线 + 一个能收订阅的产品"，不是利润表。护城河弱（模型开源、算力外包给网宿、产品体验领先仅数月），可复刻性强：**垂直场景视频生成工作台 + 聚合多模型**是低成本起步范本。
2. **Mercor**：从 AI 招聘平台长成"专家数据 / 评测 / 后训练"市场，估值两年从 2.5 亿美元飙到 200 亿美元；"20 亿 ARR"实为**总支付流水（GPV）**，按 30–40% 抽成净收入约 6 亿美元量级（估算，未审计）。强网络效应 + 与大厂（OpenAI/Anthropic/Nvidia）深度绑定构成护城河，但 2026-04 因 LiteLLM 被黑导致 Meta 暂停合作，安全与合规是暗雷。可复刻性低（市场双边网络 + 大客户信任门槛高），但"把某一领域的专家判断做成评测/训练数据资产"的思路对 Oscar 打包短剧领域知识成智能体产品有直接借鉴。

# 产品一：Sand.ai（三呆科技）/ VidMuse

## 1. 产品名称 & 一句话定位
**Sand.ai（北京三呆科技）** —— 做视频生成基础模型 + 创作者应用的公司；旗下 **VidMuse** 主打"给一段音乐，生成匹配节奏/情绪/画面的视频"（Music in, Video out）。

## 2. 产品定位与目标用户
| 项 | 内容 |
|---|---|
| 自研模型 | MAGI 系列（MAGI-1 自回归、MAGI-2 Preview 114B 超细粒度 MoE、单次仅激活 6B 参数），2026-08 开源 MAGI-2 Preview |
| 应用产品 | VidMuse（2026-01 上线），切入口为音乐视频，已扩展到商品广告、叙事短片、动画；服务音乐人、个人创作者、品牌、创作工作室 |
| 解决痛点 | 传统视频制作贵（一条 MV/广告要几千到几万美元）、门槛高（要会写提示词）；VidMuse 把"给首歌出片"做成低门槛入口，对"精确可控"要求不高的场景容错空间大 |
| 目标用户 | 短视频团队、电商素材、音乐人、社媒博主——"真的靠视频吃饭的人"（定价瞄准专业而非玩票） |

## 3. 核心价值主张
- **成本代差**：蒸馏版推理成本约 **0.5 元 / 10 秒 1080p**（按 8 卡 H100 月租折算，公司/网宿口径，未独立审计），约为主流模型的 1/10；把"敢不敢反复试不同镜头"的成本从几百降到十几块。
- **音画联合生成**：单一模型同时生成画面+声音+口型同步+运镜，角色表演、情绪切换自然。
- **开源换信任**：放出权重（MAGI-1 / MagiHuman / MAGI-2 Preview），用生态换反馈速度、用透明换开发者信任；图生视频全球第 6（Artificial Analysis，厂商/第三方榜单口径）。

## 4. 盈利与营收模式
| 收费点 | 详情 | 来源/不确定性 |
|---|---|---|
| VidMuse 会员订阅 | Pro 版 **月付 39 美元**；Freemium + 积分充值；比剪映专业版贵、比专业剪辑软件订阅便宜 | 同花顺/36 氪/官网，已确认 |
| 模型 API / 推理 | 自有 MAGI 系列 + 同时接入可灵、Seedance、Veo 等第三方模型，用户在同流程里混用 | 官网 + 报道；"聚合器 vs 自研不够好"两说并存 |
| ARR 里程碑 | 公司称 VidMuse 上线两月 **ARR 破千万美元**（年化流水口径，非确认收入） | 公司声明；属 run-rate，与 H1 实际营收落差大 |
| 实际财务 | 网宿公告（未审计）：2026 H1 营收 **1739.8 万元**、净亏 **约 1.52 亿元** | 网宿投资公告；年化营收约 3500 万、亏损约 3 亿，烧钱换规模特征明显 |
| 融资 | 2026-11-05 宣布 **2 亿美元 A+ 轮**（基石资本、网宿科技联合领投），10 个月 3 轮累计 **3 亿美元**，独角兽（>10 亿美元）；老股东源码/经纬/华业天成/中科创星等加注 | 同花顺/财联社/网易，已确认 |

## 5. 关键成本结构与资源
- **算力/推理**：最大成本项（算力、存储、审核、版权）。本轮领投方**网宿科技**同时是基础设施伙伴——先可转债（3 亿元）+ 认股权证，再转股权；业务上由网宿出算力/边缘节点/调度/安全，Sand.ai 新模型"优先通过网宿平台部署"。代价：推理成本与上线节奏部分交予他人，**议价空间让渡**。
- **研发**：MAGI 系列训练 + MoE 架构/系统/数据协同设计；创始团队为清华系（曹越，Swin Transformer 一作、ICCV 2021 Marr 奖，前 MSRA/智源/光年之外联创）。
- **内容与版权审核**：低价获客后，真实利润在审核、版权、企业服务而非 C 端调用。

## 6. 获客与增长策略
- **开源作获客漏斗**：放权重 → 开发者心智 + 论文引用 + 生态口碑 → 反哺 VidMuse 与 API 调用。
- **低门槛场景切入**：音乐视频是最易上手、容错高的入口，不需要会写提示词。
- **产品感驱动**：VidMuse 由前剪映 PC 端产品负责人主导，强调"把模糊创意变成可用成片"的流程设计。
- **融资驱动规模**：10 个月 3 轮、3 亿美元，靠资本支撑烧钱换增长。

## 7. 竞争壁垒
| 壁垒 | 说明 | 强弱 |
|---|---|---|
| 成本曲线 | 约 1/10 推理成本，是客户切换供应商的最短路径 | 中（0.5 元是生存底线非利润壁垒，巨头可补贴碾压） |
| 开源/中立 | 在 Kling/Seedance/Veo/Sora 全闭源下，少数放权重的前沿厂商；企业自托管合规场景有稀缺性 | 中（权重放出≠生态自动成型） |
| 架构差异化 | 唯一主推自回归视频生成，利于长视频/交互式/无限延展 | 中（效果尚未全面追平头部） |
| 软肋 | 模型、算力、部分产品独特性都"让出去了"；与可灵（账上 ~198 亿）、Seedance（字节分发）、Vidu（阿里）不在同一资本/分发量级 | 高（真实约束） |

## 8. 可复刻该模式的关键步骤与门槛
| 步骤 | 动作 | 门槛 |
|---|---|---|
| 低成本起步 | **垂直场景视频生成工作台**：选定一个具体切口（如"音乐→短视频""商品广告"），聚合多家视频模型 API，做最好用的流程而非最强模型 | 低：API 聚合 + 工作流 UI，1–2 人可做 |
| 差异化 | 把"模糊创意→可用成片"的流程做顺，支持多模型混剪、改镜头、导出 | 低–中 |
| 定价 | 会员订阅 + 积分充值（参考 Pro $39/月档位），用低价换试用 | 低 |
| 进阶 | 自研/微调垂直模型压成本（如 MoE 蒸馏），或绑一个算力伙伴降推理价 | 高（训练 + 算力资本） |
| 护城河补强 | 企业服务、行业方案、合规/版权/工作流增值，而非靠 C 端按秒卖 | 中–高 |

> **Oscar 可行动点**：海外短剧素材生产正好是"音乐/脚本→片段"的场景，可先做一个"聚合多视频模型 + 分镜工作流"的轻量工具，按订阅或按条收费，验证真实付费意愿后再考虑自研模型。Sand.ai 证明"聚合器 + 低门槛入口"比"自研最强模型"更容易先收钱。

# 产品二：Mercor

## 1. 产品名称 & 一句话定位
**Mercor** —— 把"人类专家知识"组织成 AI 经济基础设施的公司：一端连接 ~500 万领域专家（医生、律师、工程师、顾问），另一端卖给前沿模型厂与大型企业，做**训练数据、模型评测、后训练**。

## 2. 产品定位与目标用户
| 项 | 内容 |
|---|---|
| 起源 | 2023-01 成立，原是 AI 招聘/人才市场；现长成"专家数据 + 评测 + 后训练"市场 |
| 核心交付 | ① 专家生成的训练/标注数据；② 定制评测（evals）；③ 基于企业真实工作流的后训练；④ 专家人力外包 |
| 目标用户 | 前沿模型厂（OpenAI、Anthropic、Nvidia 等，为其 Nemotron 供数据）、大型企业（想把自有工作流训成专属 Agent） |
| 解决痛点 | 模型"知道怎么普遍做一件事"但"不知道某家公司按什么系统/政策/质量标准做"；公开基准高分≠生产可用 |

## 3. 核心价值主张
- **专家网络规模**：声称 **500 万+ 专家**在网、覆盖 300+ 专业领域、800+ 美国职业；专家时薪约 $63–120（平均 >$95）。
- **评测即资产**：APEX 基准家族（APEX-Agents / -Accounting / -SWE），联合 Harvey 等发布开源法律/会计/软件工程基准，衡量模型能否做"有经济价值的工作"。
- **训练环境**：2026-07 收购 **Deeptune**（重建数百个企业应用的 RL 环境，让 Agent 在仿真里练真实流程），补齐"在哪练"一环。
- **企业玩法**：起点用开源模型 → 建公开评测 → 后训练降本 → 为客户训专属模型（所需资源仅为前沿厂零头）。

## 4. 盈利与营收模式
| 收费点 | 详情 | 来源/不确定性 |
|---|---|---|
| 市场抽成 | 双边市场 + 服务：专家按小时计费，公司抽成约 **30–40%**（专家拿走 60–70%） | The Next Web 引 The Information；抽成比为估算，未审计 |
| "ARR" 口径 | 公司称年化收入 **20 亿美元**（2026-06），但这是**总支付流水 GPV** 而非净收入；按 30–40% 净收入约 **6 亿美元**量级（估算） | 多处冲突：GPV≠SaaS 净收入， headlines 常混用；未审计 |
| 增长曲线 | 年化 GPV：2025-02 约 $75M → 2026 初 $1B → 2026-06 $2B（16 个月约 26 倍） | Sacra/公司口径，未审计 |
| 盈利 | 有来源称年初 FCF 已盈利（不确定，单一来源） | 不确定 |
| 融资 | 2026-11-10 宣布 **7.5 亿美元 D 轮 @ 200 亿美元**（较 2025-10 的 $10B 翻倍），含员工 tender；投资方 Benchmark/Felicis/General Catalyst/NVIDIA/Salesforce/Zoom/Apollo 系基金等 | 公司声明 + TNW/Unite.AI；terms 多为公司自陈，未见独立核实 |
| 历史轮次 | Series A ~$30M@$250M → 2025-02 B $100M@$2B → 2025-10 C $350M@$10B → 2026-11 D $750M@$20B | 已确认轨迹 |

## 5. 关键成本结构与资源
- **专家报酬**：最大流出项，GPV 的 60–70% 直接付给承包商；日支付额声称 >$400 万（后期口径，未独立核实；2025-10 为 30k+ 承包商、$1.5M/日）。
- **推理成本**：公司称**推理支出已是员工薪资的 3 倍**（模型运行费用），并认为该比例若扩散到全经济将带来近两位数 GDP 增长（属创始人预测，非公司数据支撑）。
- **安全/合规**：2026-04 因 **LiteLLM 开源组件被黑**发生数据泄露，Meta 据此冻结与 Mercor 的 AI 数据合作；此类事件直接动摇大客户信任（市场赢家靠的是信任而非吞吐）。
- **获客资源**：与大厂深度绑定（OpenAI/Anthropic/Nvidia）形成"同一专家网络 + 同一评测方法"双向飞轮。

## 6. 获客与增长策略
- **从招聘到数据市场的身份切换**：先用 AI 视频面试（约 20 分钟，含案例评估）以远超人力的规模筛专家，建立低成本获客机器。
- **前沿厂 → 企业外溢**：先服务预算充足、需求明确的前沿模型厂，沉淀评测/后训练能力后，向"想拥有自己智能"的大企业售卖同款。
- **开源基准作 top-of-funnel**：发布 APEX 等公开基准，既建立行业话语权，又作为企业获客入口。
- **并购补能力**：收购 Deeptune 补齐训练环境，快速扩展可覆盖行业。

## 7. 竞争壁垒
| 壁垒 | 说明 | 强弱 |
|---|---|---|
| 网络效应（双边） | 专家越多 → 数据/评测越全 → 大厂越依赖 → 更多专家涌入 | 强（Scale AI 之后最头部） |
| 大客户信任 | OpenAI/Anthropic/Nvidia 深度绑定，合同即护城河 | 强，但单点依赖（Meta 因泄露暂停即例证） |
| 基准/评测资产 | APEX 家族 + Harvey 等联名基准，定义"什么叫做好了" | 中–强 |
| 软肋 | 安全事件（LiteLLM 被黑）、GPV 与净收入口径混淆、劳工/合规定性（是否构成雇主责任）、对少数大厂营收依赖 | 高（真实约束） |
| 竞品 | Scale AI（Meta 49% 持股）、Surge AI、Turing、Invisible、Micro1 | — |

## 8. 可复刻该模式的关键步骤与门槛
| 步骤 | 动作 | 门槛 |
|---|---|---|
| 低成本起步 | **垂直领域"专家评测/数据"小市场**：选一个你真懂的领域（如海外短剧投放、某类金融合规），把该领域的"什么算做好"做成可复用评测集/数据集出售或用于自训 Agent | 低–中：需真实领域专家资源 + 评测设计能力 |
| 差异化 | 不做通用标注，做"按客户真实工作流定制 evals + 后训练"的高价值服务 | 中 |
| 规模化 | 建专家网络 + AI 筛面试机器，复制 Mercor 的低成本获客 | 高（网络 + 资本 + 大客户信任） |
| 护城河补强 | 绑定 1–2 个大客户/模型厂，用信任而非吞吐取胜 | 高 |

> **Oscar 可行动点**：Mercor 的精髓不是"做大市场"，而是"把某一领域的专家判断产品化"。Oscar 手上的海外短剧投放/归因领域知识，正可做成一套"短剧投放/ROI 评测与后训练数据集 + 领域 Agent"，先以咨询服务或数据产品收第一笔钱，再考虑规模化为"领域版 Mercor"。但直接复制其双边市场形态门槛极高，不建议作为 30 天拿第一笔收入的首选路径。

## 对 Oscar 的借鉴（一句话版）
- **Sand.ai** 教的是：**先做一个"聚合多模型 + 低门槛工作流"的垂类工具收订阅**，比死磕自研最强模型更容易先验证付费——适合海外短剧素材生产场景。
- **Mercor** 教的是：**把你的领域专家知识做成"评测/训练数据资产"**，这是"AI 员工化"里最值钱、也最难被抄的一环；但双边市场形态本身门槛极高，只学其"知识产品化"内核即可。
