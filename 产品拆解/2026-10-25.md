## 一、今日精选理由

今日挑两条 **"Agent 替人干完一整件事"** 的 B2B SaaS，刻意避开 10/16–10/24 已拆的 18 个产品（Instinct/Folk/Hark/Higgsfield/HelppliX/Hone/TypeSafe/Arena/Nous/Zenzap/Manus/Reco/Zeroset/Verso/Town/Melius/doubleAI/Ambi），且两条商业模式都**可抄、能起步**：

二者对照：**一个是"替内容团队反复拍视频的 Agent"，一个是"替运营团队跑流程的 Agent"**，共同揭示 2026 年 Agent 商业化主线——卖"结果/产出"而非"席位/Token"。

## 四、产品一：Clueso

### 1. 产品名称 & 一句话定位
**Clueso** — 面向企业团队的 AI 视频与文档生产平台：AI Agent 操作真实软件、自己录屏拍产品演示视频，并在产品变更时自动重拍，一次采集同时产出"讲解视频 + 分步文档"。

### 2. 产品定位与目标用户
- **解决的问题**：每个 B2B 公司都要做产品演示、教程、发布更新视频，但人工拍摄/剪辑贵且慢，且软件一更新旧教程就失效。
- **目标用户**：营销、销售、支持、L&D（培训）、产品、运营团队；典型客户 Atlassian、Zendesk、Seismic、Ironclad（1000+ 企业）。
- **差异点**：多数 AI 视频工具仍需人先录原始素材，Clueso 的 Agent 直接打开软件、自己操作、边操作边录，产品更新后自动重跑同一工作流刷新视频。

### 3. 核心价值主张
- **一次录制 → 视频 + 文档双产出**，含 AI 配音（付费档 10k+ 嗓音）、自动缩放/标注、字幕、翻译（多语种脚本+新配音）。
- **"自更新"内容**：核心卖点不是生成更快，而是内容随源系统演进持续正确——这是 2026 年企业内容工具的分水岭（同理驱动文档/支持文章自动化）。
- **Clueprints**：品牌与格式一次设定，团队所有视频自动统一；并开放 **Clueso MCP** 与 Agent Skills，可从 ChatGPT/Claude/Cursor 直接创建与管理内容。

### 4. 盈利与营收模式
官方定价页（2026-10-21 复核），四档，**按"导出时长 + AI credits"计费**，年付约省 20%：

| 档位 | 价格（年付） | 核心额度 | 关键能力 |
|---|---|---|---|
| Free | $0/mo | 1 用户；10 分钟视频/月、15 篇文档/月；1080p；1000 credits；带水印 | 评估试用 |
| Solo | $40/mo（月付 $50）| 1 用户；3 小时视频/年、180 篇文档/年；2K；去水印；2500 credits/月 | 个人 |
| Business | $120/mo（月付 $150）| 2 用户；6 小时视频/年、360 篇文档/年；4K；3500 credits/用户/月；协作/分析 | 小团队（最受欢迎）|
| Enterprise | 定制 | 自定义用户/额度/credits；语音克隆、SAML/SSO、白手套 onboarding、SLA | 大客户 |

- **单价换算**：Solo 年付 $480 换 3 小时导出 ≈ **$2.67 / 导出分钟**。
- **收入结构**：以订阅为主（按席位+导出额度），Enterprise 走定制 + 增值（语音克隆、PII 自动模糊、私有部署）。
- 评测侧：G2 4.8/5（128 条），Capterra 有页面但 0 评价（截至复核）。

### 5. 关键成本结构与资源
- **算力/模型**：AI 配音、语音克隆、图像生成、运动图形、翻译均需推理成本；credits 体系把成本转嫁为用户额度，边际成本随用量上升。
- **Agent 运行成本**：导航真实软件、录屏、自动重拍依赖浏览器自动化 + 视觉/操作模型，是技术与成本核心。
- **人力**：客户成功（白手套 onboarding）、内容质量审核。
- **合规**：SOC2 Type II、ISO 27001 全档位，云存储与数据处理合规成本。
- **不确定项**：具体毛利率、模型自研还是外采、单客户服务成本未公开 → 标「不确定」。

### 6. 获客与增长策略
- **免费档引流**：永久 Free 档（带水印、限额）作为 top-of-funnel，转化 Solo/Business。
- **YC 系+老股东加注**：A 轮 80%+ 来自现有股东（YC、f7 Ventures），信号强、成本低。
- **标杆客户背书**：Atlassian/Zendesk 等具名客户用于信任背书。
- **生态嵌入**：Clueso MCP + Agent Skills，借 ChatGPT/Claude/Cursor 的工作流自然获客。
- **品类卡位**：主动做 "Tango 替代品" 对比页，抢搜索与选型流量。

### 7. 竞争壁垒
- **可靠 UI 导航 Agent**：能稳定操作第三方软件、随界面变化重跑，是技术与数据壁垒（依赖大量真实 UI 轨迹）。
- **"自更新"闭环**：内容随产品演进持续正确，比"一次性生成"更难被替代。
- **合规+品牌资产**：SOC2/ISO + Clueprints 模板沉淀，企业切换成本高。
- **生态位**：MCP/Agent Skills 提前嵌入主流 Agent 工作流。
- **软肋**：导出时长按年配额偏紧（Solo 仅 15 分钟/月等效），G2 有用户抱怨限额与需谈折扣 → 价格透明度是弱点。

### 8. 可复刻该模式的关键步骤与所需条件
**可落地步骤清单**
1. 选一个垂直场景（如 SaaS 教程、短剧"幕后制作"短片、跨境电商上架视频），别一上来做通用平台。 【低成本起步】
2. 用浏览器自动化（Playwright）+ 屏幕录制 + LLM 脚本生成 + TTS，搭 MVP：录入操作→出视频+文档。 【低成本起步】
3. 加入"变更检测+自动重跑"：监听目标产品更新或定时重跑工作流，刷新内容。 【低成本起步，但技术门槛渐高】
4. 设计 Free/付费两档，按"导出时长 + credits"计费，先收小额订阅验证付费意愿。 【低成本起步】
5. 沉淀品牌模板（Clueprints 类），让同团队视频风格统一。 【中成本】
6. 拿 2–3 个具名标杆客户做背书，做"XX 替代品"对比页抢选型流量。 【中成本】
7. 企业档上 SOC2/ISO、开放 MCP/Agent Skills 嵌入生态。 【高门槛：认证周期与费用、工程投入】

**必备资源/门槛标记**
- 低成本可起步：开源自动化栈 + 公有云 LLM/TTS API + 单人多场景试水。
- 中门槛：可靠 UI 导航 Agent 的工程化（容错、跨界面适配）、品牌模板体系。
- 高门槛：企业合规认证（SOC2/ISO，数月+数万美元级）、1000+ 客户规模、生态位卡位。

## 五、产品二：Duvo

### 1. 产品名称 & 一句话定位
**Duvo** — "Enterprise Execution OS"（企业执行操作系统）：让企业员工与 AI Agent 共同运行业务流程，成为"企业运营所依赖的唯一平台"；先用 AI 厘清流程真相，再由 Agent 跨现有系统执行，决策与异常交还责任人。

### 2. 产品定位与目标用户
- **解决的问题**：企业后端办公（发票审计、货运审计、供应商奖金对账等）重复、跨系统、易错，传统 RPA/试点难跨过"价值不清"阶段（Gartner 预测 2027 年前 >40% Agent 项目因成本/价值不清被砍）。
- **目标用户**：零售商、CPG（消费品）企业的运营/财务/AP 团队；从美国市场切入（已有欧洲客户）。
- **核心工具**：Duvo Clarity（AI 主导访谈+录屏+文档，先画出流程真实运行机制）。

### 3. 核心价值主张
- **人机协同执行**：Agent 在 ERP、供应商门户、表格、邮箱等既有系统间执行获批步骤，异常转交责任人，不要求企业换系统。
- **从试点到落地**：强调"让 AI 跨过试验阶段"，用证据而非假设决定自动化哪些重复任务。
- **模型中立**：底层可跑不同模型，含专用硬件上的开放权重模型，成本与可控性更优。
- **ROI 证据**：Notino 供应商奖金季度对账 70天→15天、专家工时 120→<10 小时；自称累计为客户释放 >$100M。

### 4. 盈利与营收模式
官方定价页，三档订阅 + 企业三种商业模型，**关键创新是按"完成的流程运行（process run）"计费、且承诺 5x ROI 保证**：

| 档位 | 价格 | 额度 |
|---|---|---|
| Free | $0（终身限额）| 2 次 Clarity 访谈、100 agent runs、1 并发、25 邀请 |
| Pro | $199/mo（年付 $2,149，省 10%）| 5 访谈/月、500 runs/月、20 并发、50 邀请 |
| Business | $699/mo（年付 $7,549）| 12 访谈/月、2,500 runs/月、50 并发、100 邀请、多团队 |
| Enterprise | 定制（年付）| 无限；组织级流程全景、SSO、审计日志、优先支持、驻场工程师 |

- **三种企业商业模型**：① 固定范围（流程发现）；② 固定项目（转型/SAP）；③ **按完成流程运行计费（生产自动化，如"处理一张发票"）**。
- **5x ROI 保证**：协议约定基线、测量方法与窗口；若实测 ROI < 5 倍提案总价，整单免费。把厂商费用与可测量结果绑定。
- **分发**：上架 **Azure Marketplace**，微软企业渠道代售（市场计划为年承诺+超额按次计费）。
- **不确定项**：Capterra 显示 Pro $100/月、Enterprise $10,000/月"其他"口径与官网不一致 → 以官网为准，Capterra 数字标「不确定/可能 stale」；估值未披露 → 标「不确定」。

### 5. 关键成本结构与资源
- **算力/模型**：Agent 运行 + 可能自托管开放权重模型（专用硬件）的推理与基础设施成本。
- **交付成本**：流程发现需访谈/录屏/驻场工程师（forward-deployed engineer），人力密集。
- **合规**：SOC2 Type II、ISO 27001、ISO 42001、GDPR、NIS2 对齐的认证与运维成本。
- **销售**：企业长周期 + Azure Marketplace 抽成。
- **不确定项**：毛利、单流程运行成本未公开 → 标「不确定」。

### 6. 获客与增长策略
- **免费两周试点**：在一个流程上免费跑两周发现（Discovery），作为最低成本切入点。
- **地理+行业聚焦**：A 轮资金用于进军美国，首选最熟悉的零售/CPG，再横向扩展（freight/invoice audit 逻辑不限于零售）。
- **生态嵌入**：Azure Marketplace 借微软企业渠道。
- **标杆+权威背书**：Notino/Morrisons 具名成效、Balderton 投资人发声、引用 Gartner 预测建立信任。
- **创始人光环**：Tomáš Čupr（2014 创立在线杂货 Rohlik）的运营经验与品牌。

### 7. 竞争壁垒
- **流程洞察+执行闭环**：AI 访谈/录屏真正理解企业流程再跨异构系统执行，降低 Agent 项目失败率。
- **合规认证**：SOC2/ISO 42001（AI 管理体系）+ NIS2，满足大企采购门槛。
- **商业风险共担**：按 process run 计费 + 5x ROI 保证，比按 Token/席位更有说服力，且敢对赌。
- **领域经验+驻场模式**：Rohlik 运营基因 + forward-deployed engineer，难被纯自助 SaaS 复制。
- **软肋**：集成深度有限（Capterra 评"复杂用例集成不足"）；复杂 legacy 桌面端 UI 自动化不支持（rightaichoice 指出）。

### 8. 可复刻该模式的关键步骤与所需条件
**可落地步骤清单**
1. 锁定一个高价值、跨系统、重复的后端流程（如跨境电商的发票/物流对账、短剧分账核对），做单场景 MVP。 【低成本起步】
2. 先用"AI 访谈+录屏"画流程地图（Clarity 思路），再让 Agent 在既有系统间执行、异常转人。 【低成本起步】
3. 定价按"完成的流程运行次数"而非席位/Token，并设置可测量的 ROI 基线。 【低成本起步】
4. 提供免费小范围试点（如一个流程两周）作为获客钩子。 【低成本起步】
5. 上架云市场（Azure/AWS Marketplace）借企业渠道分发。 【中成本】
6. 拿具名客户 ROI 数据做背书，逐步扩展流程与行业。 【中成本】
7. 做 SOC2/ISO 42001 认证、驻场交付团队、敢签 ROI 对赌。 【高门槛：认证、销售周期、商业风险承担能力】

**必备资源/门槛标记**
- 低成本可起步：单流程 Agent + 人类审核闭环 + 按结果计费的小生意，个人/小团队可做。
- 中门槛：云市场入驻、标杆客户获取、跨系统集成工程。
- 高门槛：企业合规认证、驻场交付组织、5x ROI 对赌所需的资金与风控能力。

## 六、今日交叉观察（OPC 视角）

1. **Agent 变现主线收敛到"卖结果"**：Clueso 卖"导出的分钟数/credits"，Duvo 卖"完成的流程运行"——都在把价值锚定到**交付物**而非席位或 Token。对 Oscar 的 D7（海外短剧归因/投放 ROI 数据产品）有启示：定价可锚定"跑通一份归因报告/一个渠道回本测算"而非按账号席位。
2. **"自更新"是比"生成更快"更深的护城河**：Clueso 的卖点是内容随源系统演进持续正确；Duvo 是流程随系统演进持续执行。复刻 Agent 产品时，重点不是"一次生成多好"，而是"能否持续正确地再生成"。
3. **合规即门槛也是信任状**：两家都拿 SOC2/ISO 当获客信任状。做企业侧产品，认证不是成本中心，是销售前置条件。
4. **免费档/免费试点是 B2B Agent 的标准钩子**：Clueso Free 带水印、Duvo 两周免费发现——先用零风险试用建立证据，再转付费。可照搬。

> 标注说明：凡来源未公开的数据（毛利、估值、单客户成本等）均已标「不确定」；Capterra 与官网定价不一致处已注明以官网为准。
