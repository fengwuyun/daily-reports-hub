## 关键结论速览

- **Clark**：把「审计助理」做成 24/7 自主员工，CPA 只保留判断与签字。商业模式 = 垂直 SaaS 订阅（定价未公开，custom）+ 100% 准确率/同行评审资金担保做差异化。壁垒在审计域专业度、合规认证（SOC1/2 Type2、ISO27001）、事务所方法论锁定；可复刻的是 Agent 技术骨架，难复刻的是职业责任与信任。

## 产品一：Clark（原 uiAgent）—— 自主 AI 审计员工

### 1. 产品名称 & 一句话定位
**Clark**（产品名 Clerks / 站内亦称 Ava）—— 面向注册会计师（CPA）事务所的「自主 AI 审计员工」，7×24 替审计师做资料追要、测试执行与底稿编制，人类保留专业判断与签字。

### 2. 产品定位与目标用户
- 目标用户：**审计与鉴证类专业服务机构**（CPA 事务所），先从员工福利计划审计（EBP/401k）切入，已扩展到财务报表、单体、非营利、薪酬、SOC、 payroll 等审计，以及客户会计服务（月结、对账、rollforward）。
- 解决的核心问题：审计中大量低价值、易卡壳的「追资料 / 跑测试 / 编底稿」工作占用了审计师时间；传统审计是「年度快照」，发现问题时钱已花掉。Clark 让检查持续进行（continuous verification）。

### 3. 核心价值主张（凭什么付费/留存）
- **「不睡觉的审计助理」**：Clerk 被分配到某个 engagement（审计项目），像初级审计员一样从头跑到尾；缺资料自动向客户索取并跟进，资料一到即刻续跑，无需人工再提示。
- **证据链可追溯**：每个数字/结论都回链到源文件的精确位置；计算、抽样、统计以代码执行而非让大模型心算，降低幻觉。
- **事务所方法论锁定**：Methodology Studio 把每家事务所的审计程序、底稿模板、复核关卡编码进去；Agent Studio 无代码建自定义 Agent——用「自家方法」而非通用方法论，切换成本高。
- **100% 准确率担保 + 同行评审担保**（资金兜底，是最大差异化）：创始人原话「AI 要干活，造它的公司就该负责」。

### 4. 盈利与营收模式
| 项目 | 内容 | 来源/确定性 |
|---|---|---|
| 定价策略 | **未公开**，官网为「Custom · Contact for pricing」，demo-only、仅美国可用 | AI Agents List 页；标不确定 |
| 收费点 | 推测为按事务所/engagement 的 SaaS 订阅（垂直 SaaS 惯例），具体档位与是否按用量未披露 | 推断，标不确定 |
| 收入结构 | 目前早期，35+ CPA 所已用（含 CliftonLarsonAllen、Aprio、Kreischer Miler、Sensiba）；ARR/客单价未披露 | PR Newswire / Unite.AI；标不确定 |
| 担保作为商业武器 | 用「100% 准确率担保 + 同行评审担保」降低事务所采用顾虑，本质是责任转移换取采购决策 | Accounting Today / PR Newswire |

### 5. 关键成本结构与资源
- **算力/模型成本被刻意压低**：系统设计为「静默 engagement 几乎零 token 消耗」——由连接系统上报变更或定时轮询，先用小快模型筛掉无关事件，只有「可能影响 engagement 的变更」才进大模型推理；忙的 engagement 才按实际发生量花钱。
- **合规与认证成本**：已通过 SOC 1 Type 2、SOC 2 Type 2、ISO 27001，支持 HIPAA/GDPR；审计属强监管，认证是必备入场券。
- **担保准备金**：100% 准确率担保意味着公司资产负债表要能为 AI 出错兜底，这是隐性负债。
- **数据隔离**：明确「不为训练跨事务所共享数据」，需要在架构上做租户级隔离。

### 6. 获客与增长策略
- **种子客户 + 标杆事务所背书**：以 35+ 家 CPA 所（含 Top 级 CLA）做信任状；用具体痛点故事（周六晚 11 点客户上传缺失银行对账单、周一才被发现）做叙事。
- **监管叙事驱动**：引用 GAO 估算美国联邦政府年 fraud/waste 2330–5210 亿美元，把「持续审计」包装成能抓 fraud 的新审计服务，帮事务所开拓政府/企业新业务线。
- **销售驱动（sales-led）**：早期垂直厂商典型路径，demo + 部署评审（SSO、数据驻留、留存/导出条款在部署评审中确认而非公开）。

### 7. 竞争壁垒
- **专业域壁垒**：审计程序、复核标准、底稿规范是深行业 know-how，通用 AI 工具难以替代。
- **合规与信任**：SOC/ISO 认证 + 数据不跨所训练 + 资金担保，构成「敢让 AI 碰审计」的门槛。
- **方法论/流程锁定**：事务所把自身方法编码进 Methodology Studio 后，迁移成本极高。
- **弱项**：模型本身未自研（未公开用哪家），技术骨架（agent harness + 文档处理 + 多层记忆）可被复刻；护城河实质是「职业责任 + 信任 + 合规」，而非纯技术。

### 8. 可复刻该模式的关键步骤与条件
| 步骤 | 动作 | 门槛 |
|---|---|---|
| 1. 选一个界定清晰、流程标准的专业服务 | 如记账月结、税务申报、尽调资料收集 | 低：单人可定义 |
| 2. 搭「委托而非聊天」的 Agent 骨架 | 任务定义→计划预览→执行→回链证据→异常上报 | 低–中：WorkBuddy Skill+MCP 可起步 |
| 3. 证据可追溯 + 代码化计算 | 每个结论回链源文件，抽样/统计走代码 | 中 |
| 4. 行业合规认证（SOC2 等） | 才能进企业/专业机构采购白名单 | 高：时间与费用 |
| 5. 资金兜底担保 | 用「包赔」换采购决策 | 高：需资产负债表支撑，慎做 |
| 可低成本起步 | 1–3 步，做垂直小场景的数字员工 MVP | — |
| 门槛高 | 4–5 步的合规与责任转移 | — |

**OPC 视角**：Clark 就是 Oscar 一直在做的「AI 员工化 / 日报分析员」路线在审计业的落地样板——核心不是模型，而是「把一项专业服务拆成可委托、可追责、证据可溯的 Agent」。在国内复刻可从非强监管场景（如电商/投放日报分析员、财报初稿编制）起步，担保条款先用「人工复核兜底」替代资金兜底。

## 产品二：Marble（Marble Cognition）—— 观察员工学做事的 AI Coworker

### 1. 产品名称 & 一句话定位
**Marble**（Marble Cognition）—— 用桌面端观察员工「怎么干活」，把隐性流程变成结构化地图，再派出 AI Coworker 在原有业务系统里端到端跑流程、人在关键判断处介入。

### 2. 产品定位与目标用户
- 目标用户：**任何想把白领重复性流程交给 AI 的企业**，早期落地在 PE 旗下金融服务公司、德国科技企业（EGYM、Mutares、Enam）及 PE 组合公司。
- 解决的核心问题：企业 90%（创始人估计）核心流程只存在于收件箱和人员脑子里、从未被书面记录；传统自动化要先让人「写清楚流程」，而人极不擅长准确自述。Marble 改「先记录、再自动化」。

### 3. 核心价值主张（凭什么付费/留存）
- **观察即建模**：桌面 App 录制业务软件内的屏幕、点击、键击，转成 AI 可读的结构化流程地图（process map / SOP）。
- **观察后即执行**：据此生成 Coworker，在团队现有工具里端到端跑流程；需要判断时升级给人，不瞎猜。
- **隐私前置**：捕获内容在进入任何人或模型前先匿名化、仅聚合不针对个人、只录业务 App、不录私人标签/非工作时间、员工可随时暂停；支持客户云/本地部署。
- **提效叙事**：单一 PE 旗下金融服务客户案例——单案处理时间降 90%、首月无增员多处理 50% 案件（公司自报、未独立验证，标不确定）。

### 4. 盈利与营收模式
| 项目 | 内容 | 来源/确定性 |
|---|---|---|
| 定价策略 | **未披露** | 各源均未提；标不确定 |
| 收费点 | 企业自动化 SaaS，按 Coworker/流程/席位或用量计费均可能，无公开信息 | 推断，标不确定 |
| 客户 | 已具名 EGYM、Mutares、Enam；另有德国科技公司、欧洲 PE、美国 PE 旗下专业服务公司 | AI Frontier Post / Pomegra |
| 早期指标 | 单一部署 90% 时间降本 / 50% 吞吐提升——单客户首月、非对照实验 | 标不确定 |

### 5. 关键成本结构与资源
- **推理算力是主要变动成本**：Agent 跑在真实工作流上、持续消耗算力，是 pre-seed 资金主要去向之一（与 Clark「静默零消耗」相反，Marble 是「持续观察 + 执行」重算力）。
- **观察捕获技术**：录屏 + 键鼠事件 + 业务 App 识别 + 匿名化流水线，是工程核心。
- **隐私合规**：匿名化、聚合、可暂停、本地/客户云部署，是进企业采购的前提。

### 6. 获客与增长策略
- **投资人即渠道**：天使含 Datadog 董事、Personio 创始人、McKinsey/Mistral AI/Lovable 高管——直接对接欧洲企业 GTM 与 PE 组合公司。
- **「观察即自动化」demo 驱动**：用「看一遍就会干」的强演示打动想自动化却写不清流程的客户。
- **地理扩张**：慕尼黑工程团队 + 美国 launch 计划，借 PE 网络做跨洲复制。

### 7. 竞争壁垒
- **差异化定位**：流程挖掘厂商（Skan AI $63M C 轮）只「画地图不跑」、RPA 巨头（UiPath）只「跑人写好的脚本」；Marble 把「观察 + 执行」合为一体。
- **软肋/风险**：incumbent 有庞大客户基数，加「观察」能力窗口短；pre-seed 资金远少于对手（Skan $63M、Interloom $16.5M、Duvo $32M），靠速度和新品类定义抢时间。
- **隐私信任**：匿名化 + 可暂停 + 本地部署是相对大厂的信任优势。

### 8. 可复刻该模式的关键步骤与条件
| 步骤 | 动作 | 门槛 |
|---|---|---|
| 1. 选一个垂直、重复性、跨系统但规则固定的流程 | 如电商客服退款、报销初审、简历初筛 | 低 |
| 2. 做轻量「观察录制 + 流程地图」MVP | 录屏/事件捕获 → 结构化步骤 → 可重放 | 中：需桌面捕获与隐私边界处理 |
| 3. 接原有工具执行（API 优先，无 API 走 RPA/浏览器自动化） | 在客户现有系统里跑，不要求换平台 | 中 |
| 4. 设 human-in-the-loop 判断节点 | 降低「自动化出错」责任 | 中 |
| 5. 企业级隐私/合规（匿名化、可暂停、本地部署） | 进大客户采购 | 高 |
| 可低成本起步 | 1–3 步，单人切一个垂直流程做 MVP 收第一笔钱 | — |
| 门槛高 | 4–5 步的企业信任与合规 | — |

**OPC 视角**：Marble 是「30 天拿第一笔收入」的高契合范本——思路极轻：找一个被 AI 替换 legacy 软件的白领流程，先做「观察→地图→执行」的最小闭环收订阅费。对 Oscar 而言，可先在「海外短剧投放日报/异常归因」这类自家域做内部 Coworker，验证后再外化为小企业自动化产品；隐私/合规先用「本地运行 + 可暂停」降低采用阻力。

- 凡营收、ARR、估值、定价、客户提效未公开或为厂商/单一客户自报，一律标注「不确定」，不把宣传口径当事实。
