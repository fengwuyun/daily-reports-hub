# 产品一：doubleAI / Maxwell（Code Execution Model）

## 1. 产品名称 & 一句话定位

- **名称**：doubleAI（公司，以色列特拉维夫）+ 首款产品 **Maxwell**
- **一句话定位**：全球首个"代码执行模型（CEM）"——住在运行中的程序里、按硬件与数据现场重写底层机器码，用**形式化证明**保证行为不变，从而把同样的芯片"多榨出性能"，并**按客户省下的算力费分成**收费。

## 2. 产品定位与目标用户

| 项 | 内容 |
|---|---|
| 解决谁的什么问题 | 企业 AI 算力账单暴涨（H100 一年期租金同比 +60%，SemiAnalysis；现货紧张），"加卡"成本高且买不到——doubleAI 选"让手里的卡跑更快" |
| 目标用户 | 算力账单最大的群体：**头部 AI 实验室（OpenAI/Anthropic 等）**、跑专用微调模型的企业、视频生成管线、大规模 embedding/RAG 系统 |
| 与编码 Agent 的关系 | **互补不竞争**：Claude Code/Cursor/Copilot 负责"写"代码，Maxwell 在"执行层"优化，源代码一行不动，无需重训模型 |

## 3. 核心价值主张

- **凭什么让客户付费**：直接砍可量化的算力账单，且用**数学证明**保证优化后程序行为不变（解决了"运行时改代码无人复核"的信任死结）。
- **厂商自报效果（未独立验证，标"不确定"）**：数据管道 >38× 加速、AI 推理内核 >4.5× 加速；某早期客户算力成本 −67%；视频模型公司 LTX 推理速度翻倍（LTX CEO 公开确认）。
- **对齐激励**：按节省分成 → 客户账单降了才付费，对 CFO 友好，无需先签年框再证明价值。

## 4. 盈利与营收模式

- **核心模式：gain-share（按节省分成）**。Shashua 举例：客户算力账单从 $10M 降到 $6M，doubleAI 拿走那 $4M 节省中的**某个百分比**；具体费率**未披露（不确定）**。
- **逻辑**：把自身收入和客户降本直接挂钩——优化越狠、自己赚越多，是对"算力供应商靠低效用代码赚钱"旧范式的反向挑战。
- **无传统 SaaS 订阅/按 token 计费**：刻意避开，因目标客户是"账单以百万美元计"的大户，分成比订阅更顺。
- 预计 broader release 在 2026-10-31 前；当前 early access（heymaxwell.ai）。

## 5. 关键成本结构与资源

| 资源 | 说明 |
|---|---|
| **算力（自建）** | 募资约一半（约 $110M）直接买 **1,000 块 Nvidia B300** 自用，而非全租云——Shashua："不能只靠租，价格在涨" |
| **人才** | 约 40 人、成立约 2 年；核心是**形式化验证 + 编译器/ML systems** 尖端人才（CEO 为 Mobileye 创始人 Amnon Shashua，联创 Shai Shalev-Shwartz） |
| **资本** | 总募资约 **$220M**（其中 $200M Series A，估值 >$1B）；领投 Lightspeed、Bessemer，跟投 Nvidia、Dell Technologies Capital、Greenfield、Pitango、BRM |
| **验证开销** | 形式化证明本身吃算力，短任务/波动负载可能 overhead 抵消收益（厂商提示需测长稳负载） |

## 6. 获客与增长策略

- **标杆客户背书**：LTX（开放权重多模态）公开确认翻倍提速，作为可引用案例；瞄准 OpenAI/Anthropic 等"省 10% 即数亿美元"的灯塔客户。
- **自上而下（Enterprise, top-down）**：早期 access + 针对具体硬件/负载做**省前预估**，用 gain-share 降低决策门槛（"先估再签"）。
- **生态位卡位**：把自己定义为"编排层与推理层之间"的优化层，强调 add-on 而非替代，降低集成阻力。
- **资本驱动叙事**：Nvidia 亲自下场投资（"英伟达给自己算力的商品化买单"），本身就是强背书与渠道信号。

## 7. 竞争壁垒

| 壁垒 | 强度 | 说明 |
|---|---|---|
| **形式化验证技术** | 高 | 运行时改写机器码还能数学证明等价，是真正的硬科技壁垒；短期难被抄袭 |
| **Nvidia 关系 + 自建千卡** | 高 | 既拿投资又拿卡，算力自给，受租金上涨冲击小 |
| **创始人/团队光环** | 中高 | Mobileye 153 亿美元退出案例 + 顶尖学术联创，融资与人才吸引力强 |
| **gain-share 定价心智** | 中 | 范式创新，但易被模仿为"按效果收费"口号 |
| **大客户切换成本** | 中 | 一旦接入并验证省幅，粘性强；但客户也可自研或等大厂（如 Nvidia/芯片厂）从硬件侧解决同一问题 |

## 8. 可复刻该模式的关键步骤与所需条件

**结论**：定价范式（按效果分成）**可低成本抄**；核心技术（运行时形式化重写）**门槛极高**，不适合小团队正面硬刚。

- ✅ **低成本可起步（定价/商业侧）**
  1. 任何"能帮客户降本"的工具/咨询，都可改造成 **gain-share 合同**（省多少抽多少），用 ROI 仪器属性替代年框。
  2. 先选一个**具体热点负载**（如某 CUDA kernel、某 pandas 数据管道）做 demo，比泛泛"优化 AI"更易成交。
- ⚠️ **中门槛（工程侧）**
  3. 搭一个**剖析器**：基线测量 → 提出可验证变换 → 自动回退守卫（条件不满足交还原代码）。
  4. 用云 GPU 租赁做研发（**不必学他们买千卡**，那是资本配置选择，非技术必需）。
- ❌ **高门槛（技术侧，慎入）**
  5. 形式化等价证明需要编译器 + 程序语言 + 验证交叉人才，属于研究级难题；小团队建议聚焦**单一负载的启发式优化 + 实测对比**，而非通用 CEM。
- **必备资源/门槛**：形式化方法/编译器专家、可信参考客户、测算方法论（如何让客户信"省了多少"）。

# 产品二：Ambi（Ambient AI）

## 1. 产品名称 & 一句话定位

- **名称**：Ambi（母公司 Mistlabs，创始人 Peter Mo 为前 Plaud 高管/中国区 CEO）
- **一句话定位**：全天候"环境聆听"AI——不止会后总结，而是**会中实时**基于日历/知识库/网页给建议的"主动智能"App；软件先行，并规划自带屏/摄/扬/麦的硬件。

## 2. 产品定位与目标用户

| 项 | 内容 |
|---|---|
| 解决谁的什么问题 | 传统会议纪要类工具（Otter/Fireflies/Granola）只能"会后出总结"；Ambi 把智能**前置到会议进行中**，并扩展到"全天上下文捕获"，解决"智能被困在屏幕里、要等上传处理"的延迟 |
| 目标用户 | 知识工作者、频繁开会/跨设备办公的专业人士；团队 >50 人，办公室分布 SF/北京/上海/深圳 |
| 差异化 | 连续后台聆听（默认关）+ 会中主动建议；对比纯会后总结的工具形成"实时"技术区隔 |

## 3. 核心价值主张

- **主动而非被动**：会中实时推荐相关资料/文档/下一步，不只是结束后给纪要。
- **跨设备无缝**：在一台设备发起任务，另一台续做；规划桌面端监控工作流 + 本地记忆。
- **生态连接**：已列连接器 Gmail、Google 日历/文档/表格/幻灯片、Drive、Dropbox、Notion、Slack、**飞书(Lark)**、Teams、Outlook、Zoom、GitHub、LinkedIn、HubSpot、Salesforce、Twitter、iMessage、短信、WhatsApp。
- **软硬一体愿景**：硬件设备（屏+扬+摄+麦）计划 2027 年初 CES 发布，把"环境感知"从手机延伸到实体。

## 4. 盈利与营收模式

- **订阅 + credits（按周重置、不滚存）**，来自官价页（IC.work/网易/LIFE生活网 交叉印证）：

| 档位 | 价格 | 每 7 天 credits | 实时 AI 时长(约) | 备注 |
|---|---|---|---|---|
| Free | $0 | 4,000 | ~2h | 3 Routine / 3 完整 Insight；7 天试用含 4,000 点、无需付款 |
| Plus | $20/mo | 8,000 | ~4h | 折算每周仅约 4h 实时聆听，与 ChatGPT Plus 同价但额度紧 |
| Pro | $100/mo | 45,000 | ~26h | 放开 MCP agent 数量限制 |
| Max | $200/mo | 100,000 | ~62h | Routine 不限量；高频专业级 |

- **年付统一八五折（15% off）**。credits 在实时 AI / 问答 Chat / 后台任务间共享；付费下手动基础录音与转写**不占 credits**，免费用户需有效积分才能开 Listening。
- **营收结构洞察**：高额定档（$100/$200）实质是**售卖算力切片**——实时流式推理 token 消耗极大，定价暴露了"环境智能"的算力窘境（标"不确定"：实际毛利未披露）。

## 5. 关键成本结构与资源

| 资源 | 说明 |
|---|---|
| **算力（最大成本）** | 实时流式 ASR + 会中 LLM 推理，token 消耗远高于会后批处理；credits 体系即为此设的"算力账本" |
| **ASR/LLM 供应商** | 后端接 OpenAI、Anthropic、Google、**Soniox（流式转录）** 等合规供应商；承诺不将私有内容用于训练 |
| **团队/资本** | $26M 融资（Luminous Ventures 领投 + ODM 华勤），团队 >50 人；前 Plaud 高管带来硬件/供应链认知 |
| **合规成本** | 隐私政策：主动录制音频/原文件云端保留 90 天、操作日志 180 天（与"即录即删"宣传存在口径落差，标"注意"） |

## 6. 获客与增长策略

- **创始人杠杆**：前 Plaud（录音硬件爆款）高管自带"会议智能"品类认知与渠道，冷启动可信度高于纯新团队。
- **平台铺量**：首发 macOS/iOS/watchOS（Apple 生态），下载即装，降低门槛；Android/iOS 全量"即将推出"。
- **Freemium + 7 天试用无卡**：低摩擦转化；用 credits 上限逼高活用户升 $100/$200。
- **硬件造势**：CES 2027 硬件预告，制造"软硬一体"叙事与期待，反哺软件订阅心智。
- **连接器的网络效应**：接飞书/Slack/Notion 等越多，切换成本越高，向"个人工作操作系统"演进。

## 7. 竞争壁垒

| 壁垒 | 强度 | 说明 |
|---|---|---|
| **实时会中 Agent 时延/成本工程** | 中高 | 流式 ASR + 低延迟 LLM + credits 成本控制的工程闭环，需调优 |
| **硬件 + 供应链（前 Plaud 基因）** | 中 | 拟自研带屏设备，有硬件经验者稀缺 |
| **连接器生态** | 中 | 接得越广越黏，但本质是集成，壁垒有限 |
| **品牌/创始人** | 中 | Plaud 光环助力，但易被大厂（Google Foresight 等离线会议笔记）碾压 |
| **合规护城河？反向风险** | ⚠️ | "全员同意"录音法（加州/伊利诺伊 BIPA 高额法定赔偿）是**核心法律风险**而非壁垒；处理不好即成致命伤 |

## 8. 可复刻该模式的关键步骤与所需条件

**结论**：**会议助手（会后总结）可极低成本抄**；**环境聆听 + 实时会中 Agent + 硬件 + 合规**门槛递增。

- ✅ **低成本可起步（MVP）**
  1. 选单一平台（先 macOS 或先 Web）+ 单场景（会议笔记），用开源/API 转录（Whisper/Deepgram/Soniox）+ LLM 出纪要。
  2. 照搬 **Freemium + credits** 计费：免费额度引流，$20 档起步，按分钟/点数计量。
  3. 接 2–3 个高频连接器（日历、Notion、Slack）即可形成"比纯纪要多一点"的卖点。
- ⚠️ **中门槛**
  4. 做**会中实时**建议：流式 ASR + 低延迟 LLM + 成本熔断（credits 用尽即降级），工程不小但技术可行。
  5. 隐私合规基线：默认关聆听、加密传输、明确留存期限、禁用训练——否则寸步难行。
- ❌ **高门槛**
  6. 全天候环境聆听 + 自研硬件设备 + 跨法域"全员同意"合规，需法务+硬件+资金，个人/小团队不建议同时上。
- **必备资源/门槛**：ASR 与 LLM API 额度、应用分发账号（Apple/Google）、隐私政策与法律审查、冷启动靠创始人/社区而非纯投放。

## 附：OPC / 个人可借鉴视角（仅供参考）

1. **定价范式值得偷师**：Maxwell 的 "gain-share（按节省分成）" 对任何"能帮客户降本/增收"的 AI 工具都成立——比"先收年费再证明价值"更容易敲定企业单。可复制到 Oscar 的 D7（海外短剧 ROI/归因）方向：按"帮广告主省下/多赚的投放费"分成，而非纯 SaaS 订阅。
2. **Ambi 的 credits 账本是"算力即商品"的范本**：做 C 端 AI 产品时，把"实时推理成本"显性化为按周 credits，既能控本又能制造升级锚点。
3. **合规是环境智能的生死线**：若做"监听/全天候"类 AI，务必把"全员同意 + 明确留存期限 + 禁用训练"做成产品默认值，否则参考加州/伊利诺伊判例风险。
4. **两条路对照**：Maxwell=卖"看不见的降本基础设施"（高壁垒、高客单）；Ambi=卖"看得见的能力升级 App"（低壁垒、靠速度与合规取胜）。小团队更现实的切入是 Ambi 路线里的"会后总结 MVP"，而非正面挑战 CEM。
