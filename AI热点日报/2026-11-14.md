## 一、AI 资讯

**1. Cursor 供应链被攻破：投毒的 Claude Code 扩展在市场缓存里活了约 11 小时，最多 5,000 人中招（P0·安全·跟你工具链直接相关）**

Cursor 11/13 公布两周调查结论，11/14 在开发者圈持续发酵。攻击链起点是一把 Cursor 发给 Fireworks AI 的访问密钥在 Fireworks 侧泄露。攻击者用它拷走只读存储桶里的 coding-agent 轨迹（多为 2025 年、未开 Privacy Mode 的会话），在轨迹里翻出未脱敏的真实凭据，顺着进到 Cursor 内部几个 SaaS 工具；10/29 用另一把窃得的凭据，把两个被篡改的 Claude Code 扩展构建（2.1.312 / 2.1.313，Windows 与 macOS 各一份）**直接塞进 Cursor 扩展市场的缓存层**。恶意代码要做三件事：写攻击者 SSH 公钥、开 SSH、开一条常驻反向隧道。上架约 11 小时、最多触达 5,000 名用户；因恶意代码自身有 bug，多数无管理员权限的机器上 SSH 那步失败，但公钥与持久化脚本已经落盘。Cursor 口径：受影响轨迹 <0.05% 用户、API 凭据 <0.01% 客户；生产基础设施、应用发布、客户仓库与 Privacy Mode 数据未受影响；11/1 阻断最后一次活动，已把全部推理迁离 Fireworks、重建整个扩展市场。Anthropic 未发布过这两个构建，Open VSX 也未托管恶意包——毒在「市场缓存」这一层，不在源头仓库。

同源另一条：Fireworks 11/9 扩大披露——除 10/9 已承认的环境变量泄露，还有账单与发货地址、发票与付款历史、账户余额被访问，部分客户的密钥、数据集、**不完整模型权重**也被拿走；第二起入口是其第三方云厂商 10/23 被攻破。Fireworks（今年 7 月估值 175 亿美元）归因于倒卖模型访问权限的「LLMjacking」团伙，与 Palo Alto Networks Unit 42 联合调查。

跟你业务直接相关：日报自动化、抓取、批处理都跑在 Claude Code / Codex 上，扩展从市场缓存装。三件立刻能做的：①把「缓存层来源」和「官方 registry 来源」分开算信任，上游干净不等于 CDN 干净；②agent 会话轨迹现在是凭据仓库，外发给第三方做训练/分析前先脱敏；③扩展装完扫一遍 `~/.ssh/authorized_keys` 有没有陌生公钥——这次恶意代码的主要动作就是加这一条。

源：Cursor 事件报告 /Fireworks 安全公告 /TechCrunch /dev.to，11/9–11/14

**2. 和平饭店「6 人消费 51.7 万元」天价账单查明是 AI 改的：15 人落网（P0·跟你业务直接相关）**

上海黄浦警方 11/13 通报、11/14 冲上微博热搜第 2（约 19 万热度）与今日头条热榜第 1（5852 万）。经查：外省市一家互联网酒类销售公司负责人赵某某为博关注、提销量，组织王某某等 3 人**用 AI 软件篡改账单金额、把饭店用酒换成本公司产品**，制作虚假视频后控号、雇人代发。4 人被采取刑事强制措施，11 人被行政处罚。

判断：这张账单最贵的地方不是那瓶标价 23 万的酒，是它证明「伪造证据」的成本已经降到一部手机。以前造这种谣要 PS、要做假票据，现在改个数字就能生成以假乱真的影像。

跟你业务直接相关：投放素材里凡是出现「截图、账单、聊天记录、后台数据」这类可被当作证据的画面，都是造假指控的高危点位；自证清白的速度正在变成竞争力——素材留底、拍摄脚本留档、生成链路可追溯，出事时才拿得出东西。

源：央视新闻 /央广网 /上海黄浦警方通报，11/13–11/14

**3. AI 短剧《持械入宋》登顶红果 AI 榜、全网播放 66 亿：投入 100 万，已盈利（P0·跟你业务直接相关）**

**4. Gemini 4 Carbon 登顶 MathArena 85.4%，但高推理档单任务 $15.7（P1·价格）**

11/14 公布的评测：Gemini 4 Carbon 以 85.4% 准确率超过 GPT-6.1 Sol 的 80.6%，终结 OpenAI 在高级数学基准上的长期领先。但同一份评测给了另一面：Carbon 高推理档单任务平均成本 $15.7，约为对手的 15 倍。

判断：这是「每美元智能」第一次被摆在榜单旁边公开算账。能力领先和商业可负担之间的落差还在扩大——单价低不等于账单低，推理档位一开，成本结构立刻变形。

做法：把「高推理档」当成一次性武器而不是默认档。先用 Medium 档跑通任务、记下实际 token 消耗，再决定哪些任务值得开满档。

源：THE DECODER，11/14

**8. AI 从平扫 CT 里「顺带」筛出 41 例无症状肠癌：敏感性 86.6%、特异性 99.8%（P1）**

11/14 报道：上海新华医院与阿里达摩院联合研发的肠癌筛查 AI，从普通 CT 平扫中识别医生肉眼难辨的病灶，已辅助发现 41 名无症状肠癌患者，多为早中期、均已手术；无需注射造影剂。一位 48 岁患者因车祸拍 CT 被 AI 提示，确诊 II 期结肠癌并完成根治。

判断：这套系统最聪明的地方是「不增加任何一步」——病人本来就要做 CT、医生本来就要写报告，多出来的只是那一眼。真正能落地的 AI，往往长得不像 AI。

**1. 美国全国航班停飞：近 7,000 班受影响，初步指向软件更新故障**
来龙去脉：11/14 美国联邦航空管理局因空管系统严重通信故障发布全国范围地面停飞指令，近 7,000 个航班受影响，欧洲航空安全组织同步暂停成员国赴美航班。初步调查指向软件更新故障而非网络攻击——这是 2001 年之后全美罕见的全国性禁飞。NBA 等赛事被迫重新排行程（有客场任务的球队当天开始制定备选方案）。
判断：高度集中的系统，抗打击能力和爆炸半径成正比。这条和本期资讯第 7 条（微软 365 宕机）是同一个母题的两层：一层是软件配置，一层是软件更新——都不是攻击，都不是小概率，但都能让一个国家的交通停摆。

源：FAA 通报 /中新网 /多平台热搜聚合，11/14

**2. 产妇求剖腹产遭拒、孩子脑瘫：法院在病历存疑下推定医院全责，判赔 42 万**
来龙去脉：11/14 微博热搜第 2（约 79 万热度）。产妇产程中多次要求剖宫产被拒，延误后新生儿重度窒息导致脑瘫；因关键胎监原始数据存在争议、医院无法提供完整记录，法院在病历资料存疑的情况下推定医院承担全部赔偿责任。争议焦点是 42 万元判赔与家属诉求、长期康复开销之间的落差。

源：微博热搜 /法院通报经媒体转述，11/14

**3. 南京「零元面馆」周边 7 家店挂转让：免费模式的账由谁付**
来龙去脉：11/14 百度热搜在榜。南京一家免费供餐一个多月的「零元面馆」持续走红，周边快餐店已有 7 家挂出转让牌，多家经营多年的商户称营业额显著下滑、难以覆盖房租。争议核心：公益让利与低价倾销的边界，以及外部性由谁承担。
判断：这是「免费引流」最有教育意义的一次现场演示——免费模式的边际成本可以趋零，但它的成本没有消失，只是转移到了同一品类的邻居身上。做内容、做投放的人同理：用免费/超低价抢来的注意力，最后一定有人替你付账，而那个人通常不在你的报表里。

源：百度热搜 /当地媒体走访，11/14

## 三、潜在挣小钱的机会

**1. Postiz：开源社媒排程器由 AI agent 运营，月流水 $41.86 万（TrustMRR 核实，11/14）**
路径：开源社媒内容排程工具，核心不是功能而是运营方式——由 AI agent 生产并排程内容，主要获客渠道是 Reddit + 开源本身。核实口径：MRR $418,600（TrustMRR，11/14 最近核实）。可复制的部分：用开源做分发（GitHub 星数 → 自托管用户 → 转云服务付费），这条转化路径是慢但可重复的；不可复制的部分：排程器是个拥挤赛道。
⚠️ 一是公司规模未披露（已不是一人项目）；二是「AI 运营账号」在平台风控上随时可能变；三是开源转付费的转化率通常个位数。
源：theaireceipts.com（TrustMRR 核实），11/14

**2. Heyron：帮「一人公司」托管 AI agent，$49/月，月流水 $1.72 万（TrustMRR 核实，11/14）**
路径：把一个「自己搭很麻烦」的东西（自托管 AI agent）托管好，再配一个社区教你怎么把 App 上线，卖 $49/月。核实口径：MRR $17,200。公开的自述里有一条关键数据：开张 13 天内做到 $8,374 MRR——靠的是一条爆掉的 TikTok 实验加几期播客。
⚠️ 同一份数据的另一半更值得看：**六个月内出现明显下滑**。炒作型启动缺的是留存引擎。这条的教训比数字值钱：把「省事」卖成订阅，前提是每月都要有新的「省到的事」。
源：theaireceipts.com（TrustMRR 核实），11/14

**3. CreativeClaw：在 Claude/ChatGPT 里卖「创意工作室」，月流水 $1.46 万（TrustMRR 核实，11/14）**
路径：一条 MCP 连接，把市面上最强的图像、视频、音频、3D 模型接进 Claude 和 ChatGPT，按 credits 计费。核实口径：MRR $14,600。价值不在模型，在工作流——模型选择、品牌套件、角色一致性。获客走 Claude/ChatGPT 的插件与连接器目录 + X。
判断：这是「一人公司能吃到的一层薄利」里最清晰的一种：**不训练模型、不做产品，只做「把模型缝进用户已经在用的界面」**。对做短剧的人来说，同样形状的服务可以挂在「角色一致性 + 多语版本」上。
⚠️ 纯转售别家模型，定价权不稳；credits 模式对现金流是预收好处、对退款是负债。
源：theaireceipts.com（TrustMRR 核实），11/14

## 四、小而美产品

**obra/superpowers（主推·把开发流程装成一套技能）**
- 是什么：把一整套软件开发方法论拆成 14 个技能装进编码 agent（Claude Code 官方插件市场、Codex CLI、Cursor、Gemini CLI、Hermes 均可）：brainstorm 出规格 → 分块确认 → 写实现计划 → subagent-driven-development（每个任务派独立子代理、两阶段审查：先查规格符合度再查代码质量）→ TDD（RED-GREEN-REFACTOR）→ requesting-code-review。27.5 万星级别，Jesse Vincent（Prime Radiant）维护
- 差异化：它不是「一个技能」而是「流程操作系统」——把「资深工程师才知道的流程」变成可复用、可审查、跨工具一致执行的资产；还带 writing-skills 这种元技能（教 agent 怎么自己写技能）
- 用在哪：你那套「一条指令给全流程」的日报/采集任务，正是这个形状；把抓取→清洗→写稿→校对→推送写成技能串，跨 harness 都能跑，不绑死在某一个 CLI 上
- ⚠️ 技能越多，上下文占用越大、行为越难预测；14 个技能全开容易互相打架，按需启用；不是独立开发者作品
- 源：hqwc.cn 技能生态盘点 /GitHub，11/14

**QGIS MCP server（主推·把 agent 接进 GIS 的事件循环）**
- 是什么：不是「聊天机器人回答地理问题」，而是通过 TCP socket 与 QGIS 的 Python 外挂通信、把 agent 直接接进 QGIS 事件循环的 MCP server（FastMCP）。破坏性操作默认二次确认，长跑工具回报进度；需 QGIS 3.28+ 外挂 + MCP client
- 差异化：大多数 MCP 只是「调 API」，这个是真的操作桌面 GIS 软件的运行时状态——意味着可以用自然语言跑完一整套空间分析流程，不用切回菜单点选
- 用在哪：做投放/门店/区域分析时，把「按行政区聚合 → 出图 → 导出」这类步骤交给 agent；数据全程在本机 QGIS 里，不出网
- ⚠️ 上手难度中：外挂 + client 两边都要配，不止一步；生态很窄，出问题基本靠自己读源码
- 源：quidproquo.cc 11/14 AI Agent 日报，11/14

**ag-ui（备选·agent 与前端之间的握手协议）**
- 是什么：定义 agent 与用户界面之间通信协议的 TypeScript 项目（流式输出怎么分块、工具调用怎么回显、状态怎么同步），不绑定任何 agent 实现；1.7 万星级别
- 差异化：定位像当年的 LSP——把「编辑器↔语言服务」的解耦，搬成「前端↔agent」。协议类项目的价值不在日增星数，在有多少项目真的采用
- 用在哪：如果你要给小程序/内部工具加一个「能看到 agent 推理过程与工具调用」的界面，直接用这套协议比自造消息格式省事，换 agent 后端时前端不用重写
- ⚠️ 日增已降到个位数（11/15 仅 +9），处于「被认可但慢渗透」阶段；早期采用者要接受协议仍在演进
- 源：CSDN 每日 AI 研究简报 /kongchang.com 11/15 日榜，11/14–11/15
