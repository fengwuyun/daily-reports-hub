## 一、AI 资讯

**1. Cursor 供应链被攻破：投毒的 Claude Code 扩展在市场缓存里存活约 11 小时，最多 5,000 人中招（P0·安全·跟你工具链直接相关）**

Cursor 11/13 公布两周调查结论，攻击链起点是一把 Cursor 发给 Fireworks AI 的访问密钥在 Fireworks 侧泄露。攻击者用它拷走一个只读存储桶里的 coding-agent 轨迹（多为 2025 年、未开 Privacy Mode 的会话），在轨迹里翻出未脱敏的真实凭据，顺着这些凭据进到 Cursor 内部几个 SaaS 工具；10/29 用另一把窃得的凭据，把两个被篡改的 Claude Code 扩展构建（2.1.312 / 2.1.313，Windows 与 macOS 各一份）**直接塞进 Cursor 扩展市场的缓存层**。恶意代码要做三件事：写入攻击者 SSH 公钥、开启 SSH、开一条常驻反向隧道。上架约 11 小时、最多触达 5,000 名用户；因恶意代码自身有 bug，多数无管理员权限的机器上 SSH 那步失败，但公钥和持久化脚本已经落盘。Cursor 口径：受影响轨迹 <0.05% 用户、API 凭据 <0.01% 客户；生产基础设施、应用发布、客户仓库与 Privacy Mode 数据未受影响；已于 11/1 阻断最后一次活动、把全部推理迁离 Fireworks、重建整个扩展市场。Anthropic 未发布过这两个构建，Open VSX 也未托管过恶意包——毒塞在「市场缓存」这一层，不是源头仓库。

扩散面同源三处。Notion 确认其 Insights 功能用到的 AI 聊天记录（多数不可归因）被暴露，影响 <1% 工作区、Insights 已停用；Notion 11/2 从 Fireworks 处得知、11/3 切断流量并删数据、11/8 才被确认「客户数据确被访问」；调查中还在用户消息里发现第三方 API 密钥，11/11 撤销了泄露的 Notion 密钥。Uber 本周向各州总检察长提交通知：司机个人信息与驾照信息经一供应商被窃，TechCrunch 指认该供应商为 Fireworks、Uber 已证实；仅马萨诸塞 2,567 人、南卡罗来纳 3,430 人、罗得岛 1,873 人，合计已 7,870 人，加州与伊利诺伊也已发通知但未列人数。Fireworks（今年 7 月估值 175 亿美元）把事件归因于倒卖模型访问权限牟利的团伙，即「LLMjacking」，与 Palo Alto Networks 的 Unit 42 联合调查。

跟你业务直接相关：你的日报自动化、抓取、批处理都跑在 Claude Code / Codex 这类 CLI agent 上，扩展与插件都从市场缓存装。三件能立刻做的：①把「从缓存层装的东西」和「从官方 registry 装的东西」分开算信任，上游仓库干净不代表 CDN/缓存干净；②agent 会话轨迹现在等于凭据仓库，凡要外发给第三方做训练或分析的会话，先脱敏再出网；③扩展装完扫一遍 `~/.ssh/authorized_keys` 有没有陌生公钥，这次恶意代码的主要动作就是加这一条。

源：Cursor 事件报告 /TechCrunch /Notion 客户通告 /BleepingComputer /dev.to，11/13–11/16

**2. GPT-5.6 Sol 全线涨价 10%：$4/$20 → $4.40/$22（P0·价格）**

价格追踪站 11/15 检测到 GPT-5.6 Sol 三条价目同时上调——输入 $4.00→$4.40、输出 $20→$22、缓存输入 $0.40→$0.44，涨幅均 10%。同日 Particle-1 输入 $0.05→$0.06（+20%）。这是这轮价格战里少见的「旗舰反向涨价」：过去两周主线一直是降价，现在头部档位开始往上补。

不要当孤立事件看。它和 11/13 那期报的「7 天 478 次降价 vs 423 次涨价」是同一件事的两面——便宜的在探底，贵的在上抬，中间档被两头挤。对按 token 计价的调用方，成本结构会从「选最便宜」变成「按任务分层」。

做法：把调用按任务分级重跑一遍。高频重复子任务（分类/抽取/格式转换）继续压最便宜档；只有「一次做错就要重来」的活留给旗舰。⚠️ 涨价是否扩散到套件内其他档位，官方价目页未见说明，未披露。

源：Tokenando 价格变更日志，11/15

**4. Gemini 4 Hydrogen：$1.50/$7.50，100 万上下文不加价（P0·价格）**

**5. Claude Opus 5.5 成为全部付费套餐默认模型（P1）**

11/15 Anthropic 宣布 Opus 5.5 取代上一代成为所有付费套餐的默认模型，同时建议用户停用上一代的「think hard」指令、把努力档从 High 降到 Medium 起步——官方自测称 Medium 档的 Opus 5.5 表现已抵得上 High 档的 Opus 5。这是「默认值即产品」的典型动作：不新增功能，只改基线，让存量用户的使用曲线整体上移一格。

「默认模型」切换对成本的杀伤力常被低估——它不是涨价，但会让你既有调用在新默认档下跑出不同的 token 数。账上第一次对不上时，先查默认档是不是被动过。

升级后第一周，把努力档显式写在 prompt 里，别吃默认值；长会话里残留的旧指令（think hard 一类）清一遍。

源：Anthropic /The Decoder，11/15

**7. OpenAI 把 ChatGPT 同时改成店铺和钱包：认证商家主页 + Business Agents 广告位 + Wallet 代付（P0·变现·跟你业务直接相关）**

两条同步推。①ChatGPT 内上线**认证商家主页**与品牌提及追踪，并开放一类新广告位「Business Agents」——符合条件（先美国）的企业可购买，让自家 agent 在 ChatGPT 里承接用户请求。这是 ChatGPT 从「聊天窗口」变成「店铺+发现面」最直接的一步。②**ChatGPT Wallet** 上线，让 agent 在 ChatGPT Work、Codex、dots 里完成购买，逐单需用户授权、沿用原有卡的消费者保护。两条合起来是完整闭环：找到商家 → agent 谈 → agent 付。

跟你业务直接相关：短剧/漫剧的海外分发一直卡在「投流买量」这一环，而 ChatGPT 这边第一次给出了「不买量、靠 agent 被调用」的入口。判断标准很朴素：如果你的服务能被一句话说清、能被 agent 调用完成，这里有低成本曝光位；如果是纯内容消费（看剧），这里暂时只是分销渠道。现在能做的只有一个动作——把你的产品/服务整理成「一句话能调用的能力说明」，等 Business Agents 开区。

⚠️ 目前仅美国、需资格审核；广告位与自然推荐如何分栏，官方未披露。

源：AI Weekly /Quadra Daily Briefing /fruition.net，11/14–11/15

**8. 短剧平台净利率不足 1%：从卖剧转向卖工具（P0·跟你业务直接相关）**

联合早报 11/15 特稿把行业利润表摊开了——ReelShort 母公司枫叶互动 2025 年上半年净亏损 4651 万元人民币（约 897 万新元）；点众科技公开表示短剧业务净利率不足 1%。同时给出产能侧的硬数：OpenRouter 上 10/26 当周，字节、阿里、快手、MiniMax 四家中国视频模型合计吃掉该平台 API 请求量的 46.4%，其中字节 Seedance 系列以 26.1% 居首；字节的 PineDrama（免费+广告、靠 TikTok 引流）9 个月下载破 1 亿、日活约 700 万。转折点在这里：头部开始从「做剧给人看」转向「教人怎么做剧」——中文在线、酱油文化等把自家的「保人物一致 + 统筹生成」工作流和 agent 打包对外。

净利率 <1% 说明投流买量的钱几乎全被渠道拿走，内容本身不再是利润中心。这对一人/小团队是好消息：**平台赚不到的钱正在往工具层转移**，而工具层的客户是同行，不用跟平台抢流量。

别去跟平台比产能（人家月更 800–1287 部），去做「一部剧从剧本到多语版本」里最脏的那一步，做成能卖第二遍的模板/工作流。

源：联合早报（含 OpenRouter 数据引用），11/15

## 二、热点 & 梗

**1. 猪价跌到 10 年新低，菜场里青椒和肉一个价**
来龙去脉：11/15–11/16 猪价创近 10 年新低连续霸榜，百度热搜第 1、微信搜一搜第 1，最直接的体感是「一盘青椒肉丝，青椒和肉一个价」。归因层面公开报道集中在供给充裕叠加消费偏弱，但生猪存栏与产能的具体官方口径未见同期披露（未披露）。同一天另一条热搜撞了上来：「酸奶界的爱马仕」Blueglass 一年内门店净减 66 家（降幅约 31%），单杯近 50 元的高溢价模式退潮。一头是「肉比菜便宜」，一头是「酸奶卖 50 块没人买」，一天之内把消费分层的两头同时摆出来了。
判断：这两条放一起看才准——不是简单的「消费降级」，是**参数透明化**。能算清成本的东西卖不上溢价，算不清的（品牌叙事、社交货币）先被砍。

源：百度热搜 /微博 /微信搜一搜聚合，11/16

**2. 「亲肤棉」「水洗棉」都不是棉：买衣服别看名字，看水洗标**
来龙去脉：11/16 微博热搜第 1，话题「买衣服别被面料名字忽悠」。科普的核心很硬：纺织纤维规范里没有「亲肤棉」「水洗棉」这类法定名称，它们不构成含棉量承诺，实际成分可能是聚酯纤维等化纤；判断含棉量只有一个依据——水洗标上的法定「纤维成分」标注。
跟你业务直接相关：这条对投放素材是直接的合规提醒。「纯棉」「100% 棉」「婴儿级亲肤棉」这类文案，没有水洗标或检测报告支撑就是虚假宣传的现成靶子。素材库里带材质宣称的模板，上线前应挂上对应检测依据。

源：微博热搜 /纺织纤维规范科普，11/16

**3. 老板假装扫付款码，为一位特殊顾客免单五年、五百多次**
来龙去脉：江西萍乡安源区一家小超市，店主陈辉五年来对一位五十岁上下、早年受刺激后独居的低保女子，每次都照常扫码却不生成消费记录——累计五百多次、贴补近万元。11 月中旬被媒体挖出后连续登顶微博热搜；各地网友往店里寄衣物零食保温杯，外卖订单备注写「老板，我给她买几次单」。店主回应：热度会降，日子照过。被问值不值，他说「我在帮她，她其实也在帮我」。
为什么值得记：这是今年少见的「传播不靠投放、不靠对立」的样本——没有冲突、没有反转、没有脚本，纯靠一个具体动作被重复了五百次。做内容的都该看一遍：能被复述的故事，比能被算法识别的钩子活得久。

源：中华网 /微博热搜，11/16

**4. 微软宕机的尾巴：德国酒店泳池加氯失控，报警邮件没送到，15 名住客呼吸道受伤**
来龙去脉：德国科隆附近布吕尔的梦幻乐园（Phantasialand）旗下酒店，泳池自动加药系统故障、氯含量严重超标，15 名住客出现呼吸道刺激、4 人送医。乐园的说法是：系统其实发出了报警邮件，但上周微软大规模服务故障导致邮件未送达，工作人员没能及时发现。
为什么值得记：这条和本期资讯第 1 条是同一个道理的两副面孔——**你的告警链路依赖别人的服务，别人的故障就是你的故障**。把「报警有没有真的送到」当成一条可验证的链路去测（而不是假设它通），比再加一块监控面板有用。做日报/抓取自动化的人尤其该自查：任务失败时通知走哪条路、那条路失败时谁通知你。

源：德国 WDR /ainewslog 11/16 汇总，11/15–11/16

**5. 韩国税务师考试「状元」承认用微型摄像头拍题发给 AI，160 道只错 1 道**
来龙去脉：11/16 前后曝出，一名在税务师考试中成绩异常拔尖（160 题仅错 1 题）的考生，承认用微型摄像头把考题传出、交给 AI 作答。意义不在作弊手法，而在它第一次把「AI 让标准化考试的区分度失效」变成了可举证的个案——不是理论风险，是已经发生的成绩。
判断：凡以「标准化试题」做筛选的场景（考试、认证、笔试题、AI 面试），接下来都要重估有效性。招人/被招同理：能联网的笔试题，等于开卷。

源：ainewslog 每日 AI 汇总，11/16

## 三、潜在挣小钱的机会

**1. 给纹身师做 AI 转印：$48.8k MRR，单订阅约 $28/月（TrustMRR 核实，11/14）**
路径：纹身师上传一张参考照，产品转成可直接打印的线稿（stencil），按月订阅。核实口径：MRR $48,800、平均每订阅约 $28/月——是多数消费级 AI App 的数倍。为什么能收这么贵：它卖的是「干活工具」不是「玩具」，纹身师一天要用十几次，线稿质量当场就能判断好坏。可复制公式写得很清楚：**挑一个有「慢且重复的一步」的行当（纹身描线、代账做表、外贸单证、装修出图），把图像/文本模型包成那一步的专用工具，按工作工具定价而不是按玩具定价。**
⚠️ 护城河是手艺不是模型——纹身师对线条质量零容忍，同赛道已有 Ghostline、Procreate 工作流和免费转换器。模型那部分谁都能做，剩下的是对那一步的偏执。
源：theaireceipts.com（TrustMRR 核实），11/14

**2. 苹果库存监控：448 家店每 5 秒扫一次、2 秒推手机，$16,680/月（约 11.8 万元）**
路径：填上想要的颜色和容量，它替你盯 448 家苹果直营店（25 国）的提货库存，有货 2 秒内推手机。定价三档：$5/月守 2 条、$10/月守 5 条、$20/月守 10 条。上线一个月 2,215 个付费用户、$16,680/月，累计发出 98,847 条通知，ARPU ≈$7.5/月。值得抄的设计还有一个：第一周一条通知都没收到全额退款——卖方自己承认价值只在「有没有货」那一下。
判断：本质不是软件，是**比售罄早两秒的信息窗口**。它踩中「付费意愿三条」的全部：已有人工方案（自己一家家店点）、场景极窄、愿为省时间付钱。同样的形状国内现成可搬：茅台、球鞋、演唱会回流票、显卡首发、医院号源——缺的不是技术，是「盯哪 448 个页面」。
⚠️ 单源自述案例（阿里云开发者社区 OPC 系列第 64 篇），具体上线日期未披露；平台反爬与 ToS 是长期风险。
源：阿里云开发者社区，日期未披露

**3. AI 测身高：周订阅 $5、百万用户、$10 万/月（约 70 万元）**
路径：输入父母身高、现在身高、年龄、发育阶段四个数，输出预测区间，再配一张「今天该睡几小时、吃什么、拉伸哪几组」的打卡表。基础功能免费，解锁全量按周付 $5。英文市场为主，商店页自述「一百万人在用」、6.8K 条评分 4.6 分。月入约 10 万美元（≈70 万元人民币）。起步方式比产品更值得抄：他先在挂售小生意的网站看到同款 App 标价 2 万美元——「有人靠这件事收过钱」本身就是需求验证；再去短视频评论区翻「我 15 岁一米八，我爸一米七我妈一米六」这类自报数据，几千条白送的问卷。上线第二天出第一单。
判断：周订阅是把「一次性焦虑」变成「持续付费」的关键设计——身高这件事没有终点，只有下周再量一次。
⚠️ 单案例自述（阿里云开发者社区 OPC 系列第 65 篇），日期与留存数据未披露；「预测身高」类产品的医学声称在多数市场需免责声明，先看当地广告法。
源：阿里云开发者社区，日期未披露

## 四、小而美产品

**JuliusBrussee/caveman（主推·把 agent 的嘴缝上，省 65% token）**
- 是什么：刻意写成「山顶洞人说话」的 skill + 本地 proxy。skill 管输出（去掉铺垫和客套，压 50–65%），proxy 管输入（把日志、JSON、diff、测试输出先压 30–90% 再喂给模型）；支持 30+ 编码 agent（Claude Code、Codex、Cursor、Windsurf、Gemini CLI、Aider、OpenCode 等），一条命令装。119,655 stars、11/15 日增 +227
- 差异化：**永远不压代码、命令、路径、报错**，只压自然语言，原文全存本地 SQLite 可还原；JetBrains 用 86 个真实编码任务实测「无可测质量变化」（p=0.82）；另有 pixel 模式把 skill 页渲染成图片再省 61%
- 用在哪：直接对着你的账单——日报抓取、长会话调试、日志分析这类「输入远大于输出」的批任务，先开 lite 档跑一周看实际省多少；配免费/低价档模型能把「重试次数」的成本一起压下去
- ⚠️ 每轮多 1–1.5k 输入 token，极短任务净亏；ultra 档压太狠影响可读性；skill 是 MIT、proxy 是 BSL-1.1（源码可看、一方使用免费，2030 年转 Apache-2.0），商用分发前看清许可
- 源：quidproquo 11/14 日报 /mcpagentsmarket /GitHub，11/14–11/15

**backnotprop/plannotator（主推·agent 审阅台，把人塞回循环里）**
- 是什么：本地跑在浏览器里的审阅面，通过 plugin / hook / slash command 挂进 Claude Code、Codex、Copilot CLI、Gemini CLI、OpenCode、Kiro。agent 一提计划（Claude Code 是在 ExitPlanMode 那一刻）、一交 diff、一出一份 HTML，浏览器自动弹出，你划词、划掉、行内批注，再一键把结构化反馈送回 agent 当下一轮输入。约 1.1 万 stars、11/15 GitHub 日榜第一，Apache-2.0
- 差异化：不生成、不推理、不当 orchestrator，只做「不让 agent 的产出把你淹掉」这一层；三块界面分别收 Inbox（多 agent 待你决策的事）、Artifacts（计划/规格/HTML）、Code Review（本地改动或远端 PR），代码评审侧支持 Git / GitHub / GitLab / GitButler / Jujutsu / Perforce——多 VCS 这条比同类实在
- 用在哪：你的痛点很具体——子智能体一次给你四份日报草稿、三份脚本 diff，终端里根本没法指「第三段第二句不对」。丢进浏览器划完再回传，比在终端敲一长段自然语言描述准得多
- ⚠️ 依赖 agent 支持 hook（非阻塞投递要 Claude Code 2.1.287+）；Windows 走 PowerShell 安装脚本，装前确认 hook 路径没被中文用户名卡住；数据默认留本机，主动分享才出网
- 源：reporadar 11/15 日榜 /corpusiq 安装文档 /GitHub，11/14–11/15

**Tencent/LoopForge（备选·自托管多 agent 交付流水线，带人工审批闸）**
- 是什么：Go 写的自托管 coding-agent 工作流编排，用脚本串起 CodeBuddy、Codex、Claude Code 依次干活，关键节点插人工审批闸；11/15 GitHub 日增 +33
- 差异化：不做 agent 本体，只做「排队 + 分工 + 闸门」这一层——比 T3 Code/orca 那种并行面板更偏交付流水线，适合任务有明确先后依赖的场景
- 用在哪：日报这种「抓取 → 清洗 → 写稿 → 校对 → 推送」固定链，每步当一个 agent，审批闸放在推送前
- ⚠️ 腾讯出品、非独立开发者；Go 服务要自己运维，先在一台闲置机器上试；项目很新、star 量小、生态未验证
- 源：GitHub Daily 11/15 /CSDN 11/15 日榜
