**1. OpenAI 发 GPT-6.2 Astra / Sol：旗舰降到 $8/$40，首个达「自我改进 High 档」的对外模型（P0·价格）**

11/17（美东）发布，抢在 Anthropic 定价前一天。Astra 定位最难项目，$8 输入 / $0.40 缓存输入 / $40 输出（每百万 token），比 GPT-6 Astra 的 $10/$50 降 20%、缓存降 60%；Sol 面向日常任务，$2 / $0.10 / $10，与上代同价。官方口径：Astra 在 Agents' Last Exam 比上代 +5.2 分、单项任务成本不到上代 1/3；比 Claude Fable 5.2 高 5.5 个点、单项任务成本约为其 5%。FrontierMath Erdős 未解难题 68 道解出 7 道（前纪录 3 道）。系统卡把 Astra 的「AI 自我改进」定在 High 档——OpenAI 首个对外发布达该档的模型；两款均触及网络安全 Critical 档，官方承认加严防护会限制部分正当漏洞研究。

第三方不一致的部分要一起看：Artificial Analysis 智力指数把 Astra 排第二（在 Fable 5.2 之后），但 Coding Agent 指数显示 Astra 与上代持平、Sol 反而降 3 分；在刻意挑选的难题上测得幻觉率 59%（官方注明不代表日常）；Vals AI 法律研究榜 Astra 只排第 30。

判断：能力没跃升，价格是真降。这次卖的是「同分更便宜」，和 11/16 阿里腾讯的动作是同一个方向，只是口径从「单任务成本」换回了 list 价。

做法：把日报的写稿段从 GPT-6.1 Terra 换到 GPT-6.2 Sol 跑一天对比。Sol 在 FrontierCode 2.0 只落后 Astra 0.5 个点、单任务成本约 1/5，「结构化输出 + 改写」这类活用它就够。

⚠️ 缓存输入的命中条件与有效期官方未细化；「成本不到 1/3」是自家基准口径，不是 list 价折算。

**2. 微软 Ignite 一次发七款自研模型，MAI Code 2 单任务 $0.309 vs Opus 5.5 的 $6.306（P0·工具链）**

**7. 新华社给 AIGC 收入定性：登记与不登记，同一笔钱到手差一截（P0·跟你业务直接相关）**

11/17 新华社采访财税专家，给出两条判定线。未在市场监管部门登记个体工商户或个人独资企业、收入主要依赖个人技能与劳动 → 按「劳务报酬所得」或「特许权使用费所得」计税；已登记个体工商户或工作室、有固定经营场所与雇佣人员且持续经营 → 按「经营所得」计税，与生产经营有关的合理支出可扣除，但须取得合法有效凭证。

平台侧：平台支付创作分成或服务费时是扣缴义务人，必须依法代扣代缴；以「创作者是独立经营者」为由不代扣，或只对部分收入代扣，均属违法。自《互联网平台企业涉税信息报送规定》施行后，平台内经营者收入数据已全面纳入监管。

被明确点名的违规做法：注册多个个体户或「空壳」工作室，把本应属于劳务报酬的收入转成经营所得、违规适用核定征收——与主播「转换收入性质」偷税同性质。

跟你业务直接相关：分账、代工、定制费是三种收入、三种税目。工作室已登记与未登记，同一笔钱到手差一截。

做法：这周先确认一件事——你们收分账和代工费的主体是个体户/工作室还是个人。若是个人，接单前先算清代扣后的净额，别拿含税报价去谈成本。

⚠️ 专家受访口径，非税务总局正式文件；各地核定征收政策差异大，落地以主管税务机关为准。

源：新华社 /网易财经，11/17

**8. 平台补贴从「普惠」改「阶梯」：AI 内容要备案、片头标识、凡播必审（P1·跟你业务直接相关）**

澎湃 11/17 梳理行业：多数平台已把 AI 内容扶持从普惠式补贴改成按质量分级的阶梯奖励，资源向原创成片集中；AI 内容须完成备案、片头做标识，纯流水线低质内容收益被压缩，真人 + AI 融合方向普遍受鼓励。11/5 广电精品创作大会微短剧论坛上，监管要求各平台「凡播必审、全量人审」。

供给侧数字：2026 上半年抖音新增 22.19 万部 AI 剧，仅 1.3% 跨过 5000 万播放的盈亏参考线；9 月新剧中 1.46% 拿走 64.6% 的播放增量，82% 新剧当月播放不足 100 万。

判断：补贴从「给所有人发钱」改成「只给好内容加价」，本质是供给过剩后的库存清理。产量占比不等于观看量，更不等于收入占比。

做法：把「备案编号 + 片头标识」做成出片模板里的固定字段，别再靠人工补。同时用 1.3% 这条线反推立项——如果单集成本不支持「一个月内做到 5000 万播放」，就不该按分账模型立项。

⚠️ 平台政策来自行业媒体梳理，各平台细则不同，以各自后台通知为准。

源：澎湃新闻 /央广网 /行业媒体梳理，11/16–11/17

**1. 英伟达董事会当场否决黄仁勋复职，而他前一天刚说「愿意回来」**
来龙去脉：11/12 黄仁勋因「个人行为违反公司准则」辞任 CEO；11/17 财报电话会开场，新任董事长哈维·琼斯即表示董事会一致接受辞呈、无意让其回归。同日黄仁勋发声明，称若董事会允许，愿重返公司担任 CEO——这是他 11/12 辞职以来首次公开谈复职。董事会另宣布新设「国家安全与出口管制监督委员会」。股价本月累计跌约 24%，较 10 月历史高点跌超 35%，财报后盘后反弹 4–5%。
判断：这是继任程序问题，不是业绩问题。业绩越好，越说明「人」不是不可替代的那一环——但市场给的 24% 折价说明它暂时还不信。
跟你业务直接相关：这类治理事件的定价逻辑可以直接借用——当一家公司的估值里有一部分是「创始人溢价」，这部分溢价消失时，业绩超预期只能让它变窄，不能让它回来。

**2. 苹果服务大规模中断：内部系统更新引发，不是攻击**

**3. 「123456」第 7 次登顶最差密码榜首，出现 723 万次**

做法：手上所有对外服务（对象存储、后台、数据库面板）这周过一遍：有没有开 MFA，有没有把管理端口暴露在公网。

源：NordPass 报告（经腾讯新闻早报），11/17–11/18

**4. 冒充小米汽车发「召回」诈骗短信，小米已取证**

## 三、潜在挣小钱的机会

**1. PlugKit：让 AI 直接管社媒发布，单人做到 $8,039 MRR（Stripe 验证，11/17 更新）**

路径：不做新后台，把 Instagram、TikTok、YouTube、Facebook、X、LinkedIn 接成一个 MCP 服务，用户在自己已有的 ChatGPT 或 Claude 里下指令——改 reel、排期发布、回评论和私信、读数据。卖点是「没有新面板要学」。

报价：Creator $49/月（年付 $490），Pro $97/月（年付 $970），7 天免费试用。月收入换算：$8,039/月 ≈ 5.7 万元（按 7.1 折算），年化约 $96,468；单人运营，2026 年建。

为什么这个位置能收钱：社媒运营的痛点是「平台太多、每个后台都要学」，而 AI 已经坐在用户面前了。把工具做成「AI 的一个能力」而不是「又一个 SaaS 后台」，省掉的是迁移成本。

⚠️ 收入经 Stripe 验证，但验证的是收款不是留存；产品 100% 依赖六家平台的开放接口与政策，任一平台收紧就断一条收入线；MCP 生态本身还在变。

源：profitable.app 企业页（Stripe 集成验证），11/17 更新

**2. AI 漫剧只接单点工序：分镜 30–80 元/集、角色套图 150–400 元/角色（报价表口径，C 级源）**

路径：不接整部剧代工（那条路已经从年初 5000 元/分钟跌到 200 元/分钟甚至几十元），改接单点工序——分镜脚本、角色一致性套图、配音，按件计价，交付物是文件不是成片。整剧代工仍有一档：精品漫剧每集 1000–2000 元，差别在分镜设计与剪辑节奏，不在会不会用工具。

报价：分镜脚本 30–80 元/集；角色一致性套图 150–400 元/角色；配音 20–60 元/集。月收入换算（按单价 × 产能推算，非实测）：一天 4 集分镜、一周 20 集 → 600–1600 元/周，约 2600–6900 元/月；若叠加角色套图（一周 3 个角色）再加 1800–4800 元。

⚠️ 这是市场测试价不是收入承诺：上半年至今代工价跌了约 96%，抽卡算力占成本 30–50%，客户改一轮就把利润吃光。源为行业自媒体报价表（C 级），腾讯云开发者社区的分析（B 级）给了价格坠落曲线佐证。

源：AiToollab 报价表（C）/腾讯云开发者社区（B），11/07

**3. AI 短剧定制镜头包装：800–2500 元/支，算力成本 30–50 元（单价有据，成交价未披露）**

路径：只接「整集镜头包装 / 高难度特效镜头替换 / 老片画质修复」这一段，3–5 分钟整集或单个镜头，周期 2–3 天。上游是各家的视频模型（可灵、即梦、海螺、Runway），中间的手艺是「抽卡能出可用镜头」+「镜头衔接不跳」。

报价：800–2500 元/支。月收入换算（推算，非实测）：一周 2 支 → 6400–20000 元/月。成本侧参考：一条 150 元的 20 镜头片子，素材生成消耗 30–50 元算力（行业抽卡率 3–5 次才出一条可用镜头）。

判断：这个价位能站住，不是因为技术难，是因为「客户自己重拍一条更贵」。你卖的是返工能力，不是生成能力。

⚠️ 客户反复改分镜会直接吃掉利润，合同里必须写「含 1 次免费微调」；算力是预付款，接单前先估算抽卡次数。单价来源为行业整理文（C 级，日期未披露），无公开成交样本。

源：技能提升网行业报价整理（C）/腾讯云开发者社区（B），日期未披露

## 四、小而美产品

**heygen-com/hyperframes（主推·把 HTML 渲染成确定性 MP4，专为 agent 写的视频引擎）**
- 是什么：开源框架，用 HTML + CSS + 可寻址动画（GSAP / CSS / Lottie / Three.js / Anime.js / WAAPI 任选）定义视频，渲染器在无头 Chrome 里逐帧 seek、FFmpeg 编码，**同一输入必然产出同一视频**。85,987 stars、Apache-2.0、最新 v0.9.65（11/17）；配 CLI、约 450 个现成组件（转场/字幕/图表/地图/3D/运镜）、AWS Lambda 分布式渲染，还有一套 agent skills（`npx hyperframes skills update` 后让编码 agent 直接出片）
- 差异化：与 Remotion 同样走「无头 Chrome + FFmpeg」，但赌的是**纯 HTML 而不是 React 组件**——没有构建步骤，`index.html` 直接能播。对 agent 这一层差别很大：agent 本来就会写 HTML，不用先学一套组件体系。另有一个 `frame.md` 设计规范，把品牌 design token 反转成「给镜头用」的版本，agent 不用猜尺寸
- 用在哪：短剧/漫剧的**片头片尾、竖屏字幕条、榜单卡、集数角标、批量模板化包装**——这些以前要人拉 AE 模板，现在写成 HTML 组件后一条命令跑全季。也可做投放素材的批量版本（同一套版式 × 20 个标题）
- ⚠️ HeyGen 公司出品，不是独立开发者项目（这点如实标注）；它渲染的是「图形 + 已有素材」，不生成画面，AI 镜头仍要靠视频模型；4K 长片在 16GB 内存的本子上会很慢，建议用 Lambda 渲染路径；Pro 级 skill（reverse-any-video、style-sampling）要订阅
- 源：GitHub heygen-com/hyperframes /hyperframes.studio（11/18 实测 star 数与版本），11/17

**mvanhorn/last30days-skill（主推·让 agent 自己去 Reddit / X / YouTube / HN / Polymarket 做带出处的调研）**
- 是什么：一个 AI agent skill，给一个话题，跨 Reddit、X、YouTube、Hacker News、Polymarket 与网页抓最近 30 天的讨论，再合成一份带出处的结论。69,046 stars、6,144 forks、MIT，2026/1/23 建仓
- 差异化：多数「AI 调研」是让模型回忆训练数据，它走的是「先去现场抓」。Polymarket 这一路尤其少见——预测市场赔率是当下唯一能量化的「群体预期」，比任何观点文都硬。带出处这一点决定了它能不能进正式报告
- 用在哪：日报的「潜在挣小钱机会」段现在是人工搜，改成先让它跑一遍过去 30 天的讨论，再由人筛；也可用于「某个题材最近在海外被怎么讨论」——短剧出海选本子时用它看 Reddit / YouTube 的真实反应
- ⚠️ 个人项目（非公司），依赖各平台公开接口，抓取量一大就会被限流或改接口；输出质量取决于 agent 的归纳能力，引用链接必须自己点开验一遍再进正文
- 源：GitHub mvanhorn/last30days-skill（11/18 实测），11/18

**cloudflare/security-audit-skill（备选·给编码 agent 装一个分阶段安全审计技能）**
- 是什么：Cloudflare 开源的编码 agent 技能，做多阶段安全审计，产出**可独立验证、机器可读**的发现（findings），而不是一段散文式的「建议加强安全性」。74,784 stars、MIT
- 差异化：审计结论机器可读这一点是关键——它能进 CI、能比对两次审计的差集，也能被另一个 agent 复核。多数安全类 skill 只给建议，不给可复现的证据链
- 用在哪：给「agent 写的代码」做上线前闸门。你们现在让 agent 写脚本、写小程序云函数，最怕的是它把密钥写死、把管理接口暴露出去——这类问题正好是规则化审计能抓的
- ⚠️ Cloudflare 出品，非独立开发者；只读到仓库描述，具体覆盖哪些漏洞类别、是否要联网、误报率如何均未核实；安全审计工具本身要给高权限，跑之前先看清它读什么、传什么
- 源：GitHub cloudflare/security-audit-skill（11/18 实测），11/18
