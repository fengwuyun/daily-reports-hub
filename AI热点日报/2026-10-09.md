## 一、AI 资讯

**1. 端侧多模态嵌入开源：Google EmbeddingGemma 2（10/6 发，10/8 集中报）｜OPC / local-first**
- 740M 参数，Apache 2.0，把文本/代码/图/视频/音统一映射进 768 维共享空间；端侧可跑：全量约 567MB RAM，纯文本版 191MB（Pixel 11 Pro 实测）。权重已上 HuggingFace + Kaggle。
- 价格：免费开源，自托管成本≈电费。
- ⚠️ 端侧推理要 NPU / 足够 RAM，笔记本跑纯文本版更现实；做「图+文」搜本地素材库才显价值。
- OPC 视角：你本地优先栈多了一个检索底座——短剧素材库、报表、笔记的本地语义检索不用再上云 embedding API，数据不出机。
- 来源：unite.ai 10/8；blog.google 10/6；aiimpacthub 10/8

**2. Liquid AI 开源两款「只给判断、不吐文字」的小模型（10/8）｜OPC / local-first**
- 3B 版读图文、600M 版还能读音频，一次前向直接出结构化判断（分类 / eligibility / triage），不做生成。
- 价格：免费开源权重。
- OPC 视角：本地「决策层」补齐——你 agent 的「看截图→判状态→触发动作」可以跑在本地小模型上，不把操作权交给托管决策 API；和 10/8 日报的 HF D1 / OpenAI Decisions API 是同一思路的本地版。
- 来源：aitop.news 10/8 日报；wire.rundatarun.io 10/8

**3. Perplexity 发 Decider v1.1 决策模型 + 9B/0.6B 搜索嵌入（10/8）｜OPC 工具**
- pplx-decider-v1.1-27b 把 Jev Decision Index 从 56.4 拉到 61.56（高于同 backbone 的 57.9）；另发 9B / 0.6B 搜索嵌入模型给 agent 检索用。
- ⚠️ 托管 API 价未披露；权重开放可自持，本地跑决策/检索两件套成本≈0。
- OPC 视角：决策模型多一个比对项，和 OpenAI Decisions API（$0.10/M）做「强模型规划 + 小模型决策」双档路由时多一个选择。
- 来源：wire.rundatarun.io 10/8；huggingface.co；aitop.news 10/8

## 二、热点梗 & 热点新闻

**1. 「门诊告示豆包诊断患者改问千问」**
- 来龙去脉：10/8 凌晨热搜 #1，一张门诊告示显示患者先用豆包做医疗咨询拿到错误诊断，随后改问千问。截图在医患群和微博扩散。
- 为什么火：戳中「AI 问诊到底靠不靠谱」的全民焦虑——大模型当医生用，出错成本极高，和「AI 不能替代医生」的共识共振。
- 跟你业务相关：你做 AI 内容生产/投放，这类「AI 翻车」案例是素材可信度警示——给用户的文案/数据别让模型背书包，口径要人审。

**2. 「薄肌理论 / 大水理论 / 大睡理论」**
- 来龙去脉：10/8 热搜 #6「薄肌理论」与「大水理论」「大睡理论」同屏爆火。薄肌=低体脂、有线条、不追求壮硕；大水=足量白水、拒含糖饮料；大睡=保证充足睡眠。三者被概括为「低成本高回报自我管理三件套」。
- 为什么火：打工人用最低成本对抗亚健康，反「精致健身/贵价养生」叙事——不办卡、不买补剂，先喝水睡觉练线条。

**3. 「西西弗书店是如何盈利的」**
- 来龙去脉：10/8 热搜 #1（118万热度）。书店扎根商场，图书销售占营收七成以上，再搭矢量咖啡、不二生活文创拉高整体毛利；连锁规模带来议价优势，并向商场拿到租金优惠。
- 为什么火：在「实体书店必死」叙事下，它靠「图书引流 + 文创毛利」活下来，成了商业模型讨论样本——流量入口不赚钱，后端变现才赚钱。

## 三、小而美产品

**主推 1 ｜ LosslessCut**
- 是什么：开源无损视频裁剪/切割/合并工具，Windows 原生，基于 ffmpeg，不重新编码，切哪段留哪段。
- 差异化：无损=画质零损、速度快（只改容器不重算像素）；比剪映/PR 轻，专做「粗剪 + 切片」。
- 具体用在哪：短剧素材粗剪、按镜头无损切片、导出多分辨率，出海分发前预处理——和 9/29 推的 HandBrake（压码）互补：HandBrake 压、LosslessCut 切。
- 偏差：社区开源项目非单人作品，但免费 MIT、数据不出机、本地跑。
- 来源：github.com/mifi/losslesscut（开源经典，本日报 9/23 起未收录）

**主推 2 ｜ Lumina**
- 是什么：AI 视频剪辑工具，不「从零生成」，而是按你的脚本建议镜头语言、匹配 BGM 情绪，把已有素材按专业逻辑重新组装。
- 差异化：反「年货级 AI 生成」（剪出来看两秒想关），走「帮你把库存素材剪专业」路线，瞄准专业内容团队效率。
- 具体用在哪：短剧宣发/投放素材精剪——你有一堆拍摄/生成素材，用它快速出多版投放短片，少请剪辑。
- ⚠️ 偏差：平台/收费未核实（疑似 SaaS 订阅），偏专业团队非纯个人；业务强相关但先试用再决定。
- 来源：今日头条 10/6《刷完 Product Hunt 前十，我发现 AI 创业圈正在换血》

**备选 ｜ Spira AI**
- 是什么：自主 AI 网红 + 成品短视频——脚本粘贴进去，自动选主播、切 B-roll、加字幕音乐，一张照片 + 一段语音克隆人脸声纹。
- 具体用在哪：投放宣发批量产短视频，尤其多语区（你 FB/TikTok/YouTube 多语投放）快速铺量。
- ⚠️ 偏差：SaaS 订阅（首发月 5 折），非免费买断/数据自持；人脸克隆有合规红线——仅作备选并警示，商用前先过合规。
- 跟你业务相关·AI 内容生产/投放，但合规优先于效率。
- 来源：openaimaster.ai 10/4–6 PH 周榜盘点
