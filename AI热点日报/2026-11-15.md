## 一、AI 资讯

**1. 英伟达 100 亿美元领投 Anthropic 260 亿美元私募配售：七家芯片与云厂商集体锁筹（P1）**

11/15 披露：Anthropic 这笔 260 亿美元私募配售（按 IPO 发行价买无投票权 Class N 股）由英伟达领投 100 亿美元，其余由 AMD、博通、谷歌、美光、微软、台积电分摊。同一批文件里 TSMC 的另一笔 10 亿美元（OpenAI 与 Anthropic 各 5 亿，11/10 董事会批准）也在推进。

判断：这不是财务投资，是资产负债表互相绑定。芯片厂买自己最大客户的股权，客户的订单又回到芯片厂的收入里——「循环融资」的规模已经大到让「真实需求有多强」这个问题越来越难独立回答。Hacker News 上「英伟达是否在资助自己的需求」的帖子当天破千分，讨论的核心就是这个。

⚠️ 260 亿是七家合计的私募配售口径，不是 Anthropic 的新增融资总额；各家的具体持股比例未披露。

源：aitoolsrecap 11/15 /彭博 /Ars Technica 转述，11/15

**2. Anthropic IPO 超额认购 6–7 倍：两个口径并存，11/18 定价、11/19 挂牌 ANT（P1·增量）**

数字冲突，并列不裁。发行结构已于此前披露：8.25 亿股 A 类、$70–78 区间、代码 ANT。本次新增的是认购与组合口径——彭博（经 Techmeme 转引）11/15 称获约 **7 倍**超额认购，Anthropic 及部分投资方拟通过 IPO 与一笔单独私募合计募资最高 **904 亿美元**；财联社 11/15 口径为约 **6 倍**，叠加超额配售与约 260 亿美元私募，「整体融资最高约 1000 亿美元」。定价 11/18、挂牌 11/19，两源一致。招股书披露 10 月底年化营收约 81 亿美元，比 9 月底增加约 10 亿。

⚠️ 904 亿与 1000 亿不是同一件事（后者含超额配售），也都不等于公司到手现金（部分为老股东出售）。以最终发行文件为准。

判断：真正的信号不是倍数，是「IPO 窗口还开着」——这决定一大批 AI 公司未来 6 个月是融资还是缩表。

源：彭博（经 Techmeme）/财联社 /CNBC，11/15

**3. GPT-5.6 Sol 全线涨价 10%：$4/$20 → $4.40/$22，价格战第一次反向（P0·价格）**

价格追踪站 11/15 检测到 GPT-5.6 Sol 三条价目同时上调——输入 $4.00→$4.40、输出 $20→$22、缓存输入 $0.40→$0.44，涨幅均 10%。同日 Particle-1 输入 $0.05→$0.06（+20%）。这是这一轮价格战里少见的「旗舰反向涨价」：过去两周主线一直是降价，现在头部档位开始往上补。

判断：不要当孤立事件看。它和 11/13 那期报的「7 天 478 次降价 vs 423 次涨价」是同一件事的两面——便宜的在探底，贵的在上抬，中间档被两头挤。对按 token 计价的调用方，成本结构会从「选最便宜」变成「按任务分层」。

做法：把调用按任务分级重跑一遍。高频重复子任务（分类/抽取/格式转换）继续压最便宜档；只有「一次做错就要重来」的活留给旗舰。

⚠️ 涨价是否扩散到套件内其他档位，官方价目页未见说明，未披露。

源：Tokenando 价格变更日志，11/15

**4. 7 天 110 次调价、24 个新模型、16 个下线：两个模型归零、GLM 5.3 单日 +157%（P0·价格）**

价格追踪站 11/15 更新：最近 7 个记录日累计 110 次价格变动、66 次幅度超 20%；新增 24 个模型、下线 16 个，7 天每天都有变动；当前追踪 824 个模型、输入价中位数 $0.400/M。极端值：Particle 1 两档（$0.05 / $0.50）11/13 归零免费；文心 5.5 Flash Preview 两档（$0.28 / $1.13）11/12 归零免费；GLM 5.3 从 $1.40 跳到 $3.60（+157.1%，11/13）。

⚠️ 归零的是聚合渠道挂点，不是官方刊例。上一期判定「Kimi K3.1 Pro 的 -88% 是第三方挂价」在 11/14 被反向验证：挂点从 $0.237 弹回 $0.700（+194.7%）。同系列三个变体名（V4.1 Flash / 1017 / Flash Latest）7 天内出现 5 次反向跳动，绝对值在 $0.011 到 $0.567 之间来回——这个幅度不是定价，是通道在抖动。

看价格必须分三层：官方刊例（唯一可信）、聚合站挂点（随时回弹）、免费/试用通道（随时关）。把价格写死在模型池里的代码，这一周应该已经挂过至少一次。

源：toolsummary.com/changes（11/15 更新）/costperprompt 模型页，11/15

**5. OpenAI 把 ChatGPT 同时改成店铺和钱包：认证商家主页 + Business Agents 广告位 + Wallet 代付（P0·变现·跟你业务直接相关）**

两条同步推。①ChatGPT 内上线**认证商家主页**与品牌提及追踪，并开放新广告位「Business Agents」——符合条件（先美国）的企业可购买，让自家 agent 在 ChatGPT 里承接用户请求。这是 ChatGPT 从「聊天窗口」变成「店铺 + 发现面」最直接的一步。②**ChatGPT Wallet** 上线，让 agent 在 ChatGPT Work、Codex、dots 里完成购买，逐单需用户授权、沿用原有卡的消费者保护。合起来是完整闭环：找到商家 → agent 谈 → agent 付。

跟你业务直接相关：短剧/漫剧的海外分发一直卡在「投流买量」，这里第一次给出「不买量、靠 agent 被调用」的入口。判断标准很朴素：服务能被一句话说清、能被 agent 调用完成，就有低成本曝光位；纯内容消费（看剧）暂时只是分销渠道。现在能做的只有一个动作——把产品整理成「一句话能调用的能力说明」，等开区。

⚠️ 目前仅美国、需资格审核；广告位与自然推荐如何分栏，官方未披露。

源：AI Weekly /Quadra Daily Briefing /fruition.net，11/14–11/15

**6. 短剧平台净利率不足 1%：头部从卖剧转向卖工具（P0·跟你业务直接相关）**

联合早报 11/15 特稿把利润表摊开——ReelShort 母公司枫叶互动 2025 年上半年净亏损 4651 万元人民币（约 897 万新元）；点众科技公开表示短剧业务净利率不足 1%。同篇给出产能侧硬数：OpenRouter 上 10/26 当周，字节、阿里、快手、MiniMax 四家中国视频模型合计吃掉该平台 API 请求量的 46.4%，字节 Seedance 系列以 26.1% 居首；字节 PineDrama（免费+广告、靠 TikTok 引流）9 个月下载破 1 亿、日活约 700 万。转折点在这里：头部开始从「做剧给人看」转向「教人怎么做剧」——中文在线、酱油文化等把「保人物一致 + 统筹生成」的工作流与 agent 打包对外。

判断：净利率 <1% 说明投流买量的钱几乎全被渠道拿走，内容本身不再是利润中心。对一人/小团队是好消息——**平台赚不到的钱正在往工具层转移**，而工具层的客户是同行，不用跟平台抢流量。

建议：别跟平台比产能（人家月更 800–1287 部），去做「一部剧从剧本到多语版本」里最脏的那一步，做成能卖第二遍的模板/工作流。

源：联合早报（含 OpenRouter 数据引用），11/15

**7. Claude for Manufacturing 上线：17 个技能 + 4 个连接器，企业版免费（P1）**

**8. Cloudflare 开源 Kitesurf 浏览器引擎；Antigravity 上线云端 Remote Agents（P1·开源/工具）**

**9. 张一鸣内部讲话：字节追平前沿最早要到 2029–2030 年，预训练数据是核心瓶颈（P1）**

## 二、热点 & 梗

**1. 苹果首款智能眼镜代号 N50 曝光：卖点不是硬件，是 Siri 替你点 App**
来龙去脉：彭博记者 Mark Gurman 11/15 的 Power On 通讯披露，苹果首款智能眼镜内部代号 N50，外形接近 Ray-Ban Meta Wayfarer，预计 2027 年上市；核心体验是让 Siri AI 代替用户在第三方 App 里完成操作——第三方 App 不会跑在眼镜上，而是通过 iPhone 与 Siri AI 的应用集成被调起，苹果已要求开发者为此做准备。
判断：这是一个方向性选择——把可穿戴的差异化押在「语音调起 App」而不是往镜腿里堆硬件。对开发者意味着：未来两年值得做的事是「让我的服务能被一句话调起」，而不是「做一个眼镜 App」。和本期第 5 条（ChatGPT 的 Business Agents）是同一枚硬币。

源：Bloomberg Power On /Digital Trends /AppleInsider，11/15

**2. 深圳水贝金价单日跌约三分之一：1 公斤金块从 120 多万降到 80 多万，商户说「还没睡醒客人就要买金」**

判断：金饰的工费溢价和投资金条的保值逻辑要分开算——一个是消费品，一个是资产，同一个「跌」字对两者的含义完全相反。这类「抢购」新闻每年都会出现几次，值得记的是它的传导顺序：价格先跌 → 客流后到 → 加工费先涨，等的就是这个时间差。

**3. Hacker News 千人吵「英伟达是不是在资助自己的需求」**

## 三、潜在挣小钱的机会

**1. 88 天从 0 到 $10,400 MRR 的完整账本：成本项精确到 $25（作者自述，日期未披露）**
路径：一款开发者工作流 SaaS，无外部资金，88 天做到 $10,400 MRR。账本给得很细——第 1 个月开发 + 基础设施只花 $85（Cursor Pro + Claude API $60、Cloudflare/Vercel/Supabase $25），靠 37 份 $50 的预售 lifetime pass 收 $1,850；第 2 个月公测上 X 与 Product Hunt，164 个用户 @$30/月 = $4,920，推理成本 $182、支付手续费 $265；第 3 个月 280 个用户 + 5 个团队年费 @$400 = $10,400，成本合计 $885。**真正值钱的是验证顺序**：先发一段 45 秒的 Figma 原型屏幕录像到社交媒体，配一个折扣预售价，48 小时拿到 37 笔真实付款，才开始写代码。
判断：这套流程对一人开发者的意义在于「把风险前移到收钱那一刻」。他唯一提到的操作失误也很具体——第一天没做数据库连接池，Product Hunt 流量峰值直接把 serverless 函数打到超时。
⚠️ 作者自述账本（个人博客，标注 2026 年），收入未经第三方核实；成本项不含自己的时间；Product Hunt 首日流量不可复制。
源：sachinsharma.dev，日期未披露

**2. 把「人物一致性 + 多语版本」做成可交付的服务（报价未披露）**
依据是两条硬数据的交叉：OpenRouter 上 10/26 当周，中国四家视频模型的 API 请求量占比 46.4%，说明「换镜头人物就变」这件事是全行业的共同痛点；同一天联合早报证实头部平台已把自家工作流打包对外卖。这说明需求侧已经在付费，只是目前只有平台在卖。
做法：不做整部剧，只做「一部剧 → 10 个语言版本 + 人物不崩」这一段，按集/按版本计价。你的优势是手上有投流侧的判断（哪个语区值得配），不只是生产能力。
⚠️ 无公开成交价（未披露）；客户是同行意味着账期与压价都比平台难缠；人物授权与肖像合规是硬门槛。
源：联合早报 /OpenRouter 数据，11/15

**3. 夜间闲时档套利：把无时效任务排到 22:00 后与免费通道（单价未披露）**
现在是这类套利最好的时间窗：文心 5.5 Flash 闲时价 ≈$0.56（固定负载口径）、五折活动仍在；Ling-3.2-flash 免费窗口约 11/20 关；聚合渠道还有若干 0 元挂点。做法很朴素——把翻译、批量摘要、字幕、素材审核、历史数据回填这类「没人等着」的任务全部排到闲时 + 免费档跑，白天只跑交互流量。
判断：这不是技术活，是排班活。省下来的比例取决于你的任务结构：无时效任务占比越高，收益越大；纯交互业务几乎吃不到。
⚠️ 免费通道随时关（11/20 是一个已知窗口），别把生产链路挂在上面，要做自动降级；闲时定义的时区与结算规则以官方账单为准。
源：百度千帆价目页 /toolsummary 挂点记录 /Ling 官方公告，11/15

## 四、小而美产品

**dream-num/univer（主推·给 agent 用的 Office 文档引擎 SDK）**
- 是什么：开源的 Office 文档引擎 SDK，覆盖电子表格、文档编辑、协同与文件处理；公式计算引擎、协同编辑冲突处理、文件格式解析这些最脏的活都在里面。描述里明写「for people and AI agents」——设计之初就把 agent 读写文档算进去了。TypeScript，2.5 万+ stars、2,300+ forks，11/15 日增 +490
- 差异化：以前要在自己产品里嵌一个能算公式的表格，要么买商业组件、要么从零啃渲染与计算引擎；它把这一层开源了。对 agent 友好是真差异——多数表格库只服务鼠标，不服务 tool-call
- 用在哪：让 agent 直接生成或改写带公式的周报/数据字典/投放测算表，人在同一个界面里核对；比「agent 吐 markdown 表格、人再粘进 Excel」少两道手
- ⚠️ 是团队/公司在维护，非独立开发者；agent 写表格的权限边界（哪些单元格可写、公式能不能引用外部数据）要自己设，别默认放开
- 源：kongchang.com 11/15 GitHub 日报 /CSDN 11/15 日榜 /GitHub，11/15

**alibaba/open-code-review（主推·确定性流水线 + LLM agent 的混合代码评审）**
- 是什么：Go 实现的代码评审工具，把「确定性流水线」（规则、静态检查、可复现的判断）和「LLM agent」（理解意图、写人话解释）拼在一起，输出行级精准注释；11/15 GitHub 日榜 +893
- 差异化：市面上要么是纯规则（准但死板），要么是纯 LLM（会说人话但漏检、还会编）；它把两者分层——流水线负责「必须抓到的」，agent 负责「解释为什么」，这个分工比单纯「用 AI 审代码」靠谱
- 用在哪：一人维护多个项目时，把它接在 agent 批量改完代码之后、提交之前，行级注释直接落到 diff 上；配 plannotator 这类审阅面正好接住「人说最后一句」
- ⚠️ 阿里出品、非独立开发者；规则集需要按自己的技术栈改，开箱即用的部分有限；Go 服务部署要自己扛
- 源：CSDN 每日 AI 研究简报 11/15 /GitHub，11/15

**GoogleChrome/modern-web-guidance-src（备选·让 agent 跟上最新 Web 规范）**
- 是什么：Google Chrome 团队维护的「现代 Web 最佳实践」源仓库，做成喂给 coding agent 的知识源，让 agent 写前端时实时跟上最新规范而不是吃几年前的训练数据；11/15 GitHub 日榜 +1,231
- 差异化：解决的是一个很具体的老问题——模型的知识停在训练截止日，前端规范半年一变，agent 写的代码经常用已经废弃的写法。它不教模型变强，只给模型一份「当下的正确做法」
- 用在哪：让 agent 出 HTML Demo、投放落地页、报表页时少犯「用了被废弃 API」的错
- ⚠️ 强绑 Chrome 生态，非 Chrome 友好的规范覆盖有限；Google 团队维护，非独立开发者；内容仍在演进
- 源：CSDN 每日 AI 研究简报 11/15 /GitHub，11/15
