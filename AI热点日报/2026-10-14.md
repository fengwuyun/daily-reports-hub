**1. Meta 发布 Muse Wonder：多模态 1M 上下文 agent 模型（10/12–10/13）**
- 变了什么：Meta 在 Meta Model API 上线 Muse Wonder，可接受文本/图像/视频/音频/PDF，上下文 **1M token**，支持可调推理强度，OpenAI-SDK 兼容。官方定价 **$4/M 输入、$0.20/M 缓存输入、$20/M 输出**；订阅版 Muse Wonder Full 暂不开放为通用 API。
- OPC 视角：多 agent 编码、仓库分析、文档 RAG、多模态工具链多了个新选项。先放 provider 抽象后测，别把 Full 档当生产依赖。

## 三、小而美产品（2 主推 + 1 备选）

**主推 1｜Bruno —— 开源 API 客户端（Postman 替代）**
- 是什么：开源（MIT）API 客户端，Git 原生——请求集合存成本地文件、进 Git，不锁云；可接 IDE 和 coding agent，Windows/macOS/Linux 全平台。
- 差异化：集合是纯文本存本地、版本可控、不强制登录；agent 能直接读集合跑接口，和你的自动化取数链路天然契合。
- 具体用在哪：你手上一大把 API（Superset 只读、OpenRouter、各家模型、飞书/邮箱 token）——用 Bruno 统一管理请求与集合，数据留本机 Git，不散落各处。
- ⚠️ 偏差如实标注：Bruno 为独立 OSS 项目（Hello Pixels），非大厂；团队规模未逐一核实，但符合「独立、开源、数据可自持」。
- 来源：https://www.producthunt.com/products/bruno

**主推 2｜Open Analytics —— 开源 AI-Native 网站分析替代**
- 是什么：开源（GitHub）的 AI-Native Google Analytics 替代，可自部署，数据落在你自己的库。
- 差异化：比 GA 更轻、可私有化，agent 能直接查分析数据；自托管=数据不出网。
- 具体用在哪：做完 short-drama 看板外的轻量落地页/小程序站点分析，数据自持、不喂第三方。
- ⚠️ 偏差如实标注：偏 web 分析，与你 Superset 栈有重叠，按需引入；自托管是真运维活。
- 来源：https://www.producthunt.com/products/open-analytics

**备选｜SubtitleGenerator —— 浏览器内 AI 字幕生成**
- 是什么：浏览器里把视频转成可发布级 AI 字幕，一站式出稿。
- 差异化：免装客户端、上传即出字幕，适合快速给短剧/宣发片配多语字幕。
- 具体用在哪：出海短剧字幕（尤其西/葡/法语区）快速出稿。
- ⚠️ 偏差如实标注：浏览器 SaaS，数据自持性未核实，仅进备选；量大或对白敏感时优先本地 WhisperDesktop+人工校对。
- 来源：https://www.producthunt.com/products/subtitlegenerator
