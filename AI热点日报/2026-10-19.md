## 一、AI 资讯（价格与 API 变动排最前）

**1. 【P0】Z.ai 全线调价：GLM 4.7 降 10%，但 Flash 档输入价悄悄涨了 1.5 倍**

⚠️ GLM-5.3 Flash 输入 $0.02→$0.05/M（+150%），输出 $0.75→$0.56/M（-25%）——按 2M 输入+500K 输出算总账约持平（$0.455→$0.48），但输入占大头的负载反而变贵。
成本地板刷新（固定 2M in + 500K out）：GLM-5.3 Flash ≈$0.38 < Haiku 5.5 / GPT-6 Luna ≈$0.45 < DeepSeek V4 Flash ≈$1.20 < GLM 4.7 ≈$2.07（仅 205K 上下文）< Sonnet 5.5 / Sol ≈$9 < Opus 5.5 ≈$18。老提醒：算「每个成功任务」的成本，便宜模型反复重试更贵。

**3. 【P0·OPC 工具】Claude Code v2.1.302：插件系统官方化，云会话可脱离终端长跑**
官方插件仓库上线，新增 JavaScript/TypeScript Mods 定制系统（改 agent 行为不用碰核心），cloud sessions 让编码任务在终端关闭后继续在云端跑完。

**4. 【P0】Perplexity Decider v1.2：不发答案、只出判断概率的 27B 模型**

**6. 【P1】Anthropic 拟融 $600 亿买芯片，次级债票息 10%：AI 债务成本肉眼可见地变贵**

OPC 视角：利率是行业资金面温度计——头部「已盈利」实验室借钱都在变贵，上游成本压力最终会传导到 API 定价，别锁太长的用量承诺。

## 二、热点梗 & 要闻（已过滤娱乐圈/明星/影视）

**1. 「AB 型爸 + A 型妈生出 O 型娃」**
来龙去脉：深圳王先生（AB 型）和妻子（A 型）发现女儿是 O 型，一度怀疑非亲生；医院查出他是罕见 CisAB 血型——A、B 基因挤在同一条染色体上，另一条携带 O 基因，夫妻各传一个 O，孩子自然是 O 型。医生强调 CisAB 不是病，但输血前必须主动告知，否则按普通 AB 型输注可能溶血。10/18 同上百度热搜第 3 与抖音榜单，评论区一半在学遗传学、一半在喊「差点家破人散」——「反转科普」是本周最稳的流量模板。

**2. 「越来越多人不接陌生电话」**
微博热搜第 2（89.3 万热度）。源头是年轻人晒「陌生号码一律不接」的处世哲学：快递放驿站、医院发短信、银行用 App，唯一还在打陌生电话的只剩骗子。连锁反应也真实——错过快递、面试通知、医院回访的吐槽刷屏。对做私域/电销的生意人是明确信号：陌生触达率在崩，能留下的触点只剩「已加微信」和「已订阅」。

**3. 「相亲对象不知道周末的意思」**
微博热搜第 3（66.4 万热度）。源头是一段相亲聊天记录：一方随口问「周末有空吗」，对方回「周末是什么意思」——零售/餐饮轮班岗的年轻人真的没有固定周末。词条变成工时制度大型吐槽现场（大小周、随叫随到），与同日 99 万热度的「比大小周更歹毒的上班方式出现了」同属一个情绪包：休息权成了相亲市场的硬通货。

**4. 吴越质问 AI 冒用身份带货（跟你业务直接相关）**
10/18 凌晨演员吴越发微博：「一觉醒来，谁在利用 AI 肆意抓人替自己作恶？」涉事账号用 AI 模仿她的声音做「明星同款」护肤品带货，话术称「孕妇都能用」，还拼了邓亚萍的画面——视频页面明明标了「含 AI 生成内容」，照骗不误。同类受害者还有温峥嵘（进直播间质疑反被拉黑）。
跟你业务直接相关：这个案例击穿了「标了 AI 标识就能免责」的幻觉——标识只是入场券，素材里的人脸、声音、背书授权才是合规本体。出海素材同理，平台对 synthetic media 的审核在收紧。

## 三、潜在挣小钱的机会（轻资产 · 快速上手优先）

**1. 中老年数字助教 + 便民代办（重阳节点已验证）**
目标人群：社区里不会用智能手机的老人及其子女（付费方常是子女）。商业模型：社区免费「手机课」引流（挂号、视频、缴费、防诈），转按次代办（代挂号、代打印、代查社保，10-30 元/次）+ 小班课时费。案例验证：抖音「中老年手机教学」短视频本周集中爆火、适老化科普广受好评；三部门刚把养老机构分三类收费并推清单制，政策东风在。启动：跟居委会/养老服务站合作，几百元印手册即可开课。

**2. 电商差评应对代办（黑产曝光=需求验证）**
百度热搜曝光职业差评黑产「2700 元搞死一家店铺」，团伙自称已搞死 80 多家店——黑产存在本身就是需求验证。目标人群：被恶意差评困扰的中小电商。商业模型：证据固定（聊天记录、订单、物流线索）+ 平台申诉通道代办 + 恶意买家识别 SOP，200-500 元/单。红线：只做申诉与证据整理，不碰「以恶制恶」。启动：卖家社群挂服务，先免费帮 2 家跑通申诉换案例。

**3. 适老化改造补贴协办**
居家适老化改造补贴（扶手、防滑）多地登上热搜，叠加重阳节情绪节点。目标人群：家有老人的城区子女。商业模型：代办补贴申请 + 本地施工资源对接，打包价 300-800 元/户。⚠️ 各地补贴细则差异大，先跑通一个区的流程再复制，别跨区承诺。

## 四、小而美产品（Windows 优先 · 开源/免费/买断 · 数据可自持）

**主推 1 · Inbox Zero**
- 是什么：开源的 Superhuman 平替邮件客户端（10/18 PH 主页），AI 帮你分类、草拟回复、批量清理收件箱。
- 差异化：开源可自部署，收件箱数据不过第三方；商业邮件客户端几乎全是订阅制，它免费。
- 用在哪：配合 Agent Mail 工作流——通知、订阅、公告类邮件先让它分拣，人只看要紧的。
- ⚠️ 偏差：团队规模未核实；要数据自持需自行部署，托管版数据在云端。

**主推 2 · shim-cli**
- 是什么：命令行工具，「看你的 coding agent 到底在往外发什么，能脱敏的先脱敏」（10/18 PH）。
- 差异化：正打在 OpenCode 泄钥事件的痛点上——agent 把什么发给了模型、有没有夹带敏感串，跑一遍就清楚。
- 用在哪：给 Codex/Claude Code/OpenCode 的工作目录跑一次审计，检查日志与上下文里的 key、路径、客户数据。
- ⚠️ 偏差：新发布项目，团队与维护活跃度未核实；当定期审计工具用，别当安全边界。

**备选 · Caldera**
- 是什么：把 Obsidian 仓库变成「活的个人主页」和可公开链接的知识花园（10/18 PH 186 赞）。
- 差异化：不换笔记工具，直接给现有 vault 加发布层，笔记即网站。
- 用在哪：把笔记里适合公开的部分发布出去，是 OPC 做个人 IP 的低成本起点。
- ⚠️ 偏差：开源许可与团队未核实；公开发布前先检查 vault 内有无敏感内容。
