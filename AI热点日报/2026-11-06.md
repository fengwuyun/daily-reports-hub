## 三、潜在挣小钱的机会

**1. 零代码智能体搭建：客单 300–800 元/个 + 月维护 500–1500 元（⚠️攻略口径）**
易有料 11 月汇总：大量小微企业需要 AI 客服、私域回复机器人、行业知识库 Bot，但自己不会搭、雇人太贵；用扣子这类零代码平台搭一个收 300–800 元，月度维护费 500–1500 元，竞争者还不多。更轻的起步姿势：先做行业模板（如餐饮排班助手、电商售后问答），9.9–49 元一套挂闲鱼自动发货，不用对接客户、先验证需求。前提是真懂某个行业的业务流程，纯工具搬运没壁垒。
⚠️ 攻略文口径，收入为示例非统计；「竞争少」是作者判断。
源：易有料，11 月上旬

**2. 本地商家 AI 代运营：$350/月 × 19 个客户，8 个月 17 个来自转介绍**
易有料案例：一位前餐厅经理专做餐厅社媒管理，每家每月收 350 美元（约合人民币 2500），前三个客户是她吃过饭的餐厅，8 个月后做到 19 个客户、17 个来自转介绍。工具链就是 AI 写文案 + 数字人口播 + 剪映批量剪，单店月成本压在几百元内，复购逻辑是「下个月不续费内容就断」。国内版对标价 800–1500 元/月（上一条同源），餐饮/美甲/汽修每家都要短视频但老板不会做。
⚠️ 单案例自述，非平台统计；获客靠线下关系启动，纯线上冷启动没验证。
源：易有料，11 月上旬

**3. AI 绘画接单的垂直化生存：68 元/张月入 1.5 万 vs 六成从业者月入不足 800（⚠️案例自述）**
17you 汇总：小红书博主「AI 画师小鹿」专做情侣头像定制、68 元/张、日 5–10 单、月入 1.5 万+；另一闲鱼卖家 9.9 元起做 AI 头像，第三周因买家自发晒单小红书爆单、最高一天 23 单。对照数据（闲鱼 981.6 万笔 AI 订单，上期已发）：60% 从业者月入不足 800——赢家不是画得最好的，是垂直到一个细分场景（情侣纪念画 50–100 元、宠物拟人 30–50 元、宝宝百日头像）让客户没法比价的。启动顺序：一周作品集 → 小红书发「前后对比」引流 → 私域成交 → 好评攒够每 3 单涨一次价。
⚠️ 收入为博主自述，当作打法参考别当收入预期。
源：17you.com，11 月上旬

## 四、小而美产品

**worktrunk（主推·多 agent 并行的 Git worktree 管理 CLI）**
- 是什么：开源 Rust CLI（GitHub max-sixty/worktrunk，11.4k stars），专门管理 Git worktree，为「多个 AI agent 并行干活」设计，11/5 GitHub Trending 在榜
- 差异化：一条命令给每个 agent 开独立 worktree（独立工作目录、互不踩文件），合并回主干前各自验证；单二进制无依赖
- 用在哪：同时跑多个 Codex/agent 批量任务（比如多仓报表脚本、批量改 SQL）时，每个任务一个 worktree 隔离，人只看主干
- 源：GitHub Trending/topgit.dev，11/5

**MoneyPrinterTurbo（主推·AI 批量生成高清短视频）**
- 是什么：开源项目（GitHub harry0703/MoneyPrinterTurbo），输入一个主题或关键词，自动完成文案 → 素材 → 字幕 → BGM → 成片全流程，11/5 单日新增 617 stars 回潮趋势榜
- 差异化：老牌项目（非新品，如实标注）但链路最完整、可本地部署走自己的 API key，数据不出机；批量出「口播 + 素材」型短视频的现成底座
- 用在哪：短剧宣发的切片解说、投放素材的快速草稿、多语区批量出片实验的第一版；不追求成片质量时拿来跑量
- ⚠️ 走云端素材与模型 API 时内容质量与版权需自筛
- 源：GitHub Trending/startupcorners devtools 日报，11/5

**vercel-labs/agent-browser（备选·给 agent 用的浏览器自动化 CLI）**
- 是什么：Vercel Labs 开源的浏览器自动化 CLI（Rust，45.8k stars），专门给 AI agent 当「浏览器手脚」，11/5 Trending 在榜
- 差异化：不是 SaaS 不是扩展，是 CLI 标准件，agent 可直接调用；与同厂 agent-desktop（computer use，16.6k stars）组成桌面+网页两件套
- 用在哪：本地 agent 流程里补「登录后台、翻报表页、导出数据」这类网页操作环节
- ⚠️ Vercel Labs 团队维护，不算独立开发者作品；Windows CLI 可用性装前实测
- 源：GitHub Trending，11/5
