- ⚠️ 埋雷：Haiku 5.5 的「1 折」只限 ≤10 万 token 短请求（占其实际流量约 90%）；超过 10 万 token 长输入降幅收窄到 50%。Luna 的 $0.10/$0.50 也只限 ≤272K 输入，超出整段重计价 $0.20/$0.75，Fast 模式再翻倍、区域处理 +10%。

## 三、小而美产品

**主推 1 ｜ OpenBot**
- 是什么：开源工作区，把 Claude、ChatGPT、Grok、OpenCode、自定义 agent 接到一起，可分配角色、委派工作、跨设备实时协作。官方支持 Mac / Windows / iOS。
- 差异化：本地优先、开源、多 agent 编排在一个台面，不像各家 Chat 各自为战；数据留在你这边。
- 具体用在哪：你 WorkBuddy + 子智能体 + MCP 的多 agent 工作流，可以统一进一个编排台，少切窗口、少复制上下文；Windows 原生可用。
- 偏差：实时协作部分可能走其服务端，纯本地单人模式也 work；非单人作品但是开源社区项目。
- 来源：producthunt.com（ustack 10/6 日榜 #2，341 票）

**主推 2 ｜ Rill Browser**
- 是什么：AI 原生浏览器，⌘E 把任意网页直接变成 Claude Code / Codex 的任务，标签按主题组织、历史按天可搜。
- 差异化：把「打开的页面」变成「可操作的 agent 任务」，而不是另开一个聊天框。
- 具体用在哪：你盯投放后台、Superset 报表页时，选中页面直接派 agent 取数/对账/出结论，省掉复制粘贴。
- ⚠️ 偏差：当前交互偏 macOS（⌘E），Windows 兼容性需实测；团队维护非单人。
- 来源：producthunt.com（ustack 10/6 日榜 #1，411 票）

**备选 ｜ NoteWorthy**
- 是什么：AI 笔记，全自动在设备本地处理——离线、无账号、无订阅、不上传服务器，自动标题+归类。
- 具体用在哪：随手记灵感/需求点，数据不出机；适合你「本地优先、不碰云」的底线。
- ⚠️ 偏差：主平台疑似 Apple 生态，Windows 端待确认；非单人团队作品。
- 来源：producthunt.com（ustack 10/6 日榜 #10）
