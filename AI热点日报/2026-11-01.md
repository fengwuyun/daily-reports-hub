**1. 订阅额度大战双响：Claude Ultra 取消 5 小时限制，OpenAI 撤回降额计划全档翻倍（P0·跟你工具链直接相关）**

OPC 视角：两家在 IPO/竞争压力下抢重度用户，长任务（跨天 agent、大批量跑数）现在塞给 Ultra 档最划算——额度没多，但「中途被掐断重试」的隐性浪费没了。

**2. DeepSeek 发布 Super-agent 架构：跨会话、事件驱动、不等你下指令（P0·跟你业务直接相关）**
10/31 晚 DeepSeek Harness 团队公众号长文《Super-agent 设计探索》：现有 Agent 以单一 Session 为单位，一个人通常只能同时跟 3-5 个活跃 Session——单任务上限取决于模型能力，多任务上限取决于人的注意力。Super-agent 用双层架构、事件驱动、异步多信道交互、存算分离 + 外部 Watchdog 解决：连续（IM/GitHub 评论随时插入改需求）、主动（没人 @AI 也自己复现 bug 提方案）、持久（异常自动恢复）。内部实例已持续运行，参与 DeepSeek Harness 自身迭代。注意：官方明确这是架构思路探讨，不是现有产品功能。
对你的意义：你的日报自动化、归因插件就是「事件驱动 + 跨会话」形态，DeepSeek 把这条路写成了方法论——等 Harness 落地 Super-agent 功能，Codex 后端的自动化链路可以整体升级。

## 四、小而美产品

**sitesolide（主推·跟你工作流直接相关）**
- 是什么：免费开源（MIT）的 CLI，一条命令把 vibe-coded 应用部署到你自己的服务器——`sitesolide deploy` 完事即上 HTTPS、自带访问登录、API 密钥不进 git、每个应用跑在隔离的 systemd 沙箱里，不用 Docker。独立开发者单人项目，PH 10/30 日榜 #20（70 票）
- 差异化：agent 写完代码到「能安全给同事用」之间那一段（HTTPS/登录/密钥/备份）它全包了，且数据全在自己服务器上
- 用在哪：你让 Codex 写的小工具、报表页要给同事或外部看时，不用再手工配 nginx；自己 VPS + 域名就是全部成本
- ⚠️ CLI 在 Windows 的兼容性未实测，先在一个小应用上跑通
- 源：Product Hunt，10/30

**Tractionwave（主推·跟你业务直接相关）**
- 是什么：投放前创意预检工具——用 AI 生成注意力热图，预测用户看素材的视线落点，花预算前先验证视觉焦点
- 差异化：把「投放后看数据调素材」前移成「投放前热图预检」，对 FB/TikTok 信息流素材尤其对口
- 用在哪：短剧投放素材的封面/前 3 秒构图检查，跟你们的投放链路直接相关
- ⚠️ 定价、团队规模未核实（SaaS 形态、数据非自持），先试用再评估
- 源：Product Hunt 广告工具类目，10/30-31

**Mudroom（备选）**
- 是什么：开源工具，把 coding agent 放进 VM 里跑，产出的改动像 PR 一样逐条 review 后才合并
- 差异化：「先审后合」的 agent 工作流，防 agent 乱改文件——和币安失窃案教的是同一课：给权限之前先设计审批卡点
- 用在哪：让 agent 批量改脚本/报表 SQL 时先在沙箱里跑，人审完再落盘
- ⚠️ 平台支持（是否 Windows 原生）未核实
- 源：Product Hunt，10/31
