**1. Anthropic 定价 $83/股：基础募资 813 亿、含私募 1073 亿，估值约 1.5 万亿（P0·钱）**

11/18 美东定价，11/19 纳斯达克挂牌，代码 ANT。发行价 $83，高于 70–78 的推介区间；公司售出 9.564 亿股、联合创始人另售 2360 万股，基础募资 813 亿美元，加 260 亿私募配售共 1073 亿；完全稀释估值约 1.5 万亿。打破 SpaceX 750 亿的基础规模纪录（SpaceX 含超额配售为 862 亿，1073 亿仍然更高）。

财务底数：前三季营收 332.4 亿美元（同比约 +1206%）、Q3 单季 170 亿、截至 10/31 年化运行率 810 亿；约 79% 营收按用量计费。一个可用的付费结构证据：未使用 Claude Code 的 Claude Enterprise 用户月均支出不足 $75，而使用 Claude Code 的用户中支出最高的 5% 月均约为前者的 20 倍。代码库 90% 以上由 Claude 编写。

负债侧同日被翻出来：招股书披露已签生效的远期算力与基础设施采购/租赁承诺约 9010 亿美元，履约最远到 2045 年；2027 年 9 月前 12 个月需付约 707 亿，到 2030 年末约 4516 亿进入履约；部分芯片采购未锁固定金额，计入后总额可能破 1 万亿。

判断：这是 AI 应用层第一次被公开市场定价，卖方把区间上沿之上的 $83 认下来了。真正的风险不在需求，在「9010 亿刚性义务 vs 810 亿年化收入」这个比例——它把「必须持续融到钱」写进了商业模式。

做法：明天（11/20）只看两个数——开盘价相对 $83 的溢价幅度、首日换手率。溢价超 25% 说明情绪回来了，对已持仓是好事、对现在加仓是坏事。别在首日追。

⚠️ 9010 亿是已签未付的采购与租赁总额，不是已支出；其中部分芯片协议未锁金额，属预估。

源：财联社 /腾讯新闻·凤凰科技 /环球网 /新华财经 /CNBC，11/18–11/19

**2. Gemini 4 Neon：$3/$15，编程智能体指数 58.6 分第一、超 Opus 5.5（P0·价格）**

11/18 发布、11/19 开放 API。1M 上下文、最多 1M 输出，四档推理（low/medium/high/xhigh）；支持文本、图像、视频、音频、PDF，带 computer use、代码执行、文件搜索，可用 Google 搜索与地图做事实核验；不支持图像与音频生成。价格：输入 $3 / 输出 $15 / 缓存输入 $0.15（0.5 折），每百万 token。

跑分：xhigh 档 Artificial Analysis 智能指数 61 分列第三；编程智能体指数 58.6 分第一（超过 Claude Opus 5.5）；Vals Index 70.9% 第二并处于帕累托前沿；Legal Research Bench、Tax Agent Bench 第一；Agent Arena 新增「可操控性」维度第二。默认 high 档单任务成本比同系列 Carbon 低 32%；谷歌称整体质量达到或超过更大的 Carbon、速度约 3 倍，Antigravity 内部测试幻觉率最低。

判断：谷歌把「同等能力、三分之一价」做成了产品线，不是促销。Neon 卡在 Carbon（$2/$10，12/1 起 $4/$20）和 Hydrogen（$1.5/$7.5）之间——12/1 之后 Neon 反而比 Carbon 便宜，这在自家产品线里是第一次。

做法：把 Neon 挂到「跨文件改代码」和「长文档整理」两类活上跑一天。缓存输入 $0.15 要吃到，必须保持 prompt 前缀不变、新指令追加在末尾。

⚠️ 榜单与「质量≥Carbon」全部是谷歌自测口径；不支持图像/音频生成，别拿它替视频模型。

源：Google 官方博客 /IT之家 /财联社 /凤凰网科技，11/19

**3. 云知声 U2-Flash-1118：GPQA 93.9 第一，同任务 token 降 37%、调用降 44.8%，限时六折（P0·价格）**

11/18 发布并上线云知声 MaaS（Token Hub），API 兼容 OpenAI 与 Anthropic 协议。266B 总参 / 约 10B 激活，语言基座参数规模不变、新增约 1B 视觉模块；1M 上下文、256K 输出。九项横评拿 2 项第一、4 项第二：GPQA-Diamond 93.9 第一（高于 Kimi K3、Qwen3.8-Max）、U2-SWE-Bench v1.1 57.1 第一、DeepSWE v1.1 75.2 第二、SWE-Bench Pro 62.5、TerminalBench 4.0 35.5（较上版 +12.9）。

效率侧是这条的重点：同任务总 token 消耗降约 37.0%、模型调用次数降约 44.8%。价格：限时六折，输入 0.6 元 / 输出 1.2 元 / 缓存命中 0.02 元（每百万 token）。

判断：价值不在分数，在「调用次数降 44.8%」——agent 账单里调用次数常比单价更贵，减少无效重试比降价更值钱。但要看清两个口径：云知声 11/18 给港交所的自愿公告只写了 token 与调用降幅，**没写定价**；六折价来自同期营销稿。别把促销价当长期价做预算。

做法：拿一个现有 agent 任务，按「分析 / 实现 / 审查」拆三段独立会话跑一遍，复现那条 -44.8%。复现不出来，就别为折扣迁移。

⚠️ 分数与降幅全为厂商自测，无第三方复测；六折恢复原价后约 $0.42（按 1.0/2.0 元折算），仍便宜但优势缩水约四成。

源：云知声港交所自愿公告（9678.HK，11/18）/中国经济新闻网 /网易，11/18

**5. 微软官方包 agent-framework 在 PyPI 被投毒，恶意版本只活了 55 分钟（P0·安全）**

Wiz 报告：11/17 20:35 UTC 上架 1.26.1，21:08 出现 1.26.2，21:30 两个版本均下架。恶意代码向 site-packages 写 .pth 文件，Python 每次启动都会执行，**即使从未 import 这个包**；窃取环境变量、凭据文件、Azure 托管标识与 OIDC token，回传至 webhook.site。该包周下载约 4.1 万（另一口径为月约 20 万），最后一个安全版本是 11/12 的 1.26.0。

判断：上期是 Cursor 扩展链，这次是官方 pip 包链。55 分钟足够被 CI 缓存、锁文件、Docker 镜像留下来——下架不等于清除，清理要在自己的构建产物里做。

做法：这周跑一遍 `pip show agent-framework`。装过 1.26.1/1.26.2 的降回 1.26.0，并轮换 Azure 托管标识与所有 OIDC 凭据；CI 加 `--require-hashes`。

源：Wiz Research（经行业日报转述），11/17–11/18

**7. Epoch AI 用真实职场任务测了六款前沿模型：没有一款达到「员工标准」（P1·判断）**

Epoch AI 用真实职场任务测 Claude Fable 5.2、GPT-6.2 Astra 等六款前沿模型，结论是没有一款达到其「员工标准」；同期一篇 arXiv 论文发现跑分更高的编程模型并未完成更多工作。早期用户反馈两极：有开发者称 Astra 长任务易「过早停下」、会反问用户无法回答的问题。

判断：这条必须和昨天的降价 20% 一起读。单价在降、榜单在涨，但「能独立交付」这条线还没跨过去。采购层面的含义很直接——省钱的正确姿势是「便宜模型 + 人复核」，不是「换最强模型然后减人」。

做法：选型单上固定三列——这道题多少钱、谁能复核、出错谁负责。别只贴榜单截图。

⚠️ 「员工标准」是 Epoch AI 自建基准里的定义，不是行业共识。

源：Epoch AI（经 Sift / CNET 11/18 转述）

**11. 红果 AI 剧编剧新政 11/13 生效：S 级保底 1.5 万/部，A 级无保底（P0·跟你业务直接相关）**

红果更新《【AI 剧】编剧和剧本合作政策（2026 年 11 月版）》，11/13 生效。评级从 S+/S/A+/A/B 五档压到 S、A 两档，按投稿剧本**前 30 集**审核质量一次性定级；S 级保底 1.5 万元/部（较 8 月版上调）、分两笔发放；A 级无保底、保留进分本池资格。范围限 2D 漫剧、3D 漫剧、仿真人剧的对话型剧本；按 AI 剧全渠道免付费净收益 20% 分账、覆盖全生命周期。

承制侧同步收紧：11/1 起取消面向中小承制方每部 20–35 万保底；真人短剧保底预算超 15 亿、部均提升约 60%、付费分成从 70% 提至 80%；AI 剧 4 月起转纯分成、10 月取消系列剧规模系数。治理侧，11/19 行业论坛上中国网络视听协会与中国版权协会发布《AI 微短剧「融像」「融声」人格权益保护倡议书》。

跟你业务直接相关：同一个平台在两头动手——承制端保底没了，编剧端保底只留给 S 级。它买的是「前 30 集就能看出质量」的剧本，不是「写完再看」的剧本。

做法：走编剧这条路，把交付方式改成「先交前 30 集 + 分集钩子表」，按 S 级标准自评一遍再投稿。承制侧按纯分成重算项目账，别再拿保底模型立项。

⚠️ 政策细节以红果后台通知为准；「部均提升约 60%」为行业媒体口径、未披露分母。

## 三、潜在挣小钱的机会

**1. 快手第二期 AI 全民创作季：200 万现金 + 2 亿流量，投稿到 12/27**

路径：面向个人创作者、OPC 与 MCN 的 AI 内容征集，新增「AI 新星导演计划」。作品要求原创、版权清晰、单集不少于 1 分钟、至少以 2 集合集形式上传。适合已经有一批 AI 短剧/漫剧库存的人直接投稿，不需要新建产能。

报价：奖金池 200 万元现金 + 300 万算力值 + 2 亿流量激励；投稿 11/16–12/27，作品数据统计截至 12/31。单人可获金额**未披露**（分配规则未公开）。

月收入换算：未披露。可参照的规模感：第一期一个月 2.3 万人参与、108.5 万条投稿、5 亿播放，人均投稿约 47 条——中奖概率不高，但投稿成本接近零。

⚠️ 这是「比赛型收入」，不是可持续现金流；算力值绑定平台、不能折现；要冲奖基本等于要投人投时间，冲不到就是纯消耗。

源：快手第二期 AI 全民创作季公告（经行业日报转述），11/17

**2. 无脸长视频工具：1,600 个订阅 × 均价 $46 = $74,000/月（Stripe 验证）**

路径：贴一段脚本，自动完成配音、素材匹配、字幕与成片，卖「无脸视频」订阅。客户画像很明确——想用 AI 做内容赚钱的人，所以卖铲子比挖金子确定。

报价：GoMotion AI 均价 $46/订阅、1,600 个付费订阅、$74,000 MRR（2026-11-09 核验）；同榜 White Glove $63,100、traxy.ai $52,400。月收入换算 $74,000 ≈ 53 万元/月（按 7.2 折算）。增长斜率：2026 年 7 月成立，8 月账上 $18,400，11 月 $74,000，约 4 倍。

⚠️ 验证的是收入不是利润（广告费与退款不在账上）；无脸视频是品类红利，复制者一进来立刻打价格战；13 家 2026 年新 AI 公司的中位数只有 $21,500/月，$74,000 是头部不是常态。

源：The AI Receipts / TrustMRR（Stripe 只读接口，11/09 核验）

**3. 「把顾问复制成 AI」：一单 $521，93 个客户撑起 $48,500/月**

路径：不做通用工具，把某个具体职业的方法论做成 AI 产品，卖给同行的教练与顾问。单价能比工具类高一个数量级，代价是销售周期长。

报价：VirtualJK 均价 $521/单、93 个付费客户、$48,500 MRR。月收入换算 $48,500 ≈ 35 万元/月。换算关系值得记住：一个 VirtualJK 客户 ≈ 145 个 $3.6/月走量 App 客户。

⚠️ 客户数极窄（93 个），单个大客户流失就掉两位数百分比；产品化程度与留存未披露；高客单意味着退款风险集中。

源：The AI Receipts / TrustMRR，11/09 核验

## 四、小而美产品

**rtk-ai/rtk（主推·在命令输出进上下文之前先压缩，平均砍掉 56%）**
- 是什么：Rust 写的单二进制 CLI 代理，夹在 shell 和 AI 助手之间，把 git status / cargo test / pytest / docker ps / grep 这类命令的输出过滤、分组、截断、去重后再交给模型；`rtk init --claude-code` 装一个 PreToolUse hook 自动改写命令，不用改工作流。**87,129 stars、5,596 forks、Apache-2.0、2026-01-22 建仓、11/19 仍在提交**
- 差异化：不吹「省 90% 账单」——官方文档明确写「90% 指的是 bash 输出，不是账单」，因为输入 token 只是成本的一部分，还会被 system prompt 与会话历史稀释，并且它自报的 token 数是「字节 / 4」的估算。这种自限口径比任何 benchmark 都可信
- 用在哪：短剧项目里 agent 批量跑 ffmpeg/ffprobe、跑 lint、翻日志这些「输出很吵但只需要结论」的活；也是长会话 agent 最容易崩的那一段——噪音把上下文挤满，模型开始忘事
- ⚠️ 只压缩 bash 输出这一层，不减你的 prompt 与历史；1,686 个 open issue 说明早期项目还在磨合；Windows 建议走 WSL，别指望原生体验；README 自己承认 token 数是估算值，别拿 `rtk gain` 的数字直接写进财务模型
- 源：GitHub rtk-ai/rtk（11/19 实测 star 与提交时间）/rtk-ai.app 文档，11/19

**OpenMontageInc/OpenMontage（主推·把编码 agent 变成一条完整的视频生产线，含审批闸）**
- 是什么：开源 agentic 视频生产系统，12 条生产 pipeline、100+ 工具、700+ 份 agent skill 与制作知识文件，用 Python + FFmpeg + Remotion 串起「研究 → 脚本 → 分镜 → 素材生成 → 剪辑 → 渲染 → 自检」；配一个本地 Backlot 看板，实时显示每个阶段、每次 provider 选择与每一笔花费。**81,679 stars、11,114 forks、AGPL-3.0、2026-03-29 建仓、11/16 最后提交**
- 差异化：多数「AI 视频」是把几张图动起来；它保留了一条真素材路线——从免费素材库与开放档案抓真实运动镜头、剪进时间线再渲染。更关键的是**生成前有资产审批闸**：按场出 contact sheet（take、prompt、单资产成本、质量分），你批了才渲染，不是渲完才后悔。官方 demo 的成本是可复现的：60 秒短片 $1.33、竖屏变形片约 $4、七世界观合集约 $5
- 用在哪：漫剧/短剧的**预告片、概念片、投放素材批产**——同一套 pipeline 换题材就能出 20 个版本；也可把「参考视频 → 2–3 个差异化概念 + 工具路径 + 成本预估」这一步用来做立项预演，比直接开做便宜一个数量级
- ⚠️ AGPL-3.0 有传染性，改了又对外提供服务要开源；OpenMontageInc 是组织化运作、不是独立开发者（这点如实标注）；$1.33 那条用的是 Kling v3 via fal 的付费通道，本地免费路线出片质量另说；11/16 之后三天没提交、347 个 open issue，节奏在放缓
- 源：GitHub OpenMontageInc/OpenMontage（11/19 实测）/openmontage.video，11/19

**Panniantong/Agent-Reach（备选·给 agent 装上「读不到的那半个互联网」）**
- 是什么：一条命令装的 CLI，让 agent 能搜索和读取 15+ 平台：B 站（搜索/详情/热门/字幕）、小红书（笔记/评论，需登录）、V2EX、雪球、GitHub、YouTube（含字幕与转文字）、X、Reddit、Boss 直聘、小宇宙播客转写等；每个渠道按「首选 + 备选」的有序工具链自动切换。**113,207 stars、10,165 forks、MIT、2026-02-24 建仓**
- 差异化：CLI agent 自带的搜索对中文平台几乎无效，而中文选题的现场就在 B 站、小红书、V2EX。它的设计取舍很清楚——只读、不发帖不点赞、从不替你登录、专用浏览器后台跑；平台改反爬时只改工具链，agent 的调用方式不变
- 用在哪：短剧选题预筛（某题材在小红书/B 站最近怎么被讨论、评论在骂什么）、竞品舆情、把「豆瓣/知乎之外的中文现场」拉进日报的事实核对环节
- ⚠️ 需要登录的渠道会复用你 Chrome 的登录态（通常是主账号，建议换小号）；平台封自动访问是常态，实验渠道（X/FB/IG）随时可能失效；PyPI 上同名包不是本项目，只能按 README 的 GitHub 地址装；抓取量一大就会被限流
- 源：GitHub Panniantong/Agent-Reach（11/19 实测），11/19
