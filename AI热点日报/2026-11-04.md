## 一、AI 资讯

**1. 千问正式集成进 Apple 智能：国产模型首次进 iPhone 系统级入口（P0）**
11/3 阿里官宣：千问接入 Apple 智能，中国用户可在 Siri、写作工具、视觉智能里直接调用千问的文本与图像理解。11/4 随 iOS 开发者 Beta 开测，12 月随 iOS 27.3 正式推出。这是国产大模型第一次深度进入海外巨头的操作系统级入口，竞争从拼参数换成拼生态卡位。
OPC 视角：入口比模型重要，iOS 端「免费白嫖千问」的门槛降到零，你做工具类产品时别再假设用户没有系统级 AI。

**2. OpenAI 发布 GPT-6.1 Terra：价格腰斩到 $1/$5（P0·价格）**
面向视觉推理、精准电脑操作与自然写作，输入 $1/百万 tokens、输出 $5/百万，为 GPT-6.1 Sol（$2/$10）的一半、GPT-6 Astra 的十分之一；官方称完成任务速度较此前版本快 3 倍以上。「电脑操作」能力降到平价，是模型层为 agent 放量让路的信号。
OPC 视角：跑浏览器自动化、批量操作后台这类 agent 任务，Terra 是新的默认档；原来用 Sol 的任务先迁移跑一轮对比再定。

**3. Anthropic 摊牌 S-1：上半年营收 163 亿美元、同比 +1300%（P1·IPO）**
10/27 公开提交招股书（代码 ANTHROPIC，11/3 前后中文圈发酵），市场讨论估值 1.5–2 万亿美元，潜在融资千亿美元级。硬数据：超七成收入来自年付 10 万美元以上企业客户，Claude Code 与企业 API 是增长引擎；同期披露各项承诺支出总额 8950 亿美元（约 4480 亿在 2030 年底前发生），三季度营业利润由盈转亏。AI 公司第一次把真实账本摊给二级市场看：ToB 付费能力是定价核心，天价算力承诺也是真的。

**4. AI 基建从股市借钱转向债市：Meta 200 亿 + 甲骨文 200 亿 + Alphabet 60 亿欧元（P1）**
11/3：Meta 筹备发行至少 200 亿美元多币种高等级债券（10 月刚寻求过最高 950 亿股权融资）；甲骨文启动 100 亿美元发债 + 100 亿美元股票，合计约 200 亿；Alphabet 完成今年第二次欧元债发行 60 亿欧元。当日共 17 家公司发行美国投资级债券，为 9/8 以来最密集。算力开支已经大到巨头现金流兜不住，债券市场成了 AI 军备竞赛的第二资金池——这条融资链一旦收紧，全行业降速。

**5. 谷歌把 TPU 送上天：原型卫星在轨跑 Gemma 4（P1）**
Project Suncatcher 原型卫星已完成数据中心级 TPU 的首次在轨 AI 推理并回传响应：一颗卫星 4 颗 TPU、供电约 1 千瓦，2027 年计划再发两颗光通信卫星。项目负责人自己承认：五年内太空算力成本仍难低于地面。叙事大于实用，但「算力出地球」从 PPT 变成了工程课题。

**6. 商汤发布日日新 SenseNova 6.8 Flash 正式版（P1·工具）**
11/3 上线，主打办公协作与设计生成：支持动态 PPT、动态海报、网页、SVG 及 Blender 3D，可接入 Figma 工作流，新增长期记忆与跨会话任务协作，同步上线 Token Plan。设计类 agent 的国产平价选项又多一个，做门店物料、PPT 套餐的可以拿它压成本。

**7. 零一万物获杭州市区两级国资数亿元投资，总部落地临平（P1）**
11/3 披露：李开复的零一万物从「大模型独角兽」正式转型「产业 AI」，杭州国资加注，目标 2026 年订单额 15 亿元、2027 年 IPO。大模型公司的估值逻辑已经换了：不看你模型跑分，看你切进了多少企业真实经营。

**8. 墨芯人工智能完成近 10 亿元 C+ 轮：给推理算力「省着用」（P1）**
11/3 宣布，投方含仁爱资本、比丘资本等。路线是稀疏计算——从计算源头跳过无效运算，让同等硬件跑更多推理。背景数据：国家数据局披露今年 3 月全国日均 Token 调用已超 140 万亿、较 2025 年底 +40%。推理成本成为企业长期负担，资本开始押「少算」而不是「多堆卡」。

**9. AMD Q3 财报：营收 +45%，数据中心近翻倍（P1）**
11/3 电话会：Q3 营收超预期增长 45%，数据中心收入接近翻倍，指引 2027 年服务器营收翻倍、数据中心营收超此前预期。MI 系列在算力二供位置越站越稳，对冲了市场对 NVIDIA 单点依赖的担忧；当晚费城半导体指数 +2.64%。

**10. Claude Code 新规：禁止复刻现有游戏（P2）**
服务端推送：可以做原创、类型化或基于自有素材的游戏，但不再复刻特定现有游戏，改名或声称「原创」也不行。AI 编程工具开始主动给知识产权红线站岗——接游戏外包单的注意，用 Claude Code 抄爆款的路走不通了。

**11. 秋招 AI 门槛数据：大厂 64.3% 岗位提及 AI（P2·招聘）**
澎湃统计头部大厂秋招：64.3% 岗位提及 AI，58.6% 被 AI 渗透，技术岗渗透率 80.3%；技术岗 JD 高频词第一名是「AI 技能与框架经验」，985/211 只排第八、第九。AI 技能已经排在学历标签前面，这是就业市场第一次出现这种倒挂。

## 二、热点 & 梗

**1. 「我画地为牢，厉娜」：一句综艺台词变成全网造句模板**
源头：芒果TV《后会友期》悬崖对谈，许飞对断联 15 年的厉娜哽咽说「我是被宣判的人，我能去哪儿啊，我画地为牢，厉娜」。厉娜没听懂这个词，回屋用 AI 查了「画地为牢」什么意思，然后顺手点了一份麦当劳——一人深情内耗、一人查词干饭的错位感直接把梗焊死。11/3 吴宣仪接梗「我画地为牢啊浪姐（学歌学舞根本学不完）」，4 分钟后评论区自补「我真的要哭了厉娜」；话题单日新增讨论超 6.8 万条，「我刻舟求剑，厉娜」等仿写刷屏，芒果TV 把站内综艺文案结尾统一加上「厉娜」当句号使，央视频同日发《画地为牢有用吗》科普视频被解读成官方盖章。梗能炸的核心：句式万能、解释成本为零——「我加班到十点，厉娜」任何人可套。

**2. 雷军少打一个「万」，全网忙着提车**
11/3 雷军发小米 YU7 购车权益，把「首付 7.99 万元起」写成「7.99 元起」，评论区秒变提车现场：「我给你 10 块钱不用找了」「这条微博把车价打到 10 块以内」。雷军随后亲自下场纠错。乌龙背后是真数据：小米 10 月交付超 5 万台，YU7 一年保值率 82.3% 纯电第一；同期小鹏 50237 台也破 5 万，但 10 月全国乘用车零售同比降超 26%——头部吃肉、大盘挨打的分化格局。

**3. 爸爸魔改电视系统：孩子每看 10 分钟抽查一道题**
陕西一位爸爸把家里电视系统改了，孩子每看 10 分钟弹出随机题目，答对继续看、答错追加一道，视频发布后全网家长求同款。技术含量不高但切中痛点——「用技术手段管娃」的家庭版需求肉眼可见，有人已经在评论区问能不能出通用版。

**4. 欧洲数百家连锁超市遭网攻：冷柜被远程调成 50℃**
比利时（至少 76 家门店、家乐福约 15 家）、瑞典、爱尔兰等多国连锁超市冷藏系统被黑客远程启动除霜模式，大量生鲜一夜报废，手法与 10/11 法国数百家超市被攻击完全相同。欧盟委员会定性为蓄意破坏食品供应链。物联网设备的安全债开始连本带息地还——凡是联网可控的设备，都默认会被打。

## 三、潜在挣小钱的机会

**1. AI 萌宠账号：单条商单最高 8 万，平台还在发奖金（跟你业务直接相关）**
光明网 11/3 专访 + 网易 11/3 报道双源：抖音 #AI萌宠# 话题 15.9 万人参与、累计播放 31.5 亿次。收入结构（「猫子柒」创作者自述）：70% 广告商单 + 30% 平台激励；头部账号「LT小狗日记」单条定制广告报价最高 8 万元，中腰部「川岛小猪」约 4500 元/条，单集制作成本仅 200–1000 元。平台在撒钱：小云雀 AI 优质创作者爆款最高 25 万现金、即梦 AI 单条最高 7 万。门槛低但头部集中，可行打法是「治愈系日常叙事 + 高频更新」先吃平台激励，账号起来后商单自然来——AI 视频生成能力是你现成的。

**2. 政府出钱的 AI 技能免费课 + 商单闭环：广州 AI 动漫短剧公益课开抢**
广州日报 11/3：广州市职业能力建设指导中心「传承红棉匠心」公益项目开 AI 动漫短剧班，零基础可学，11/6、11/13、11/20、11/27 连续开班，首期短视频课秒满。关键是闭环：培训机构联动本地数字文创企业，学员自愿承接商单，按单计酬、签劳务协议，作品数据好还有分成。外地没有同款课的城市，这个「政府补贴培训 → 企业按单收货」模式值得抄——你做 AI 创作教学的变现路径里，挂上官方背书和真实商单是降维打击。

**3. AI 编程变现四件套：闲鱼 9.9 元 PDF + 接单 + 付费社群（⚠️自述口径）**
hqwc.cn 11/3 一篇独立开发者自述：四条路径月入 5000+——技术博客+付费专栏（月 300–500）、闲鱼数字产品（月 200–500，9.9 元转化率远高于 99 元，标题写具体痛点、不放 emoji 否则删帖）、AI 代写代码（月 2000–3000，别人 3 天的活一上午交）、99 元/年知识社群（月 500–1000）。⚠️ 单源自述无交叉验证，但路径拆解具体、时薪账算得清楚（接单 250–375 元/时最高），当框架参考比当收入预期合适。

## 四、小而美产品

**GeckIt（主推·多 agent 看板）**
- 是什么：PH 本月新品——给 Codex、Claude Code、OpenCode 等 coding agent 做的看板（Kanban），开源
- 差异化：多个 agent 并行跑任务时不再开一堆终端窗口切来切去，一张板子看每个 agent 的状态和产出
- 用在哪：你多仓并行跑 Codex 批量任务时，把任务当卡片拖动管理，谁在跑、谁完成一目了然
- ⚠️ PH 在榜但定价/Windows 原生支持未核实，开源项目优先看是否有 Windows 安装文档
- 源：Product Hunt AI Coding Agents 分类，2026-11 上旬

**Inyon（主推·手机遥控 agent）**
- 是什么：PH 本月新品、开源——用手机回答你的 coding agent 的提问，人不在电脑前也能给 agent 批复
- 差异化：卡住 agent 跑长任务的最大损耗是「等你确认」，这个工具把确认环节搬到手机上
- 用在哪：晚上让 Codex 跑批量改造脚本，出门时 agent 卡在权限确认，手机上直接回，任务不中断
- ⚠️ 实现细节与 Windows 兼容未实测，开源可先看 README
- 源：Product Hunt AI Coding Agents 分类，2026-11 上旬

**Kitbitz（备选·CC0 插画库）**
- 是什么：PH 本月新品——2000+ 张手绘插画，全部 CC0 协议（可商用、免署名）
- 差异化：CC0 是插画素材里最干净的授权，做产品落地页、海报、公众号配图零版权风险
- 用在哪：给变现机会里的门店海报套餐、数字产品 PDF 补视觉素材，不用再担心字体图库侵权
- ⚠️ 网页素材库非本地工具，与「数据自持」标准不符处如实标注
- 源：Product Hunt Design Resources 分类，2026-11 上旬
