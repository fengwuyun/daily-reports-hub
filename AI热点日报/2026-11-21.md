**2. 微信短剧 12/1 起双改：单集不得短于 1 分钟，AI 剧必须交「制作证明视频」（P0·跟你业务直接相关）**

11/20 微信短剧内容中心发公告，两项更新**同日 12/1（周二）生效**：① 单集最低时长由 45 秒上调至 1 分钟，生效后不足 1 分钟无法提审，官方理由是减少「剧情仓促、情节割裂」；② 含 AI 生成内容的剧集，提审材料新增「AI 制作证明视频」，需展示 AI 软件的实际创作过程——**资产列表、剧集列表、不同集与分镜使用的提示词，并播放少量分镜片段**，用于核验创作真实性、减少盗版。该材料目前选填，12/1 起转必填。

判断：这两条不是内容标准，是**举证责任转移**。过去平台判「是不是你做的」靠工程文件和自查；现在要你把提示词与资产清单摆出来。对批量出片的团队，含义很具体：**从第一天起就得留档，而不是上线前补材料**。同时 45 秒→1 分钟会直接压缩「快节奏强钩子」那一类剧型的结构空间——原来 60 集铺一个故事，现在要么集数变少、要么单集信息密度提高。

做法：这周做两件事。① 在制作流水线里加一个「提审包」自动产物：每集导出 `prompts.json`（分镜→提示词→模型→参数）、资产清单（角色/场景/道具及其生成来源）、以及 15–30 秒分镜片段拼条；② 拿手上 1–2 部待发剧按 60 秒/集重排一次，算清楚总集数变化对分账的影响再决定。

⚠️ 公告未说明证明视频的时长、清晰度与文件格式要求，建议按「能一屏看清提示词文本」的标准做，别压太狠；「制作证明」能否真正解决盗版问题，平台未给验证口径。

源：微信短剧内容中心公告 /IT之家 /凤凰网科技 /科创板日报，11/20

**3. 成都 AI 漫剧出海研讨会：市场规模 3 年从不足 30 亿到约 400 亿，今年上半年 22 万部新剧盈亏平衡不足千分之五（P0·跟你业务直接相关）**

11/20，四川省广电局指导、川报集团西部国际 AI 漫剧产业园主办的「AI 漫剧出海」研讨会在四川传媒学院举行，40 余位学界与制作、运营方代表参会。会上披露的关键数字：近三年国内 AI 短剧市场规模**从不足 30 亿元增至约 400 亿元**；**今年上半年 22 万余部新剧中，实现盈亏平衡的不足千分之五**；海外热度「多来自投流，更多是模式出海而非内容出海」。区域调研两条：印度本土平台下载量已反超中国应用，但中国出海应用仍主导内购收入；印尼下载量居前但付费意愿低，**九成以上受访者希望保留中文原声配高质量字幕，对纯 AI 生成内容多有批评**。

判断：「成本降到历史最低，成功率也降到历史最低」这句话是全场的真话。千分之五意味着 200 部里活 1 部——这个赔率下，靠「多产」对冲是数学上不成立的，只能靠「提高单部命中率」或「降低单部成本到可承受」。印尼那条更值钱：**用户要的是中文原声 + 好字幕，不是 AI 脸**。它说明海外市场的付费理由可能是「内容」，而 AI 只是把产能拉满的手段——这跟国内「AI 剧当免费流量」是两套生意。

做法：本周把最近 3 部剧的成本按「每分钟成片成本」重算一遍，和「千分之五」对齐算期望值；如果算下来单部必须爆才能回本，就先砍集数、把钱压到前 3 集的钩子上。出海侧，先给印尼/印度各做一版「中文原声 + 硬字幕」的样片投小预算，别一上来就配音本地化。

⚠️ 400 亿与「千分之五」均为与会学者在会上引用的数据，未附统计口径与出处；「海外热度多来自投流」是观点不是测量。研讨会为主管部门指导的行业会议，观点带产业立场。

源：封面新闻 /川观新闻，11/20–11/21

**4. 特朗普：将阻止美企在境外建数据中心，并对境外数据中心征「巨额税」（P0·合规·选址）**

在深圳中俄美元首会晤后的记者会上，特朗普表示将阻止美国公司在境外建设数据中心，并威胁对在海外建数据中心的美企征收「巨额税款」，原话为「不会允许我们的公司在国境外建设数据中心」。**未给税率、适用范围与实施细则**，副总统万斯与国务卿鲁比奥在场。同日另有：阿波罗与高盛完成 SpaceX 440 亿美元 GPU 融资定价（采购英伟达 Vera Rubin，2027 年启动）；CoreWeave 跌穿 40 美元 IPO 发行价。

判断：这是一句没有细则的表态，但它指向的方向很清楚——**算力被当成战略资源往境内收**。对你有两层影响：一是海外机房做备份/备份推理的合规成本会上升，二是「出海产品用哪里的算力」会从技术选择变成需要解释的决策。注意它跟 11/20 那条「用中国模型要在官网披露」是同一套逻辑的两端：一头管模型来源，一头管算力位置。

做法：给海外客户的项目，架构文档里加一行「推理与存储所在司法辖区」，并准备一句可复述的话术（例如「权重在境内托管、数据不出境、推理就近部署」）。别等采购问卷来问。

⚠️ 仅为记者会口头表态，无行政令、无草案、无生效时间；能否落地取决于国会与法院，历史上此类表态多次未成文。

**5. Anthropic 研究员称与 Claude 合作证明黎曼猜想：1737 万行 Lean 代码、41 天、无 sorry 无 axiom（P1·判断）**

Anthropic 研究员 Levent Alpöge 公布一份与 Claude 合作完成的黎曼猜想证明：**1737 万行 Lean 代码，分 14 个压缩包、175,187 个 `.lean` 文件，含 818,755 条定理声明，无 `sorry` 也无 `axiom`，历时 41 天**；他同时表示已给出广义黎曼猜想的证明。另有一份纯人工完成的广义黎曼猜想草稿同期出现。**未经同行评议，第三方编译核查仍在进行，Anthropic 官方未就此发声明**。陶哲轩回应：验证仍需时间。

判断：`sorry` 和 `axiom` 是 Lean 里的「此处跳过」与「直接假设」，两者都没有，意味着形式化层面是闭合的——这比「模型说了个证明思路」高一个量级。但形式化闭合 ≠ 数学界接受：要过的是编译、是人读、是审稿。无论如何，这是模型第一次被用在「有确定答案的纯数学问题」上，而不是写代码或写文案。

做法：这条不用做产品动作，但值得记一笔判断——**能自我验证的任务（代码可编译、数学可形式化）会先被吃掉，不能自我验证的（市场判断、审美、谈判）会慢得多**。你的短剧业务恰好落在后一半，别把「模型会证明定理」误读成「模型能判断什么剧会爆」。

⚠️ 单一作者自陈，代码未完成独立编译核验；「41 天」含人工引导与调试时间，不是纯模型运行时长。

源：Financial Times /The Verge /TechCrunch /SiliconANGLE /陆家嘴财经早餐，11/20–11/21

**6. GAO 实测：ChatGPT、Claude、Gemini、Grok 都能被诱导给出可执行攻击方案，12 小时内完成（P0·安全）**

美国政府问责局（GAO）报告称，其专家让四款主流聊天机器人产出了「判断为可实施」的攻击方案：**两款给出爆炸物方案，两款给出袭击变电站方案，全部在 12 小时内完成**。四款产品起初都做了拦截（拒答、删除内容、封号），GAO 用「常见绕过手法」突破，报告未披露具体手法。测试在 2026 年春季进行，反映的是当时的模型版本。

判断：这条的价值不在「AI 危险」，在**它给「安全对齐」定了一个可测量的基线：12 小时、常见手法**。也就是说，靠提示词层与拒答策略做的防护，面对有耐心的对手基本是礼貌性阻力。同期加州公开的 AI 安全标准下一步里有一条更硬——**重大事件 48 小时报告**。两件事合起来看：监管正在从「你有没有安全策略」转向「出事多久能说清楚」。

做法：如果你在做面向 C 端的 AI 产品（陪伴、育儿、医疗类尤其），这周把「高危请求的拦截日志」和「人工复核入口」加上——不是为了合规，是为了出事时能在 48 小时内交出一份能看的记录。

⚠️ 测试于 2026 年春季，不代表当前版本；绕过手法未公开，无法复现；报告为政府机构单方发布，四家厂商未逐一回应。

源：GAO 报告（经 AI Breaking Wire 转述），11/20

**7. Token 变成消费品：天猫双十一 Token 品类成交环比 16 倍，腾讯云给 DeepSeek 搜索/抓取退费（P0·成本账单·跟你业务直接相关）**

两件事同日落地。① 中国证券报 11/21 报道：**截至 11 月 11 日，天猫「双十一」Token 品类成交环比激增 16 倍**；淘宝充值中心已把 AI 模型充值入口与话费、流量、水电燃气并列，9 月起接入阿里云、智谱、MiniMax、DeepSeek，形成「AI 空间站」；商务部发言人 11/19 在介绍双十一亮点时提到「买算力像充话费一样简单」。个人购买方式两种：按量充值券、包月包年固定额度。② 腾讯云 11/20 公告：**调用 DeepSeek「原厂直供」模型时触发的服务端搜索（Search）与网页抓取（Fetch），自 11/18 12:00 起不再计费**，只按模型 Token 计费；11/18 12:00 之后产生的费用启动退费，**11/30 23:59:59 前统一退还**。触发接口包括 Anthropic API 与 Responses API 的 `web_search` 工具。

判断：Token 进直播间、进话费入口，说明「算力配额」已经具备消费品形态——它卖的不是模型能力，是**不被打断的权限**。对做内容的人来说这是好消息也是坏消息：好的是采购变简单、价格透明；坏的是按月套餐的价格锚一旦建立，模型厂商的降价压力会从「抢开发者」转向「留订阅者」，API 侧的折扣会变少、套餐侧的捆绑会变多。腾讯云那条退费是更实的钱——如果你在跑联网检索类 agent，先把 11/18 之后的账单核一遍。

做法：本周两件。① 登录腾讯云费用中心，把 11/18 12:00 后的 DeepSeek 原厂直供 Search/Fetch 调用拉出来核对，等着 11/30 前那笔退款到账；② 如果你团队里有人自购 Token 套餐，统一走一个账号，别让个人订阅变成不可见的影子成本。

⚠️ 「16 倍」为天猫单方口径，未披露基数；「原厂直供」是有标识的特定模型，非全量 DeepSeek 模型，退费范围以公告为准。

**8. 价格两条：华为云香港区把 DeepSeek 缓存输入打到 2 折，Fixstars 在日本托管 GLM-5.3（P1·价格）**

① 华为云公告：**11/23 00:00（北京时间）起，中国香港区 DeepSeek-V4.1-Flash-1017 的缓存命中输入价降至原价 20%**，常规输入与输出价格不变。调整后缓存命中输入：夜间（21:00–08:00）0.003 美元 / 百万 token、日间（08:00–20:59）0.006 美元。② Fixstars 11/20 宣布在日本托管的 Fixstars Inference Cloud 上线 GLM-5.3（Z.ai 开源权重），**输入 ¥10.49 / 输出 ¥210 / 缓存读 ¥10.34（每百万 token）**，用 NVFP4 4bit 量化；东京实测首 token 中位时延 1.127 秒（64 并发、平均 13.9 万输入 token、缓存命中率约 96%）；数据全部留在日本、推理后不留存不记录不训练。

判断：两条都是「缓存价」在动，不是 list 价在动。方向一致——**厂商在把「重复读同一段上下文」的价格打到接近零，把利润挪到输出和首读**。这对批处理、长 system prompt、多轮固定人设的 agent 是实质降本；对「每次都换长文档」的场景没有帮助。做预算时应该按「缓存命中率」而不是「平均单价」建模。

做法：本周算一个数——你现有 agent 工作的**缓存命中率**。低于 60% 就先改 prompt 结构（固定前缀在前、变量在后），再谈换模型。这一项通常比换一家供应商省得多。

⚠️ **Fixstars 的价格口径对不上官方 list**：厂商称 ¥10.49/¥210 约为智谱官方 API 的 1/20 与 1/3，但按 7.2 折算约为 $1.46/$29.2 每百万 token，反而高于本表记录的 GLM 5.3 list 总价（2M 入 + 500K 出 ≈ $0.84）。三个数字无法同时成立，本表**不将 Fixstars 并入排序**，等智谱日本区价目页或 Fixstars 计价页出来再核。华为云 2 折只覆盖「缓存命中输入」，不含输出。

源：华为云官方公告 11/20 /Fixstars 公告（经 IBTimes 日本版）11/20

**9. Agent 抢的不是模型是操作权：腾讯 WorkBuddy 上线电脑操控公测，Gemini 能在 macOS 上替你点鼠标，Gemini API 改成按需加载工具（P1·工具链）**

三条同日。① 腾讯 WorkBuddy 上线**电脑操控（Computer Use）能力并进入公测**：能识别当前页面、看懂客户端界面，执行点击、输入、滚动，**不需要目标软件开放接口**，可在后台操作。② 谷歌给 macOS 版 Gemini 加了**电脑操作**：在原生 Mac 应用与浏览器里执行多步任务，聊天里给实时预览、每步动作前需确认；目前**仅美国、仅英文**，需 AI Plus / Pro / Ultra 订阅。③ Gemini Interactions API 预览上线 **Tool Retrieval（`tool_search`）**：模型只看得到延迟加载工具的名称与描述，真正调用时才加载完整参数 schema，`defer_loading` 设为 true 即可；**不额外收费，按模型常规价计 token**，省下的是「根本没用到」的 schema。

判断：不需要开放接口这一条是分水岭——它把「能操作多少软件」从「愿意接 SDK 的厂商数量」变成了「有多少屏幕」，覆盖所有存量软件。三条放在一起看，agent 竞争的重心已经从模型能力转向**权限、预览、确认**这套交互契约：Gemini 每步要确认，WorkBuddy 强调后台跑，Tool Retrieval 在压上下文。这三件事决定 agent 能不能进生产，比跑分重要。

做法：这周拿 WorkBuddy 的电脑操控做一次 30 分钟实测——选一个你每天重复的活（比如从投放后台导出报表再改名归档），看它能不能在无人值守下跑完。跑得完就固定成例程，跑不完就只用来做「有人看着的半自动」。

⚠️ 电脑操控类能力天然带权限风险：后台点击意味着它能碰到你登录态下的任何界面，公测阶段别在有支付、私信、后台管理的窗口上跑。Gemini 的电脑操作目前不对中国区开放。

## 二、热点 & 梗

**1. 短剧被印成纸：一页一集、3 到 5 元一本，卖给小学生的「六一礼物」**
来龙去脉：11/20 起，电商平台出现「纸质短剧」——把竖屏短剧印成实体卡纸，或折成能塞口袋的长条纸，翻一页就是一集。实测在售价格：¥3.86、¥5.8、¥9.75、¥11.8 等，部分标注「30 页短剧」「大字幕完整剧情」「48 本装」。更值得注意的是标签：多款商品名直接写「小学生趣味小礼品」「小学生幼儿园奖」，适用节日填「六一儿童节、开学季、奖励学生礼品」，并出现专门面向儿童的题材（如《小孩哥炒饭》）。网友把它比作「小人书回归」；新浪 11/21 的报道把讨论引向版权与「改编成纸质品需授权」。
判断：这条的形式创新是真的——它把「划不到底」改成「翻得到底」，把自动播放改成手动翻页，解决了短剧最被诟病的两个问题（信息过载、算法推送）。但它同时干了三件危险的事：**把成年人向的内容卖给儿童、把平台内可治理的内容搬到平台外、把有版权的剧印成实物**。前两件是监管最敏感的两条线，第三件是民事诉讼的标准入口。
跟你业务直接相关：这是「同一内容换载体再卖一次」的最小可行样本——成本极低（打印）、渠道现成（电商）、无需备案（不是视听节目）。但它同时也演示了这条路的终点：一旦触达未成年人，监管会先来，平台会先切割。
做法：如果要做类似形态（纸质、卡片、周边），三条底线先立好——只做已确权自有 IP、只标成年人向、不出现平台 logo 与演员肖像。这三条立不住就不做，赚的钱不够付一次诉讼。

源：新腕儿 11/20 /新浪娱乐 11/21（电商在售页价格为其截图口径）

**2. 知网 AI 检出率突然变高：「像 AI 写的」正在被当成「就是 AI 写的」**
来龙去脉：知网 10 月 24 日更新 AIGC 检测算法后，同一篇论文在更新前后送检、AI 生成率结果不一致，客服回应称是算法升级、**升级后「疑似率」会更高，属版本迭代过渡阶段**。澎湃实测知网、万方、维普三家平台对同一篇文本给出的 AI 生成率「悬殊」，原创内容被误判。高校侧则在收紧：四川大学 2026 届本科毕业论文通知要求文科 AI 生成内容占比不超 20%、理工医科不超 15%；部分学术论坛要求投稿附查重率与 AIGC 率报告（均需低于 25%）才能过初审。
判断：检测的本质是**按文本特征做概率推测**，不还原写作过程。学术写作要求的术语准确、结构规范、表达客观，恰好与 AI 输出特征重叠——于是「写得太规范」变成风险。更麻烦的是激励错位：一旦 AIGC 率成为硬指标，学生的努力方向会从「把论文写好」变成「把数字降下来」。
跟你业务直接相关：只要你的内容要过「AI 检测」这一关（投稿、投标、平台审核、学校作业），结论都一样——**过程材料比结果更重要**。这跟微信 12/1 要「AI 制作证明」是同一件事的两个行业版本。
做法：给自己建一个「过程留档」习惯：初稿、修改记录、素材来源、模型使用说明各存一份。检测报告只当线索，不当结论；真被质疑时，能拿出过程的人不用辩论。

源：澎湃新闻（经多家转载）11/20–11/21 /四川大学教务处通知（转述）

**3. 「2 人 58 元买一杯咖啡被拒绝入座」冲上热搜第一，店家已撤「一客一消」**
来龙去脉：一对夫妻在咖啡店点单时被要求「两人必须买两杯」，只买一杯则不予消费、请离；离店后在店门口二三十米处坐下又被要求离开，理由是「属消费区」。当事人小红书发帖后被湖北经视报道，11/20 冲上微博热搜第一。争议点集中在三处：店方称入口与消费区均有「一客一消」告示，当事人称当日门口与户外区均无告示、仅收银台有一张字体很小的；店方先发声明函称对方「坐了 2 小时、践踏花丛」，当事人用行车记录反驳后店方删帖；最终店方撤下该规则并表示后续优化。当事人主张涉《消保法》第八条（知情权）与第二十六条（格式条款）。
判断：这不是「谁对谁错」的吃瓜，是**规则告知成本**的教科书案例。商家有权设最低消费门槛，但把规则写在小字里、等人付款时才说，就等于把纠纷成本转嫁给顾客；而顾客一旦把过程完整留证（时间、照片、行车记录），舆论与法律就都站在证据那边。
跟你业务直接相关：投放素材里的「价格/门槛/赠品」三个信息，属于同一类风险——**说清楚比说好听重要**。短剧付费点、会员权益、活动规则的表述，含糊一次就要用一次公关来还。
做法：检查一遍你在投的素材与落地页，把「多少钱、能看多少、什么时候失效」三行字放到首屏可读位置；别指望小字免责。

## 三、潜在挣小钱的机会

**1. 把「描线稿」这一步做成工具：纹身转印稿 App，$48,700 MRR、1,800 个订阅、单价 $28**

路径：不做通用生图，只接管一个职业里最慢、最重复的一道工序——纹身师把客户给的参考照片/草图，转成可直接转印到皮肤的线稿。价格按月订阅、当工作工具卖而不是当玩具卖，所以单订阅能卖到 $28（多数消费级 AI App 只有个位数）。2026-01 上线，单人，美国。

报价：$48,700/月（Stripe 接口验证，11/20 更新）；1,800 个付费订阅，均价约 $28；30 天增长 +0.9%（已进入平台期）。
月收入换算：约 35.1 万元/月（按 7.2）。

⚠️ 门槛全在手艺：纹身师一眼看线质，错一根线就不用；竞品包括 Ghostline、Procreate 工作流和一堆免费转换器；$28 的定价意味着必须持续证明「省下的时间值这个钱」，工具一旦被平台内置就失去定价权。增长已接近停滞（+0.9%），说明这是「窄而稳」不是「窄而快」。

映射到你的活：短剧里对应的同一道工序是「定妆照 → 三视图 + 表情包 + 服装变体」——制作组每次都要手工重画，且必须角色一致。这是「窄场景 + 已有人工付费方案」的标准组合。

**2. 给已经在用的工具加一层 AI，而不是做一个 AI 产品：浏览器拨号器，$16,500 / 30 天**

路径：选一个销售团队每天已经在用的工具（拨号器），只让一件事可量化地变好——一次连拨 5 个线索；再把 AI 放在「省时间」的位置：通话纪要自动生成、每通电话打分、拨号前给一页简报。按席位收费，AI 不是卖点，是功能。创始人此前已有付费浏览器扩展和一批销售岗受众。

报价：30 天 $16,500（Stripe 验证，11/20）；按席位计价，具体档位未在该页披露。
月收入换算：约 11.9 万元/月（按 7.2）。

⚠️ 脏活全在管道：电话基础设施、号码信誉（容易被运营商判为骚扰）、十几个 CRM 集成，是几年的工程量；这个案例的起点是「已有受众 + 已有付费扩展」，不是从零获客。AI 通话分析的准确率未披露，销售场景对错误容忍度低。

映射到你的活：短剧投放团队每天在用的工具是「投放后台 + 素材库 + 日报表」。做一个「批量建计划 + 自动日报 + AI 复盘」的席位制小工具，AI 只负责写复盘那一段——比做一个「AI 投放大脑」更容易卖出去。

源：TrustMRR（Stripe 验证），11/20

**3. 把一类文档的生成做成一条流水线：AI 电子书生成器，$11,900 MRR、250 个订阅、30 天 +34.4%**

路径：输入主题/大纲，输出可用的成品文件（PDF / EPUB / Word 三种格式），卖的不是「AI 写作」而是「交付一个能被上传、被打印、被卖的文件」。$48 单价、250 个订阅，增长是这一批案例里最快的（+34.4%）。

报价：$11,900/月（Stripe 验证，11/20）；250 个订阅，均价约 $48。
月收入换算：约 8.6 万元/月（按 7.2）。

⚠️ 高单价低复购的典型：电子书是一次性需求，250 个订阅说明多数人可能只买一个月；内容同质化严重，平台（KDP 等）对 AI 生成内容的政策在收紧；退货与退款率未披露。增长快可能来自一次投放脉冲，不代表留存。

映射到你的活：短剧的衍生文档——分集大纲、人物小传、投流脚本、小说化改编——都是「一次性交付物」，都可以按这套逻辑做：固定模板 + 一键导出成对方要的格式。

源：TrustMRR /The AI Receipts（Stripe 验证），11/20

## 四、小而美产品

**cathrynlavery/diagram-design（主推·给 agent 装一套「编辑级」图表设计规范，45 种图表、单文件 HTML+SVG）**
- 是什么：一个 agent skill，让 Claude Code / Codex / Copilot / Cursor / Factory Droid / Qoder / Pi 按品牌风格直接产出**自包含的 HTML + SVG 图表**，覆盖 45 种类型（架构图、流程图、象限图、时间线等），生成的文件双击就能开。**69,274 stars、4,652 forks、MIT、2026-04-16 建仓、11/19 最后提交、44 个 open issue、个人项目（GitHub 用户 cathrynlavery）**
- 差异化：README 里那句「No shadows. No Mermaid slop.」就是它的定位——Mermaid 出来的是「能看」，它要的是「能放进汇报」。做法是给 agent 一套版式规范（网格、留白、字号层级、无阴影、无渐变），所以同一主题反复生成也保持同一套视觉语言，不会每次换风格
- 用在哪：日报/周报里的链路图与对比图、给老板讲投放归因时的流程图、短剧项目的人物关系图与分镜结构图；你的「AI 产品 UI 生成器」也能接它做图表层，不必自己写图形规范
- ⚠️ 输出是静态 HTML/SVG，交互式图表（hover、联动筛选）得另接；45 种类型里中文排版未逐一验证，长中文标签容易撑破图例，出图后必须目测；只解决「长什么样」，不解决「该画什么」
- 源：GitHub cathrynlavery/diagram-design（11/21 实测 star / 提交时间 / MIT），11/21

**zhouxiaoka/autoclip（主推·一个链接进去、一条竖屏短视频出来，本地桌面端，适配抖音/小红书/TikTok/Reels/Shorts）**
- 是什么：开源 AI 视频剪辑桌面工具：粘一个视频链接（播客、访谈、课程等长内容）→ 选目标平台 → 自动切成短视频，同时出字幕、封面和发布文案；不满意可以进内置编辑器继续改。**12,179 stars、2,013 forks、MIT、2025-07-08 建仓、11/20 最后提交、49 个 open issue、个人项目（zhouxiaoka）**
- 差异化：多数「长转短」工具只做切点，它把**交付物一次做全**——竖屏成片 + 字幕 + 封面 + 发布文案，直接对应四个平台的规格；且是本地桌面端，素材不用先上传到别人的云
- 用在哪：把公司已有的长内容（直播回放、访谈、幕后花絮、演员采访）切成投放用的短素材，比重新拍便宜一个量级；也能用来做「同一集剧切 10 条不同钩子的投放素材」
- ⚠️ 「软件免费、云端模型按量计费」——切点判断与字幕走的是付费模型，成本要自己先算；成片质量高度依赖 ASR 准确率，方言与嘈杂环境会掉得厉害；多平台同发时注意去重，同一素材原样铺四个平台容易被判低质
- 源：GitHub zhouxiaoka/autoclip（11/21 实测 star / MIT / 提交时间），11/21

**mjmirza/app-store-compliance（备选·上架前的拒审清单：117 条被拒模式 + 95 个监管截止日）**
- 是什么：一份开放的 App Store / Google Play 过审手册，加一个提交前自检工具：**117 条有记录的被拒模式及修法、隐私清单（Privacy Manifest）与 Data safety 检查项、95 个被跟踪的监管截止日**（EU AI Act、DSA、COPPA、各州年龄法），并带一个给 AI 编码 agent 用的 skill。**2,735 stars、175 forks、2026-06-06 建仓、11/19 最后提交、32 个 open issue、个人项目（mjmirza）**
- 差异化：网上多数「过审攻略」是博客和经验帖，它把拒审理由做成了**可勾选的清单**，并且把「法规截止日」当成会过期的数据在维护——这一层是别的清单没有的
- 用在哪：你那几个产品方向（AI UI 生成器、记忆相机、手机寄生宠物）如果要上 iOS，第一次被拒的成本通常是一到两周；提交前先过一遍这 117 条，能省掉最蠢的那几类（隐私声明缺失、账号删除入口缺失、订阅条款不清）；微信小程序不适用 App Store 规则，但「隐私与数据安全」那一节的检查逻辑可以直接借用
- ⚠️ 仓库 license 显示为 NOASSERTION（非标准许可），商用前必须自己读 LICENSE 原文；清单以平台「最新官方政策」为准，仓库自述也这么写，别拿它当法律意见
- 源：GitHub mjmirza/app-store-compliance（11/21 实测 star / 提交时间），11/21
