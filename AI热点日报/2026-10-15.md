## 一、AI 资讯（12 条）

**P0｜新模型 / API 价格 / OPC 可用工具**

**1. Sonnet 5.5 缓存读取价 $0.20→$0.10（10/14 价格快照）**
- 变了什么：JSONHouse 10/14 全量快照显示，Claude Sonnet 5.5 的缓存读取价从 **$0.20 降到 $0.10/M**——这是 8 月以来首次「触达一个已 pin 模型 id」的降价，此前每次降价都绑在新模型 id 上、老用户吃不到。
- OPC 视角：你 OP- 前缀模型档位走缓存命中场景，等效成本再下一档；长上下文 RAG / 多 agent 编码这类高频缓存复用任务直接受益。
- 来源：https://www.jsonhouse.com/posts/llm-api-pricing-2026/

**2. ⚠️ Anthropic 4.7+ 分词器隐性加价：同文本多产约 30% token**
- 埋雷：JSONHouse 指出，Claude 4.7 及以后模型的 tokenizer 对同样英文文本多产 **约 30% token**，16 行 Anthropic 定价里有 11 行因此实际每页英文比标价更贵。
- OPC 视角：标称单价≠账单单价。算「每个成功任务成本」时要把分词膨胀算进去，尤其英文长文 / 代码生成场景，Haiku 5.5、DeepSeek 这类非 Anthropic 模型反而更划算。
- 来源：https://www.jsonhouse.com/posts/llm-api-pricing-2026/

**3. Fish Audio 开源 TTS「Drama 3 Preview」35B MoE 登顶，价格仅 Eleven v4 的 1/5（10/14）**
- 变了什么：Fish Audio 的 35B MoE 模型 Drama 3 Preview 登顶开源 TTS 榜，**发音鲁棒性 93.2%**、支持 **83 种语言**，价格只有 ElevenLabs v4 的 **五分之一**，权重直接可下载。
- 跟你业务直接相关（短剧配音 / 出海）：西/葡/法/日/韩多语区配音有了更低价的本地可部署通道，单价压到 ElevenLabs 的 1/5、且权重自持不喂第三方，适合你短剧出海量产配音。
- 来源：https://aitop.news/daily

**4. Liquid AI 发 LFM2.5-24B-A2B：开放权重推理 MoE，24B 总参 / 2B 激活 / 131K 上下文（10/14）**
- 变了什么：Liquid AI 发布 LFM2.5-24B-A2B，开放权重推理 MoE，**24B 总参数、2B 激活、131K 上下文**，在 Apple M5 Max 上解码 **184 tok/s**，agent / 工具调用任务对标 Qwen3.6-35B-A3B。

## 三、小而美产品（2 主推 + 1 备选）

**主推 1｜FocusWrite —— 本地优先的写作 app**
- 是什么：local-first 写作应用，主打专注模式，文稿存本地、不强制上云。
- 差异化：本地优先 = 数据留本机，写作过程不出云；和你的「数据不出本机」底线一致。
- 具体用在哪：写 PRD / 日报 / 需求文档 / 飞书草稿，离线也能写，文件自己管。
- ⚠️ 偏差如实标注：Product Hunt 10/14 新品，团队规模未逐一核实；Web App 形态，自持性看具体实现，按需引入。
- 来源：https://www.producthunt.com/

**主推 2｜Edgee Mod for Claude Code —— 在 Claude Code 里用任意模型**
- 是什么：Claude Code 插件，让你在保留 Claude 套餐的同时，把任意模型接进 Claude Code 工作流。
- 差异化：直接呼应本期价格战主线——把 Haiku 5.5 / DeepSeek 这类便宜模型塞进 Claude Code，难任务才丢强模型，账单可控。
- 具体用在哪：你 Codex / Claude / DeepSeek 多后端切换的编码链路，用它对简单任务走低价模型、压低每任务成本。
- ⚠️ 偏差如实标注：PH 10/14 新品，偏开发者工具，团队规模未核实，自持性看授权方式。
- 来源：https://www.producthunt.com/

**备选｜OpenScreen 2 —— 开源 AI 视频剪辑**
- 是什么：开源（Open Source）工具，录屏后由 AI agent 自动做剪辑。
- 差异化：录屏 + AI 自动剪一体，开源可自部署。
- 具体用在哪：短剧宣发 / 投放素材快速出片——录一段后台或素材，agent 自动粗剪出多版。
- ⚠️ 偏差如实标注：PH 10/14 新品，团队规模未核实；开源但自持要看部署，量大优先本地 + 人工校对。
