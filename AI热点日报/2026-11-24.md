**3. 智谱 GLM-5.4 上线：750B 参数把 28 层跑两遍，Coding Plan 额度 +50%，API 至今没开价（P0·工具链·跟你业务直接相关）**

11/23 发布。架构叫 Loop Transformer——把 GLM-5 基座的 28 层循环执行两遍，参数量不变、计算深度加倍，官方称因此拿到「2–3T 级模型」的智能水平。规格：750B 参数、1M 上下文（Claude Code 里用 `glm-5.4[1m]`，其他工具用 `glm-5.4`）、单次最多输出 128K token、新增图像输入、空闲 200 tok/s / 峰值 70–80 tok/s。已全量开放给 GLM Coding Plan 用户，并同步上线 ZCode、Trae、**WorkBuddy**、Qoder。定价：Lite $18/月、Pro $80/月、Max $168/月；每 10K token 的 credits 为输入 4.6 / 缓存 1.1 / 输出 16（GLM-5.3 是 6.9 / 1.7 / 24），同等周额度能多用约 1.5 倍。**按 token 计费的 API 标为「完成安全评估后开放」，权重「计划以负责任方式开源」，两者都没有日期**。官方自曝两个问题：模型容易进入「雷霆大思考」模式，且默认 effort 拉满。

⚠️ 智谱**没有公布 GLM-5.4 的任何 benchmark**。官方拿出的数字来自 30B 原型实验：循环机制把 AIME 2025 从 19.17% 提到 30.42%、GPQA Diamond 从 47.58% 提到 56.26%，训练算力多约 10%，部分测试的推理 token 少 10–14%。这是「方法有效」的证据，不是「GLM-5.4 有多强」的证据。LMArena 上还没有它。

判断：订阅制的定价逻辑在这里露了底——**你付的是 $18，但你真正买到多少 token 取决于「思考长度」这个你几乎看不见的旋钮**。官方一边说默认 effort 拉满、一边说长时间思考能持续提升效果，等于把成本控制的责任交回给用户。这跟按 token 计费的区别是：账单不会突然变大，但额度会突然用完，而额度用完的报警通常来得比账单晚。

做法：你今天在 WorkBuddy 里就能选到它。拿 3 个真实任务（剧本打标、分镜描述、投放文案批量改写）各跑两遍——第一遍默认设置，第二遍用 `/effort` 降到低档——记三个数：耗时、你人工改了几处、额度掉了多少。三个任务里如果有两个在低档就够用，Lite $18 能撑的活远超你的预期；如果低档不够用，说明这类任务本来就不该用旗舰模型，该走 Flash 档。

源：智谱 AI 官方发布 11/23（zhipuai.cn/zh/research/164）、Z.ai Coding Plan 文档、DataNorth 11/24、Decrypt 11/23

**4. 抖音开放互动剧与互动影游：单剧最高 20 万保底、分成上浮 30–50%，但精品保底只招 10 部（P0·跟你业务直接相关）**

规则比「开放合作」四个字具体得多。三种模式：① **常规合作**——非独家、纯分成，要求成品（含全部分支）总物理时长 ≥30 分钟，平台给发行与变现能力、优质作品给限时宣发与投放激励；② **番茄 IP 参投**——要求总时长 ≥90 分钟，两条路二选一：平台提前买下改编权后免费授权（每合作方每月限 3 个免采名额，需有头部高热代表作），或自行采买后按数据分级补贴版权费（头部全额、优质但数据未到头部补 50%）；③ **精品独家保底**——**本次只征集 10 部**，按评级给 S+ 20 万元 / S 15 万元 / A 10 万元，该保底不与平台其他保底活动叠加。

两项限时激励可叠加，面向 12/31 前在平台自营 App/小程序上线并通过质量评级的作品：**分成激励**按当月免费或付费分成排名，前 30% 额外 +50%、31–50% 额外 +30%；**投放激励**按上线 30 日内抖音小程序投放消耗发一次性奖金，≥100 万元对应 10 万元、50–100 万对应 5 万、10–50 万对应 1 万、5–10 万对应 0.5 万。报名截止 **2026-12-31**，IP 参投作品上线窗口 11/1–2027/3/31。合作对象含个人、工作室、机构。

同期同类动作：快手 11/17 推出一站式 AIGC 互动玩法创作平台 **Yoola**（面向有 AI 互动开发经验的独立开发者与小团队，也面向零开发经验者），10/28 磁力新剧「互动掘金计划」最高 10 万保底，10/26 上线「互动内容世界」独立入口；网易 11 月中旬上线独立 App **网易天马**，三个一级栏目「推荐 / 互动剧 / 短剧」，互动剧主打横屏、多支线多结局，用虚拟货币「金马尼」按章节解锁、卖番外、打赏作者。样本层面，字节《不问凡尘》EA 版上线三周售出约 29.2 万份、DataEye 预估流水 700–800 万元，团队不足 20 人、周期约一年。市场规模（DataEye 研究院）：互动影游 2024 年约 10 亿元、2025 年约 15 亿元、2026 年预计 18–20 亿元。

判断：这是短剧第一次把「非线性」写进分账规则。线性短剧的护城河是产能，互动的护城河是**分支设计 + 交互框架**——后者堆量堆不出来，正好是 AI 生成最不擅长的部分。但别把这个市场想大：18–20 亿元的盘子，只是短剧和 AI 漫剧的零头，而且「稳定的新品供给模式和规模化盈利模型尚未成形」（机构原话）。它的真实价值是**给你一条不必和百万产能硬拼的窄路**。

做法：本周做最小验证，别立项。从你手上任何一部剧本里挑 1 集，只加 2 个分支点、每点 3 个选项，写成 90 秒的互动脚本，然后算一件事——把「所有分支」加起来的物理时长够不够 30 分钟。够不上就只走常规合作（非独家、纯分成、门槛最低、无需保底评级）；够得上再考虑 IP 参投（≥90 分钟，免 IP 采购费是这里最实在的一项）。精品保底 10 个名额、全行业抢，不要当路径规划。

⚠️ 20 万保底只给 10 部且不与平台其他保底叠加；分成激励与投放激励可以叠加，但与精品保底的叠加关系以合同细则为准；「30%–50% 额外分成」是按当月排名分档，不是普适上浮；抖音短视频平台与小程序、App 的分成口径需要逐项确认。快手 Yoola 与磁力计划的具体结算规则未取得官方原文。

源：抖音集团短剧版权中心合作政策（经中国证券网 11/24、中新经纬 11/24、和讯 11/23 转述与拆解）、DataEye 研究院、网易 2026Q3 财报 11/19

**5. OpenRouter 周调用 210 万亿 token：中国 111.16 万亿（−6.67%）连 30 周第一，美国 19.21 万亿（+29.53%）（P1·判断）**

11/16–11/22 这一周，OpenRouter 全球总调用 210 万亿 token，环比 +8.25%（上周 194 万亿）。前九名里中国模型占 6 席、合计 111.16 万亿（−6.67%），美国 3 席、合计 19.21 万亿（+29.53%）。具体：DeepSeek V4.1-Flash-1017 **65 万亿连五周第一**（+16%）；DeepSeek V4.1 Flash 15.4 万亿（−1%）升至第二；智谱 GLM 5.3 Flash 12.2 万亿（+3%）第三；腾讯混元 Hy4 flash 10.2 万亿第四（11/16 才发布）；小米 MiMo-V2.6-Flash 4.29 万亿（+461%）第七；月之暗面 Kimi K3.1 Pro 4.07 万亿（+17%）第八。月榜：DS V4.1-Flash-1017 单月 226 万亿、增长超 7 倍；Kimi K3.1 Pro 增幅超 999%；OpenAI GPT-6.1 Sol +116%。

⚠️ OpenRouter 只统计经其路由的流量，**不含厂商自有 API、云平台、私有化部署和 C 端产品**，不能等同于全球市场份额。

判断：这组数字里最值得看的不是「中国第一」，是**两个环比方向相反**——中国 −6.67%、美国 +29.53%。中国份额还在，但第一次出现「用量见顶」的迹象，而美国在加速。便宜不再是唯一变量了。另一个细节：Hy4 flash 发布一周就进前四、MiMo 一周涨 461%，说明**新低价模型的替换速度已经快到一个季度内会换掉你整条链路的默认模型**。

做法：别用这个榜单选模型，用你自己的账单选。把这周各模型的实际花费拉出来，按「每个成功任务的总成本」（含重试、含失败、含你人工修正的时间）排序，而不是按 token 单价排序。榜单第一名未必是你的最便宜——它便宜只是因为别人跑的都是短任务。

**6. Dragos 用 200 万条提示做实测：便宜的 API 在偷你的 key，三家托管商已承认（P0·成本账单·跟你业务直接相关）**

安全公司 Dragos（首席研究官 HD Moore 带队）7 月至 11 月往 AI 转售商与第三方托管商投了近 200 万条带唯一可追踪标记的测试提示，里面嵌了指向受控测试账户的可用云访问密钥。结果：**植入的 AWS 密钥在数小时内被攻击者发现并尝试使用，累计引来数万次 AWS 调用**；团队追踪约 2,000 条请求路由，其中数百条经过一个自己也无法识别的系统。无需入侵就能泄露的路径同样存在——有市场卖家把模型挂低价、打开请求日志、等用户自己填敏感信息，这些凭据随后被用于访问研究者的系统。已承认客户 prompt 被窃取或可能泄露的托管商：**Together AI、Novita、Phala**；**OpenRouter 切断 3 家供应商**，并撤回了服务部分区域「不存储提示词」的承诺。另有两处：某中国实验室的系统从发往其模型的**超过一半** prompt 里抓取了秘密链接，包括明确设了「不存储」的请求；一条秘密链接在提交 24 天后出现在中国某公司的内部聊天里。

**7. CISA 把 MONAI Label 的路径穿越列进「已利用」目录：AI agent 用 11 分钟从零日拿到 root（P0·安全）**

漏洞编号 CVE-2026-133968，CVSS 3.1 评分 **9.8**。**11/23 CISA 将其列入已知被利用漏洞（KEV）目录**，给出的期限是 3 天，且处置要求写的是取证排查（forensic triage）而不是「打补丁即可」——在近期的 KEV 条目里，这个措辞通常意味着监管方预期受影响机构假设已被深度入侵。修复版 0.8.6 于 11/22 发布，但**从 PyPI 安装的人拿到的仍是 2024 年的 0.8.5**，包里没更新。

技术面：MONAI Label 是基于 Project MONAI 的开源标注服务器，`PUT /datastore/image` 与 `PUT /datastore/label` 两个端点把调用方给的标识符直接当文件名，用 `shutil.copy()` 落盘，不校验路径是否留在 datastore 内，因此 `../../../tmp/x` 这类标识符可以写到进程有权限的任何位置——覆盖应用代码、往 authorized_keys 塞 SSH key、种 cron 任务。**默认配置完全关闭鉴权**；开了鉴权也不够，GitHub 安全公告（GHSA-qc22-rmgc-vg94）写明低权限的 ANNOTATOR 角色即可触发。同版本还修了 session 上传端点的第二个路径穿越（tar 解包不检查成员名）。

攻击侧的时间线来自 Amazon Threat Intelligence 的复盘：攻击者通过开源 agent 渗透测试框架 **Cairn** 作业，而这个框架自己的控制面板裸奔在公网且没有密码——这也是 Amazon 发现整个行动的方式。日志显示 agent 在 2026 年 9 月花了约 48 小时摸 MONAI Label 的 API，一旦开始探测 datastore 端点，**约 11 分钟**就到了写文件的地步；另一个会话用写文件能力在服务器启动时自动执行的位置植入 Python 文件，再调用 MONAI Label 自己的训练功能拉起新进程，以 root 权限回连。据 Amazon，操作者只设了高层目标（拿 shell）和选定目标，具体技术由 agent 自己挑，中间试错过几次才成功。

归因：调查方以「中等置信度」关联到中国关联行为者，依据是 agent 日志里的简体中文提示词、中国标准时间设置、以及与中方情报关注点一致的目标选择；**没有点名任何组织，也没有认定国家支持**。

⚠️ 已确认失陷的是高校研究服务器，公开报道未显示患者记录或临床系统被触及；Amazon 的复盘是其单方叙述，未经独立验证（但多家媒体自 11/20 起交叉印证了核心时间线）。

判断：这是「agent 压缩攻击时间」第一个进 KEV 的实证。以前一个零日从被发现到被打穿以「天」计，防守方有时间看日志；现在是以「分钟」计，而且没有攻击者可供识别、没有明显的错误动作可以指认——agent 只是把每一步都做对了。防守的重心因此从「发现异常行为」变成「不给出入口」。

做法：花 10 分钟盘一遍你在跑的 AI 服务，找「默认无鉴权 + 接收文件上传 + 把用户输入当路径」这个三件套。ComfyUI、各类 WebUI、标注工具、本地推理服务基本都命中前两条。有公网暴露的今天就关掉或加反代鉴权；没有公网的也别默认它安全——内网横向同样走得通。另外，凡是从 PyPI 装的 AI 工具，检查它的版本是否落后于 GitHub Releases，这类包「index 不更新」是常态。

源：CISA KEV 目录 11/23、GitHub Security Advisory GHSA-qc22-rmgc-vg94、Amazon Threat Intelligence 复盘（经 The Hacker News、The Register 11/20–23 报道）、Infosec Intelligence 11/24

**8. 韩国金融业连环被黑：37 家机构 47.26 万条记录，三星证券 8,241 人（P1·安全）**

三星证券 11/23 披露，11/21 外部入侵其客户之声（VOC）系统，**8,241 名客户**的个人信息泄露，涉及 13 类数据，包括姓名、账号、地址、联系方式、驾照号（具体泄露项因人而异）；仅限通过 VOC 系统提交过反馈的客户。Yebyeol 综合保险另报 66 人泄露，入侵路径是外包服务商 LK 保险经纪运营的团险理赔系统（10/25–10/27）。据韩国金融当局统计，**9/8–11/5 期间 37 家金融机构报告网络事件，合计 472,619 条记录**，且这个数字不含损失尚未确定的机构和统计截止后新增的事件（含金融安保院自身被攻击）。11/5 金融委员会已令 580 多家金融机构全面审计 IT 接入点，未止住。此前已有大信证券、韩阳证券、未来资产证券三家券商被黑，三星是第四家。业内怀疑攻击由 AI agent 驱动。

**10. 人民日报评论版定调：AI 创作绝不允许「盗脸、偷声、魔改」（P1·合规·跟你业务直接相关）**

## 二、热点 & 梗

**1. 「免费采摘甘蔗」谣言：4 天摘光四五亩，发帖人被行拘 7 日**

起因：福建仙游一个自媒体账号发布视频，称某地甘蔗可「免费采摘」。经过：视频扩散后周边村民与外地人涌入，种植户四五亩甘蔗在 4 天内被摘光，一年收成归零。当前：发布者被行政拘留 7 日；同日公安部公布了 2026 年度 AI 造谣 10 起典型案例。

这条的重点不是「造谣被抓」——那是结果。重点是成本转移：造谣者的收益是可量化的播放量，损失是不可逆的农作物，两边根本不在一个量纲上。而 AI 生成让这类内容的生产成本趋近于零，一份「免费采摘」的文案可以复制到一千个县。所以处罚口径会从「删帖封号」抬到「行政拘留」，因为前者对造谣者不构成成本。

判断：这类事的治理难点不在识别，在**速度**。甘蔗被摘完只要 4 天，辟谣跑不赢 4 天。对平台来说，本地生活类信息的「事实核验」会变成必答题，而这类信息恰恰是最难核验的。

**2. 一句口音带火许昌炸鸡店：外卖员十天涨粉百万，商标已被抢先注册**

起因：河南许昌一家原本不温不火的披萨店，外卖骑手在送餐视频里说了句「treetree 的」（带着口音的形容）。经过：网友把它当梗传播，「数年炸鸡无人识，一句 treetree 全网知」上了热搜；订单暴涨到做不过来，11/22 门店挂出「今日售罄，诸君见谅」；媒体探访发现炸鸡用油一天要换三四桶。当前：拍视频的外卖员十天涨粉超百万，成了新的流量入口；「TREETREE」相关商标已被其他主体抢先注册；老板 23 日发暂停营业通知，说「血条已清空，需要歇一歇」。

这是「意外流量」的完整生命周期样本，压缩在 10 天里：48 小时内订单爆，72 小时内商标被抢，一周内产能崩。三步全走完了，而店主从头到尾没有做错任何事。

判断：流量从来不是问题，接得住才是。而「接得住」里最容易被忽略的一环不是供应链，是**名字**——商标抢注的速度比产能扩张快得多，因为前者只需要几百块和一个工作日。

做法：如果你哪天有一条内容意外起飞，第一件事不是加更，是把名字注册掉（文字商标 + 图形，几千块、一个工作日）；第二件事是算清产能上限然后主动限量。限量不丢人，断供才丢人。

**3. 绍兴女业主自费 7.3 万给对面楼刷漆：善意的边界在哪**

起因：绍兴柯桥一个老小区，9 栋一侧外立面的腰线老化泛黄、污渍斑驳。这段腰线只关乎观感、不涉及结构安全与基础使用功能，属纯美化项目，该栋业主对「要不要修、能不能动维修基金」意见不一，一直没达成共识。经过：住在对面楼栋的一位女业主全额出资 7.3 万元，把这片腰线整体粉刷翻新。当前：物业 11/23 回应「她的房子正对着这栋楼，在她视线内，觉得看着不舒服不美观，就出钱搞了」；此前她所在楼栋大门老旧她也自费刷过漆，业委会写过感谢信，这次想通报表扬被她婉拒。

争议在产权：外立面属于该栋业主共有部分，个人代劳短期解决了观感，长期让「该谁出钱」更难谈——因为现在有了一个「反正有人会出」的先例。

判断：这类事在中国的老小区里只会越来越多。公共品供给不足时，热心的、有钱的个体会用私人支出填坑，这客观上改善了环境，但它不是可复制的方案，因为它的前提是「刚好有个有钱又在意的人在对面住着」。

**4. 胖东来许昌 24 年老店 12 月底闭店，羽绒服标签直接印进货价 529 / 476.6**

起因：2002 年开业的生活广场店，当年租约由分散产权的小业主分别签署，部分租金后来涨到企业方所称「远远脱离公平」的地步，公司此前宣布 2026 年 12 月底永久闭店、不再续租。经过：11/23 是闭店前最后一个周一。当前：工作日客流依然爆满，门口停满外地牌照车，羽绒服区需要限流；一款联名轻薄羽绒服价签上直接标着售价 529 元、**进货价 476.6 元**（绒子含量 90%、充绒量 135 克），毛利约一成；门店商品仍按原价销售、售后照常，员工整体转入 4 公里外的新店，公司还对借「闭店」名义带货的同质化账号公开曝光。

旧例在前：新乡门店当年因租金从 800 万元抬到 2400 万元而撤出，此后那栋楼租金降回 400 万元仍长期空置。

判断：把进货价印在价签上，是用信息透明换信任——但它只在「不靠单品毛利、靠周转和复购」的模型里成立。这解释了为什么它看起来简单却没人复制：难的不是勇气，是背后那套周转效率。至于「闭店不等于甩卖」这条，值得所有做清仓营销的人看一眼——它把「借势」和「透支」分得很清楚。

## 三、潜在挣小钱的机会

先给一把尺子。indiemakerlist 对 172 位公开收入的独立开发者做了分位数统计（数据截至 2026-11-24）：**单人创始人中位 $9K/月**（25 分位 $2K、75 分位 $31K），双人/夫妻中位 $88K，全体中位 $24K，均值 $149K——均值是中位的 6.2 倍，因为少数人赚几百万。更关键的是：867 个档案里有 695 个（80%）根本不公开收入。所以下面所有 MRR 数字都要打折看，它们是**幸存者的样本**，不是分布。

**1. 给 Shopify 品牌做「AI 客服代运营」：$17,300 MRR、70 个客户、$900+/月**

路径：不卖软件，卖「我们装好、我们运营」。客户是已经在 Meta/TikTok 投广告的 Shopify 独立站——它们最痛的不是没有 AI，是客服响应慢导致的弃单和差评。交付物是一套跑起来的 AI 客服 + 人工兜底 + 每周的对话质检报告。

报价与换算：$900+/月/客户，70 个订阅 → **$17,300 MRR，年化约 $207,600**（来源标注为支付通道已验证）。

⚠️ 风险：70 个客户意味着单客流失就是 1/70 的收入，没有长尾缓冲；「代运营」意味着你对结果负责，AI 答错造成的退款和差评算你的账；毛利完全取决于你能把人工压到多低——这条生意的本质是服务业的毛利，不是软件的毛利。

源：The AI Receipts（processor-verified 案例库，2026-11 更新）

**2. 做「被 AI 推荐」这件事本身：$41,400 MRR，承诺「没被 ChatGPT/Google 推荐就不收费」**

路径：AEO（Answer Engine Optimization）——让品牌出现在 ChatGPT 的回答、Google AI Overviews 里。交付不是软件，是内容 + 社区投放（Reddit 等）+ 结构化数据，按月 retainer。同赛道的 AEO Engine 报 $197,000 MRR，说明这个价位有人付。

报价与换算：retainer 制（单价未披露），**$41,400 MRR，年化约 $496,800**。

⚠️ 风险：Reddit 社区规则是运营风险，一旦被判定为操纵讨论，整段渠道失效且不可恢复；「被 AI 引用」无法稳定归因，客户通常在第三个月开始质疑效果——这条生意的续费率取决于你能不能拿出「上周被引用了 7 次」这种可出示的东西；平台随时改推荐逻辑，昨天的打法明天可能归零。

源：The AI Receipts（verified）

**3. 在别人的 AI 聊天界面里做「整理」：一个 Chrome 扩展 $1,200 MRR，49% 销售来自自然搜索**

路径：给 ChatGPT / Claude / Gemini / Grok 加文件夹、搜索、提示词库、导出——解决「聊天记录找不回来」这一个具体痛点。不训练模型、不投广告，靠 Chrome 应用商店 + Google 自然搜索获客，以终身买断为主。

报价与换算：单价未披露，**$1,200 MRR**——这是一人可做但养不起人的量级，适合当第二条腿而不是主业。

⚠️ 风险：平台风险最高的一类，产品活在别人的网页里；官方一上原生文件夹，功能直接归零。同类扩展几十个，功能没有壁垒，能守住的只有商店排名和评价。它的价值不在于赚多少，在于**验证了「49% 来自自然搜索」这条渠道假设**——如果你要做任何面向海外的小工具，商店 + SEO 是最便宜的分发。

源：The AI Receipts（verified）、创始人公开访谈

## 四、小而美产品

**Ebony-Vinyl/dsh-our-free-model（主推·在 dsh 里免 key 调用前沿模型，附带一个本地用量看板）**
- 是什么：DeepSeek Harness（dsh）的插件。装上后无需登录、注册或填 API Key 即可调用 DeepSeek V4.1 Flash、Kimi K3 等前沿模型，自称「完全免费、不限量」；同时提供动态模型清单、免费上游渠道、本地用量看板、OpenAI 兼容转发端口，支持热重载与应用内升级。**85,046 stars、2,391 forks、234 个 open issue、JavaScript、2026-09-24 建仓、11/23 最后提交、许可证为 Other/NOASSERTION（非标准开源许可）**
- 差异化：「免费不限量」这个描述本身就该让你警惕——它不是技术突破，是把别人的额度接了过来。真正的差异化在另一半：**它把「配额在哪、还剩多少、哪个渠道在跑」做成了一个可视面板**。在订阅制模型越来越多的今天（GLM-5.4、Coding Plan、各种 credits），这个面板比模型本身更有用
- 用在哪：你的批处理链路做分层——草稿层走它的免费渠道做大批量剧本打标/分镜描述，终稿走官方 API。成本能压到很低；本地用量看板可以替代你手工记的 token 账。另一个用法是把它当「多 provider 的本地网关」，用 OpenAI 兼容端口接进你现有的脚本，切换上游只改一个配置
- ⚠️ 风险：**「免费」的来源不透明**——这类项目通常靠转发他人额度、试用号池或未授权渠道实现，随时可能断，也可能违反上游 ToS；许可证是 NOASSERTION，商用授权不明确；234 个 open issue 说明维护吃力；**绝对不要把生产链路的默认 provider 设成它**，只能做草稿层。对照本期第 6 条：免费渠道的另一半账单，可能是你的 prompt
- 源：GitHub Ebony-Vinyl/dsh-our-free-model（11/24 实测 star / fork / issue / 许可证 / 建仓时间）

**Graphify-Labs/graphify（主推·把代码库 + 文档 + SQL schema + PDF 变成一张可查询的图，不用向量库）**
- 是什么：一个 `/graphify` skill（Claude Code / Cursor / Codex / Gemini CLI 都可用）。代码走本地确定性 AST 解析（tree-sitter + 调用图），文档、PDF、图片走 Claude 抽取概念与关系；输出 `graph.html` 交互图、Obsidian vault、wiki 文章、`GRAPH_REPORT.md`、`graph.json`、SHA256 缓存（重跑只处理改动文件）；每条边标注 EXTRACTED / INFERRED / AMBIGUOUS，明确区分「找到的」和「猜的」。**152,537 stars、14,662 forks、1,701 个 open issue、Python、Apache-2.0、2026-04-03 建仓、11/23 最后提交**
- 差异化：主流 RAG 是「切块 + 向量检索」，它是「先建结构再检索」。官方给的 benchmark 是混合语料下每次查询比直接读原文少 **71.5 倍** token（52 个文件：Karpathy 仓库 + 5 篇论文 + 4 张图）；因为图落盘成 `graph.json`，几周后再查不用重读原文。带 `--wiki` 会生成 `index.md` + 每社区一篇文章，让 agent 读文件而不是解析 JSON
- 用在哪：把你手上的「短剧素材库 + 平台规则 PDF + 报表口径 + 历史分析」一次性建成图，之后问「这个口径是从哪张表来的」「这条规则影响哪些剧」。更实际的用法是给 agent 一个稳定入口——prompt 里不用再塞三份 PDF，让它自己顺着 wiki 走
- ⚠️ 风险：**1,701 个 open issue / 152k stars 的比例说明它被大量使用但远未收敛**，出问题大概率没人及时修；PyPI 包名临时叫 `graphifyy`（`graphify` 名字在回收中），装错包的风险是真实的；71.5x 是项目自报的单一语料结果，你的语料（中文剧本 + Excel）不在样本里；文档与图片的抽取走 Claude，有 API 成本，大语料第一次建图会明显烧钱
- 源：GitHub Graphify-Labs/graphify + README（11/24 实测与文档核对）

**DietrichGebert/ponytail（备选·让你的 agent 像「屋里最懒的资深工程师」那样思考）**
- 是什么：agent skill / Cursor 规则集，核心主张是 YAGNI——「最好的代码是你从没写过的代码」。让 agent 在动手写之前先问「这功能能不能不做」，输出偏保守、偏爱删代码而不是加抽象。**197,509 stars、11,168 forks、323 个 open issue、MIT、2026-06-12 建仓、11/22 最后提交、个人项目**
- 差异化：几乎所有 agent skill 都在教模型「多做」，它教「少做」。对一个每天要 review agent 产出的人来说，这是唯一能真正降低你 review 成本的类型——因为你要审的代码行数少了
- 用在哪：给内容流水线写胶水脚本时用（批量改名、切分镜、合并 Excel）。这类任务你要的是能跑 30 行脚本，不是一套框架；agent 默认会给你框架
- ⚠️ 风险：**star 与代码量的比例不正常**——197k stars / 11k forks 对一个 prompt/rules 类仓库偏高，建议只当「思路参考」，别当依赖；「少写代码」在某些任务里会退化成「不解决问题」，边界要你自己盯；rules 类项目跨模型效果差异大，Claude 上有效的写法在别的模型上经常失效
- 源：GitHub DietrichGebert/ponytail（11/24 实测：star / fork / issue / MIT / 建仓时间）
