## 三、小而美产品

**主推 1 ｜ OpenCompanion**
- 是什么：开源（MIT）本地桌面应用（Tauri / Rust + WebView），Windows / Linux / macOS 原生，**无账号、无云、无遥测**。把 Claude Code / Codex CLI / OpenCode 等多个 AI 编码 CLI 会话统一在一个面板，哪个在等批准一眼可见，桌面或同 Wi-Fi 手机都能 Approve / Deny。
- 差异化：你 WorkBuddy / Codex 多 agent 工作流的「前台 + 离座遥控器」——会话卡在权限提示上时不再靠盯着终端，手机两下就批；自带 cron 式自动化，可定时跑 headless 任务。
- 具体用在哪：你同时跑多个项目目录的编码 agent 时，集中监控 + 手机批批准，把「agent 等决策、人去开会」的死等时间压到零。
- ⚠️ 偏差：安装包**未签名**，首启需手动允许一次；手机链路是本地明文 HTTP，**外出用 Tailscale 之类 VPN** 才安全；作者单人（Yusup Supriyadi），Windows 每日手测。
- 来源：producthunt.com/products/opencompanion（10/7  launch，MIT）

**主推 2 ｜ Databench by Alkera**
- 是什么：开源（Apache-2.0）**自托管**数据协作工作区，人 + agent 同处共享 SQL / Python notebook 与 chat，可并行起多个 agent 探索假设，每个结果可溯源到数据与代码。
- 差异化：每动作带**权限门禁**（read / write / destroy / egress / exec），用自己的 Anthropic / OpenAI key，**数据不出你的网**；SQL 解析成语法树，藏在 CTE 里的 DELETE 也按删除计。
- 具体用在哪：你 WorkBuddy + 子智能体做数据产品的统一协作台——敏感数仓查询留本机 / 自托管，比把数仓凭据交给云端 BI 稳。
- ⚠️ 偏差：YC S26 极早期（开源 repo 仅 1 天）、自托管是真运维活、浏览器为主、IDE / CLI 待出；Alkera 团队维护非单人作品。
- 来源：github.com/AlkeraAI/Databench（10/7 launch，Apache-2.0）

**备选 ｜ Rool**
- 是什么：隐私优先的「云端 AI 机器」——每个用户一台托管在欧盟（芬兰）的私有 Linux VM，文件 / 对话 / 记忆一体，不卖数据、不拿你内容训练、可随时导出。
- 具体用在哪：不想把真实工作交给第三方时的隐私 AI 工作台；免费层 2 台机器各 1GB、240 信用 / 天。
- ⚠️ 偏差：**云端非本地**（EU 托管，日志留 30 天、支持可访问）、免费层约 20–25 次推理 / 日、不能自选模型；属 freemium 云而非买断 / 纯自持，仅作备选。
- 来源：producthunt.com/posts/rool（10/7 launch，LIGHTPOST ONE / 爱尔兰，早期团队）
