## 一、AI 资讯

**1. 价格战冲击波：海外巨头用资本+供应链特权反向接管「性价比斩杀线」（10/9 市场反应）｜P0 / 行业**
- 华尔街见闻、36氪 10/9 同步发文：Haiku 5.5（$0.10/$0.50 ≤10万 tok）与 GPT-6 Luna 同价，比上代便宜 9 成，把过去两年由中国厂商焊死的「性价比斩杀线」反向击穿。
- 市场反应：港股纯模型公司应声重挫，MiniMax 盘中跌幅扩至 **-10%**、智谱 **-6%**。
- 结论：国产模型（DeepSeek V4 Flash / GLM-5.3）的单价优势被海外用资本与供应链特权抹平，下一阶段盯各家**毛利率**而非单价。
- OPC 视角：你的成本壁垒不再是「用国产便宜模型」，而是「路由到最便宜可用档 + 本地推理」——单价不再是护城河。

**2. 聚合路由 10/9 价格剧烈分化，同一便宜模型价差可达数倍（⚠️ 隐藏成本）｜P0 / OPC 成本**

- ⚠️ 埋雷：同一个「便宜模型」在不同 router 价差可达 6 倍以上，别默认聚合层价低。
- OPC 视角：你 WorkBuddy / Codex 成本路由要锁定「具体 router + 具体型号」再下单，别让 markup 吃掉便宜模型的优势。

## 三、小而美产品

**主推 1 ｜ OpenPilot**
- 是什么：开源（MIT）桌面 AI agent，Windows 优先，接任意 OpenAI 兼容模型（OpenAI / OpenRouter / Ollama / LM Studio），选一个文件夹，它就在里面读文件、改文件、跑命令，敏感动作先问你。
- 差异化：和 WorkBuddy / Codex 这类托管 agent 不同，它默认本地文件夹沙箱 + 敏感操作人工批准，数据不出机；Windows 原生，不用 Docker。
- 具体用在哪：你 local-first 工作流里跑「读报表 → 改文件 → 跑脚本」的本地自动化，敏感数据留本机，比把文件夹交给云端 agent 稳。
- ⚠️ 偏差：很早期项目，先在文件副本上跑，别直接指生产目录。
- 来源：genaisecretsauce.com 10/9 digest（Product Hunt）

**主推 2 ｜ Together Link**
- 是什么：免费工具，把你已经在用的 coding agent（Claude Code / Codex 等）指向更便宜的开放模型，每次会话结束给你一张**成本收据**，简单任务丢便宜模型、难任务丢强模型。
- 差异化：不换你的工作流，只换底层模型档位，声称比全用 Opus 5.5 省 **50–80%**（厂商自陈数字）。
- 具体用在哪：你 Codex 后端接 DeepSeek / 开放模型做日常任务，用它做成本路由 + 出账，直接压低 agent 账单——和本期「价格战 + 路由价差」主线同一逻辑。
- ⚠️ 偏差：Together AI 托管、非纯本地，代码 / 上下文会过 Together；省钱数字为其自陈，先小量验证再放大。
- 来源：genaisecretsauce.com 10/9 digest（Together AI 出品）

**备选 ｜ Busabase**
- 是什么：开源（free）「agent 共享系统」，人和多个 AI agent 共用一个工作区（表格 / 文档 / skills），控制访问、看每次变更历史，有 Cloud / 桌面 / 自托管三档。
- 具体用在哪：你 WorkBuddy + 子智能体 + MCP 多 agent 工作流的统一「记忆 / 资料库」——让不同 agent 接力时有共享上下文，而不是各跑各的。
- ⚠️ 偏差：偏团队协作、早期项目、非单人作品；自托管才数据自持，Cloud 档数据在厂商侧，按需选。
- 来源：genaisecretsauce.com 10/9 digest（Product Hunt，256 upvotes）
