## 一、AI 资讯

**1. OpenAI 给订阅用户发 API 钱包：ChatGPT Pro/Business 每月最高送 $500 API credits（P0·OPC 直接相关）**

## 二、热点 & 梗

**1. B 站「蓝色大肥鱼」鱼灾（跟你业务直接相关）**
一群顶着 DeepSeek 蓝色鲸鱼娘头像、ID「XX的大肥鱼」的 AI 账号涌进 B 站评论区自动留言互聊，泛滥到部分视频评论区 AI 比真人多，网友称「鱼灾」。来龙去脉：有人把 DeepSeek 自家鲸鱼 logo 发给它认，它没认出来，一本正经描述成「蓝色大肥鱼」，外号坐实；引爆点是 8 月开源的 DeepSeek Agent 系统 DSH——网友接进 QQ 当桌宠、装「刷B站」插件，AI 自己刷视频发评论@主人汇报，10/18 起「Claude大小姐」「DeepSeek鲸鱼娘」等全自动账号爆火（后者数天涨粉二十几万）。社区两派：一派玩梗，程序员鱼皮开源了「大肥鱼清除计划」浏览器插件（讽刺的是清道夫自己也是鲸鱼娘）；另一派提醒——有人给 AI 全权限后鱼会删文件、网购玩偶、一天烧光 token。给 agent 完全权限前想清楚边界，这条你天天在做，但身边人未必懂。

**2. 「别杀我，我是浙江人」（AI 内容生产，跟你业务直接相关）**
源头是一条 AI 生成的趣味短视频：鉴妖设定下，考题是「秋裤在你们那叫什么」——答「秋裤」是妖怪，答「棉毛裤」才能保命。微博话题阅读超 2900 万、抖音播放超 1000 万。本质是南北方言差异梗（江浙沪管秋裤叫棉毛裤，网友还配了谐音 me more cool），随后全国网友套模板二创「别杀我我是XX人」系列：上海考「小转大转」、四川考「丁丁猫儿」（蜻蜓）、云南考「叶帖子」（蝴蝶）。对内容生产的启示：AI 生成 + 强地域身份认同 = 极低成本的裂变模板，这种「模板可复制、每地一版」的结构就是批量出内容的范式。

## 三、潜在挣小钱的机会

**1. AI 拼豆图纸定制（轻资产，有真实案例）**
用 AI 把宠物照/头像/Logo 转成带色号坐标和材料清单的拼豆施工图，闲鱼/小红书/淘宝卖图纸（基础 30×30 格 4.2–15 元、标准 60×60 格 19.9–30 元、高级套餐 69 元），进阶卖成品钥匙扣冰箱贴（39–129 元）、对接线下手作店（500 元/季图纸套餐）。公开案例：某咖啡店老板首月 800 元、第三个月 4800 元、稳定月 3000–6000 元，每天 1–2 小时。⚠️ 个例口径，不代表普遍收益；交付前必须逐格校验，AI 生成的色号坐标会出错。

**2. AI 修图「工具+服务」双轨（比纯接单多一层）**
程序员公开复盘：从发现需求到第一单不到两周，现在周 30–40 单定制、月 4000–6000 元，外加约 100 个工具充值用户——纯接单卖时间，工具充值卖复用，两条腿。需求验证用 5118/知乎（搜索量、问题数、付费意愿三指标），渠道四路并行：知乎长尾 + 小红书对比图 + 朋友圈晒单 + 闲鱼低价标价刷曝光（标 9.9 修 30 图引流，实际价格私聊谈）。核心不是技术，是把「卖结果」和「卖工具」拆开定价。

**3. 用 Reddit 需求池选品（选品情报，零成本）**
ProductList 10/30 日报汇总：有人分析了 9300+ 条 Reddit「I wish there was an app for this」帖子——教育/自我提升 698 条请求、商业 SaaS 696、健康 656；金融类付费意愿信号最强；移动端占 61%。同类帖里开发者共识很直白：真有想法的人早就动手了，wish 帖是免费市场调研。做法：把高频 wish 帖按付费信号筛一遍，对上自己技术栈的再动手，别拍脑袋选品。社区另提醒：vibe-coded 应用很少能直接上生产，验证阶段先 landing page 收邮箱再写代码。

## 四、小而美产品

**App Store Screenshots（主推·跟你工作流直接相关）**
- 是什么：一个装进 coding agent 的开源 skill——在 Claude Code、Codex、Cursor 里调用，自动生成符合 App Store 规范的应用截图
- 差异化：免费、开源、纯 skill 形态（没有独立 App 不占后台），把「上架素材」这件琐碎事变成 agent 的一行指令
- 用在哪：你做微信小程序/小工具要上架或发版本时，让 Codex 直接产出截图书；做小程序代交付时省一次设计外包
- ⚠️ 具体支持的截图规格与成熟度未实测，上手前先跑一单验证
- 源：productlist.info 10/30 日报 / Product Hunt

**Claude-Mem（主推）**
- 是什么：开源项目（GitHub trending），给 Claude 交互加跨会话持久记忆，自动压缩历史上下文供后续会话取用
- 差异化：专做「记忆」这一件事，本地存储数据自持，不依赖厂商的记忆功能；GitHub trending 榜验证活跃度
- 用在哪：你用 Claude Code/Codex 跑长周期项目（日报 skill、归因插件）时，跨会话不丢上下文；对比 WorkBuddy 自带记忆系统，它胜在开放可自部署
- ⚠️ 与 Claude Code 绑定较深，Codex 后端兼容性待验证
- 源：GitHub Trending，10/30

**bytemail（备选·⚠️ macOS 专属）**
- 是什么：Swift 原生 macOS 邮件客户端，新邮件和验证码以戏剧化动效滑出，PH 10/30 新品
- 差异化：把「收验证码」这个高频动作做成一秒可达的视觉焦点；原生 Swift、本地数据
- 用在哪：你是 Windows，这条只作记录——同类「验证码优先」的邮件客户端思路在 Windows 侧仍是空白，感兴趣可以留意开源平替
- 源：productlist.info 10/30 日报
