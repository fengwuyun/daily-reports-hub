**ai-goofish-monitor（主推·AI 闲鱼监控）**
- 是什么：开源项目（GitHub Usagi-org/ai-goofish-monitor）——基于 Playwright + AI 的闲鱼多任务实时/定时监控系统，带完整后台管理 UI，11/4 GitHub 开源趋势在榜
- 差异化：AI 分析层理解商品语义（能判断「这个二手 Switch 价格偏低且成色描述良好」），不是单纯关键词匹配，误报率低一档；监控规则可视化配置，数据全在自己机器上
- 用在哪：盯低价数字产品/设备捡漏、追踪特定卖家上新、价格异动提醒；做闲鱼副业选品的第一手工具
- ⚠️ 需要 Playwright 环境 + 登录态，Python 项目 Windows 可跑；平台风控合规自担
- 源：CSDN GitHub 开源趋势日报，11/4

**Scrapling（主推·Agent 抓取基础设施）**
- 是什么：开源 Python 网页抓取框架（GitHub D4Vinci/Scrapling），定位「从单次请求到大规模爬取全覆盖」，11/4 开源趋势在榜
- 差异化：页面结构变了还能自动定位元素；当 Agent 的外部信息获取标准件，比自己让 agent 现写爬虫可靠
- 用在哪：行情/榜单监控、给本地 agent 工具链补数据入口；常规抓取拿不到再上 REA 逆向，先用它把常规路径跑满
- 源：CSDN GitHub 开源趋势日报，11/4

**floci（备选·本地 AWS 模拟器）**
- 是什么：开源 MIT——LocalStack 的免费替代，本地跑 AWS 模拟器，docker compose up 即用，同端口 4566、同 API；floci 家族还带 Azure/GCP/OCI 本地模拟器
- 差异化：LocalStack 商业化越来越重、免费功能受限，floci 卡位开源平替，无账号、无 token、无付费墙
- 用在哪：自建小服务部署测试时本地模拟云环境，不花钱、数据不出本机
- ⚠️ 需要 Docker；项目较新，成熟度未实测
- 源：CSDN GitHub 开源趋势日报，11/4
