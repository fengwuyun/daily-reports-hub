## 四、小而美产品

**VoiceStudio（主推·全本地开源 ElevenLabs 替代）**
- 是什么：开源 Python 工具（GitHub debpalash/VoiceStudio，10.9k stars），11/6 GitHub Trending 单日 +2.88 万 stars 爆榜；声音克隆、音色设计、视频配音、听写、转写、有声书制作全覆盖，支持 646 种语言
- 差异化：ElevenLabs 的功能清单、零 API 费用、完全本地跑（数据不出机）；对比已推过的 Voice-Pro 更偏「配音工作台」整包交付
- 用在哪：短剧/视频多语区配音实验的第一版底座——批量把中语音轨替换成目标语区音色，跑通后再决定要不要上商业 API；⚠️ CUDA 依赖，需要 N 卡
- 源：GitHub Trending，11/6

**Agent-Reach（主推·给 AI agent 的互联网访问 CLI）**
- 是什么：开源 Python CLI（GitHub Panniantong/Agent-Reach，9.5k stars），11/6 Trending 单日 +5.8k；让 agent 直接读和搜 Twitter/X、Reddit、YouTube、GitHub、B站、小红书，声明零 API 费用
- 差异化：不是爬虫框架是「现成的访问层」——自动选择、安装、诊断可用的访问通道，agent 开箱即用；对比已推过的 Scrapling 少写胶水代码
- 用在哪：市场情报采集（题材/书目/排行榜监控）、投放素材趋势盯梢这类「让 agent 自己去看平台」的自动化流程入口
- 源：GitHub Trending/gitnova 周榜，11/6

**Thysrael/Horizon（备选·AI 新闻雷达）**
- 是什么：开源 Python 项目，聚合 RSS、Hacker News、Reddit、Telegram、X、GitHub 六源，按自定义画像打分，产出中英双语每日简报，本周 +1.4k stars
- 差异化：「只给你想看的」——画像驱动打分而非全量推送，本质是把这个日报的人工流程开源化
- 用在哪：自部署一套做热点初筛，人工只复核打分头部；⚠️ 需自备数据源 token，Windows 部署装前实测
- 源：gitnova 周榜（11/2–11/8），11/7
