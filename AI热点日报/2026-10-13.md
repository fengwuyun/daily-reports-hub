## 一、AI 资讯（10 条）

**P0｜API / 价格**

**1. Nano Banana 2.1 图像模型降价一半（10/6 GA，10/12 早报重点）**
- 变了什么：Google 把 Flash 档图像模型 Nano Banana 2.1（基于 Gemini 3.6 Flash）单价砍半——1K 图从 $0.067 降到 **$0.0336**，2K $0.0504、4K $0.0756。AA 图像榜 T2I / Editing 均排第 4，16 项生成与编辑能力全超上代；支持 14 张参考图、跨轮保持 **4 角色 / 10 物体**一致，文本渲染与信息图事实性（0.179→0.521）大幅提升。
- ⚠️ 隐藏成本：只有**图像输出**降价。输入 token 从 $0.50→**$1.50/M（+200%）**，文本/thinking 输出 $3→$7.50/M。长 prompt + 重推理的工作流反而更贵。
- 跟你业务直接相关（AI 内容生产 / 短剧素材）：角色一致、海报、社媒图批量出图成本腰斩；短剧宣发图、封面、多语海报可直接用。
- OPC 视角：批量出图 / 社媒配图走 2.1；要角色连续一致就喂 reference 图（上限 4 角色）；别为省图像钱堆长 prompt。

**2. Anthropic 推 OSS 扫描器（10/12）**
- 变了什么：Anthropic 发布 OSS 扫描器，给开源项目发 **AI 生成、无需人工审核**的安全审计报告，免费、自愿参与。
- OPC 视角：你自部署的 WorkBuddy 技能 / agent / docker 服务，部署前可白嫖一遍依赖漏洞扫描。

**3. OpenAI ARR 近 500 亿美元（截至 9 月底）**
- 变了什么：OpenAI 告知投资者，截至 9 月底年化经常性收入（ARR）**近 500 亿美元**，远低于媒体此前估算的 700 亿。
- OPC 视角：SaaS / 订阅叙事的"官方下限"校准，做定价 / 估值参考时别迷信媒体高值。

**4. 韩国 7 家金融机构遭 AI 辅助攻击，6.7 万资料外泄（CrowdStrike 报告，10/12）**
- 变了什么：某大学生为赚钱，组合使用 **Claude Code + 开源中文工具 ARTEX + 国产模型 + 国内中转站**，攻击新韩银行、KB 国民银行等至少 7 家韩国金融机构，致超 **6.7 万**客户及员工资料外泄；外交部回应称不了解情况、反对散播虚假信息。
- 跟你业务直接相关（自部署工具链风险）：你本机接飞书 / 邮箱 / 文件，又走 Clash 代理 + 中转站调模型——这类"模型 + 中转 + 自动化"组合正是攻击链原型。自部署 agent 别给过高文件系统权限，中转站密钥单独隔离。
- OPC 视角：把"代理 / 中转密钥"和"业务数据访问"分账户，agent 跑在受限沙箱。

## 三、小而美产品（2 主推 + 1 备选）

**主推 1｜Firetower —— 自部署 coding agent 控制面**
- 是什么：开源（AGPL-3.0）、自部署的控制平面，把 Claude Code / Codex / Kimi Code 等 coding agent 跑在**你自己的服务器**上，从桌面或手机管理。
- 差异化：agent 会话存在你自己的机器（tmux + 独立 worktree），关笔记本 / 退出 App 任务继续跑；原生 **Windows / macOS / iOS / Android** 客户端；Rust 实现，worker 仅 5MB、无内存开销；自托管免费。
- 具体用在哪：你的 WorkBuddy 本地 agent 栈正要"数据不出本机、PC 本地部署"——Firetower 让多个 agent 在常驻服务器并行跑、手机随时接管，天然契合。自托管需 Docker + Node 20。
- ⚠️ 注意：worker 不是模型宿主，agent 仍走各自模型的 API / 账号；运维（备份、密钥、磁盘）归你。
- 来源：https://www.producthunt.com/products/firetower

**主推 2｜Otter Vault —— 本地优先 API 密钥保险库**
- 是什么：Chrome 扩展（+ macOS 菜单栏）的本地优先密钥保险库，浏览器里一出现新密钥就捕获、**AES-256-GCM 本地加密**保存，无服务器、无账号、无同步。
- 差异化：密钥只在生成它的原站回填（防钓鱼域名）；空闲 5/15/30 分钟自动锁；剪贴板自动清除；独立开发者 Krishna Ganga 一人做，免费。
- 具体用在哪：你手上有 Superset 只读账号、OpenRouter、各家模型 API、飞书 / 邮箱 token 一大把——Otter Vault 防"密钥明文散落 .env / 聊天记录"。Windows 上用 Chrome 扩展即可（菜单栏伴侣是 macOS 专属，非必需）。
- ⚠️ 注意：尚未独立安全审计；忘密码无法恢复；Teams 版 $20/月（早期鸟）非本地。
- 来源：https://www.producthunt.com/products/otter-vault

**备选｜OpenSEO —— 开源 MCP SEO / GEO 套件**
- 是什么：开源（MIT）的 Semrush / Ahrefs 替代品，MCP-native SEO 套件（关键词、排名、反链、审计、AI 可见度跟踪），可自部署或 $10/月托管。
- 差异化：agent 通过 MCP 直接调真实 SEO 数据；自托管免费，带自己的 DataForSEO key 按量付费。
- 具体用在哪：你做 OPC 内容分发 / SEO+GEO，可用它让 agent 跑关键词与 AI 引用跟踪，数据留在本机。
- ⚠️ 偏差如实标注：项目已 2.2 万+ GitHub stars、由 Every App 组织维护，**不算严格"≤5 人小团队"**；数据后端依赖 DataForSEO（非自爬），索引深度不及 Ahrefs。
- 来源：https://github.com/every-app/open-seo
