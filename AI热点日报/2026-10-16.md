## 三、小而美产品（Windows 优先 · 开源/免费/买断 · 数据可自持）

**主推 1 · OpenMuse**
- 是什么：开源、可自托管的个人 AI 助手，适配任意 harness（Claude Code / Codex / WorkBuddy 等都能挂）。
- 差异化：自托管、数据不出机、harness 无关，记忆和权限自己掌控，不被单一云平台锁死。
- 用在哪：把个人助手/记忆跑在自己机器上，接你本地的 agent 流（Superset 对账、飞书摘要、日报）。
- ⚠️ 偏差：PH 10/15 新品，团队规模与许可证未坐实，按"可自托管开源"标准推，落地前先核 license。

**主推 2 · SupoClip**
- 是什么：开源 AI 视频切片工具，把长视频自动切成可发的 viral shorts。
- 差异化：开源可自部署、批量产出短切片，不依赖闭源剪辑 SaaS。
- 用在哪：短剧宣发 / 投放素材快速切片（跟你业务直接相关）——长剧片段→多语区短视频投流素材。
- ⚠️ 偏差：PH 10/15 新品，平台与许可证未完全核实，自部署才谈得上数据自持。

**备选 · Tiden**
- 是什么：给 coding agent 做"意图校验"的安全层，执行破坏性操作前先拦一道。
- 差异化：在 agent 真去删库/改配置前弹出确认，降低本地 agent 跑飞的风险。
- 用在哪：你本机 agent（WorkBuddy 子智能体、Codex）动敏感动作前的护栏。
- ⚠️ 偏差：偏 dev、团队/许可证未核实，仅作备选。
