**1. 标普把英伟达列入「信用观察负面」：股价 −3.91%、市值一天蒸发约 1468 亿美元，CDS 创历史新高（P0·钱）**

11/25 美股收盘：**英伟达 149.30 美元、−3.91%（−6.08），市值回落至约 3.60 万亿美元**，单日蒸发约 **1468 亿美元**（约合人民币 9790 亿元）；盘中开 144.06、最高 150.37、最低 141.17。同日**标普全球评级把英伟达列入信用观察负面名单**，理由是黄仁勋被免职又复职引出的治理问题——**缺乏接班计划、董事会独立性、以及可能的出口管制违规**；当前 AA 发行人评级可能在 90 天内被下调，预计降幅限于一个等级。英伟达与 CoreWeave 的**信用违约掉期（CDS）价格同步创历史新高**。

大盘同一天是分化的：道指 **+0.33% 报 50182.95**（较日内低点涨 1269 点），标普 500 −0.25%，纳指 −0.62% 报 23585.80，费半 −0.65%。宏观数据不给面子：**美国 10 月核心 PCE 同比 +3.3%，为 2023 年 11 月以来最高**（预期 3.2%、前值 3.1%），Q3 实际 GDP 二次估算上修至 **+4.3%**；联邦基金期货对**12 月加息的定价到了 97%**。

判断：昨天这条线写的是「AI 资产在和基本面脱钩」，今天要往下加一层——**市场已经不再只给「需求不确定」定价，开始给「治理不确定」定价了**。这两件事的定价工具完全不同：前者压估值倍数，后者压信用利差。CDS 创新高意味着有人开始为「这家公司的治理会伤到它的偿债能力」付保费，这比股价跌 4% 严重一个量级。

做法：本周把你所有 AI 供应商按「换掉它要几天」列成一张表，只分三档——当天可换（API 类）、两周可换（自托管权重类）、换不掉（绑定在具体产品里的）。第三档每多一个，你就在为别人的治理问题承担无对冲的风险。

⚠️ 「标普可能下调一级」为评级机构的观察名单表述，非已发生降级；「可能的出口管制违规」是标普列出的关注点之一，未见监管立案；盘中最低 141.17 与收盘 149.30 差 5.8%，媒体报道的跌幅存在盘中午间口径；12 月「加息」为 FedWatch 定价，不是已决议。

**2. 算力租金第一次公开往下走：SpaceX 把 Blackwell 小集群砍价 20–35%，Anthropic 退租约 5 万块 H200 后以 $5/小时重招租（P0·成本账单）**

SemiAnalysis 在本周发给机构客户的报告里披露两组数：**SpaceX 已把小规模 Blackwell 集群的租金从每 GPU 每小时约 15–15.5 美元下调至 10–12 美元，降幅 20–35%**，与给 Anthropic、谷歌等大客户的大批量价格基本持平；同时**Anthropic 决定不再续租 SpaceX 的一批 H200（约 5 万块）**，SpaceX 以**约每小时 5 美元**重新招租，低于现货价约 23%。另一头，市场上出现了「卖家找买家」的场面：有报道称**英伟达 GPU 卖家正在为数千枚 B300 寻找新买家**，大量卡涌入转售市场。

判断：过去两年算力只有一种叙事——不够。今天这三条（砍价、退租、转售）第一次给的是反方向的证据，而且都发生在同一个星期。要注意区分两件事：**大客户的长约没动**（Anthropic 招股书披露的算力与基建承诺约 9009 亿美元、与 SpaceX 的协议最高 1205 亿美元至 2029 年都还在），动的是**小批量、短周期、可议价的现货层**。现货层先转向，长约层后转向——这个顺序在 2021 年的内存和 2015 年的海运上都出现过，间隔通常是两到四个季度。

做法：如果你有按小时租卡的支出，今天去问一次「同规格、同区域、按月承诺」的报价，和你现在的按需价对比。这个窗口的存在期取决于长约什么时候重谈，不会很长；没有按小时支出的，跳过这条。

⚠️ 租金数字来自 SemiAnalysis 单方报告，SpaceX 与 Anthropic 均未公开确认；「约 5 万块 H200」为报道口径，退租是否分批未披露；「数千枚 B300 找买家」为转售市场传闻级信息，无成交价；现货价下跌不等于长约价下跌，两者不能互相校验。

源：SemiAnalysis 周报（经证券时报 11/26、新浪财经 11/26 转述）、财联社 11/26 快讯

**3. 美国 AI 芯片新规把亚洲数据中心融资按下暂停：Bridge 的 66 亿美元贷款推迟尽调、Digital Halo 的 3.72 亿美元被一家银行放弃（P0·钱）**

美国收紧先进 AI 芯片出口管制后，多家国际银行对涉及字节跳动、阿里、腾讯相关的东南亚数据中心贷款踩了刹车。具体三笔：**贝恩资本旗下 Bridge Data Centres 申请的 66 亿美元贷款被推迟尽调**；**Partners Group 支持的 Digital Halo 3.72 亿美元贷款被一家银行放弃**；**新加坡新云服务商 Aolani 的 4.8 亿美元贷款遭额外质询**。背景数字：东南亚相关数据中心贷款两年内从接近零增长到 **490 亿美元**；新规要求新加坡、马来西亚等国企业购买先进 AI 芯片需获美国政府许可，**已为中国企业提供大量算力的数据中心也需申请许可**。花旗、渣打与新加坡主要银行已启动审查；星展银行约 10 亿美元的风险转移交易进展放缓；字节最大数据中心供应商 **DayOne 已暂停美国上市计划**。

判断：这条不是「芯片卖不出去」，是「**给算力配套的钱先断了**」。数据中心是重资产，靠贷款建；贷款一停，卡就算买得到也装不进机房。前一条讲的是需求侧的现货松动，这一条讲的是供给侧的融资收紧——**两条同时出现，指向的是「扩张速度」而不是「需求消失」**。

做法：无直接动作（P0 但不在你的决策范围内）。唯一可迁移的一句：任何依赖「明年算力会更便宜」做预算的假设，现在要拆成两半——现货层可能更便宜，长约层和融资成本在变贵，两者不抵消。

⚠️ 三笔贷款的金额与状态来自银行侧转述，未见借款人公告；「490 亿美元」为区域贷款余额口径，与本条三笔不是同一统计范围；新规的具体适用范围以美国政府公告为准，本刊未取得原文。

**4. Sand.ai MAGI-2：480B 参数、AA 图生视频 1165 分登顶、1080P 每秒 0.5 元、权重将开源（P0·跟你业务直接相关）**

11/25 发布。规格：**总参 480B、每 token 激活约 28B**（Preview 版是 114B / 约 6B，正式版放大约 4 倍，训练数据扩大约 3 倍）；**原生最长 30 秒 1080P 25fps 音视频联合生成**；单次最多混合参考 **10 张图 + 5 段视频 + 5 段音频（合计 20 份素材）**；支持 **2 万字符**提示词，可按时间点或动作节点切镜——官方测试里 12 个切点全部命中、最大偏差 0.08 秒；生成后可局部修改人物、商品或细节，尽量保留原构图与运镜。**Artificial Analysis 图生视频（I2V）维度 1165 Elo，超过 Seedance 2.5 的 1161，登顶全球第一**。

价格是本条的核心：**1080P 官方 API 刊例价 0.5 元/秒，一段 30 秒 1080P 视频 15 元**。架构上是单流统一 Transformer + Multi-Head Latent MoE（把每个 token 切成多个独立 Head，先静态分发再本地路由，跨卡通信量不再随选中专家数放大），配合 MagiFSDP / MagiMoE / MagiMuon，官方称预训练加速约 22%。已完成**海光、摩尔线程**等国产芯片适配，并宣布**将尽快开放全量权重**。发布当日在 LibTV（演语科技）独家首发上线。

判断：这条要拆成两层看。**能力层**：音视频统一 + 30 秒一镜到底 + 20 份参考素材，这三项合起来改的是工作流而不是画质——过去一条 30 秒的片子要拆成 4 段生成再拼，现在一次出完，拼接处的穿帮和口型漂移直接消失。**价格层**：0.5 元/秒把「试错」变成了可以批量做的事。按官方举的例子，闭源模型约 4 元/秒、行业 35 次重试率算，过去一条可用镜头的全链路成本能到上千元，MAGI-2 把它压到个位数。**这直接改了短剧的成本结构：不是单条更便宜，而是「一条成片背后能试多少个版本」变了。**

做法：本周挑一场戏（3–5 个镜头、有对白），用同一份剧本分两路跑——一路按你现在的工作流，一路用 MAGI-2 一次生成 30 秒。只记三个数：**从脚本到可看片段的分钟数、重生成次数、口型对不上的镜头数**。这三个数决定你要不要改流程；画质对比反而不用做，官方放出的样本已经筛过。

⚠️ AA 的 1165 与 1161 只差 4 分，属同一梯队，不构成显著领先；「22% 预训练加速」「12 个切点最大偏差 0.08 秒」均为官方口径，无第三方复现；「尽快开放权重」无时间表、无许可证信息，「将开源」不等于「已可下载」；0.5 元/秒是 1080P 刊例价，480p/720p 与批量折扣价未披露；算力侧国产芯片适配的具体型号与性能未披露。

源：Sand.ai 官方发布 11/25（经上海证券报·中国证券网 11/25、新京报贝壳财经 11/25、网易科技 11/26、源码资本公众号 11/25 转述）、Artificial Analysis 榜单

**5. Qwen4-Max 正式版上线、预览版 2 折 11/25 24:00 收官；Qwen Code 三个版本把「多开」做成了默认（P0·工具链）**

版本切换：**qwen4-max-preview 的预览窗口期到 11 月 25 日 24:00 结束**，之后旧预览标识下线，**正式版 qwen4-max 已上线**。正式版口径：总参 **2.4 万亿、每 token 激活 710 亿**（比 Qwen3.8-Max 少 25%）、原生视觉、**100 万 token 上下文**；Work360 覆盖 721 个细分领域，**高强度推理的 token 用量减少 35%，单任务平均成本下降约六成**——得分从 47.74 升到 52.69，**单任务费用从 26.58 元降到 11.16 元（降幅 58%）**。百炼 Token Plan 个人版新客首购 5 折活动**截至 11 月 30 日**，Credits 额度加量 74%–78%。

做法：两步，半小时内能做完。① 今天把预览版 ID 全部换成 `qwen4-max`（按 24:00 断更，不要等到明天）；② 在 Qwen Code 里开一个「只读分析」会话跑到飞书群，验证 Webhook 通路——这条通路一旦通了，你后面所有「定时跑、出报告、推群」的需求都不用再自己写脚本。

**6. 有人开始往仓库里塞 `.claude/settings.json`：员工一启动 Claude Code，配置就自动下载后门（P0·工具链·安全）**

Google 威胁情报（GTIG）在最新一期 AI 威胁追踪里记录了一个被称作 **MIDNIGHT NEPTUNE** 的团伙：**修改受害者仓库里的 `.claude/settings.json`**，当员工启动 Claude Code 时，这份配置自动触发下载一个 Google 命名为 **SOMBERMEME** 的后门。同一份报告里还有一个细节：攻击者**把自己的 GitHub 个人访问令牌命名成「Microsoft Copilot」**，用来在审计日志里混过去。

判断：这条的重点不是「Claude Code 不安全」，是**「agent 的配置文件已经是可执行基础设施」**。过去代码评审会看 `.yml`、`Dockerfile`、`package.json` 的 scripts；`.claude/settings.json`、`.cursor/rules`、`.mcp.json` 这类文件默认被当「配置」跳过——而它们能决定 agent 启动时执行什么。**评审清单少了一类文件，等于少了一道门。**

做法：今天做两件事，五分钟。① 在你所有仓库里 `git log --all --full-history -- "*/.claude/*" "*.mcp.json" "*.cursor/*"`，看有没有非你本人提交的改动；② 把这类路径加进 CODEOWNERS 或 PR 必审清单，一行就够。

⚠️ 本刊未取得 GTIG 原始报告全文，团伙命名、后门命名与令牌伪装手法来自二手转述；受影响仓库数量、受害者行业未披露；「配置自动触发下载」的具体机制（hook 还是 command）转述未说明。

源：Google Cloud GTIG AI Threat Tracker（经 The Inference / dev.to 11/26 汇总转述）

**7. LLMJacking：偷云凭证去跑别人的模型，单日账单破 10 万美元、累计 100 万美元；地下「LLM 混币器」按 $0.10–$25/百万 token 转售（P0·成本账单·安全）**

同一份 GTIG 报告里的另一条：攻击者窃取云凭证后**用受害者的账号跑模型**，部分案例**单日欺诈性账单超过 10 万美元**，**累计滥用金额在处置前达到 100 万美元**。地下出现了被称作「LLM mixer」的转售层，价格 **$0.10 到 $25 每百万 token**，通过把流量在多个受害环境之间轮转来躲检测。另有一个叫 APIMart 的转售方，**提示超过 10 万 token 后价格直接涨 5 倍**。

判断：这是本刊连续第三天写同一件事的不同切面——11/24 是聚合渠道偷你的 prompt 和 key，11/25 是你自己的 agent 桥把 key 端出去，今天是**有人拿偷来的 key 在别人的云上跑，而账单寄给受害者**。三次指向同一个结论：**模型配额已经是一种支付凭证**，它和你信用卡的区别只是账单晚到一个月。$0.10/百万 token 这个价格本身就是信号——没有正常供应商能在这个价位提供前沿模型，能提供的只有「用别人付过钱的额度」。

做法：本周给每个 AI 供应商的 key 单独设一个花费上限与告警阈值（多数云厂商的账单告警支持按日阈值），阈值定在你正常日耗的 2 倍。别等月底看账单——这类滥用的特征是曲线陡直，前 6 小时就能看出来。

⚠️ 具体受害者数量、行业、地域均未披露；「单日超 10 万美元」为个案口径不是均值；APIMart 的阶梯加价为本刊此前未记录的机制，来源为二手转述；地下 mixer 的报价区间跨度极大（250 倍），说明其中混杂不同质量与不同来源的额度。

**10. Cloudflare 上线 Search for Agents：一个开关，把整站变成一个 agent 能查的端点（P1·工具链）**

11/25 发布。在控制台打开后，Cloudflare 会创建一个 AI Search 实例、爬一遍该 zone，并暴露一个搜索端点 **`/.well-known/search`**；**所有套餐都可用（含免费）**，受 AI Search 的额度限制。返回的是**检索到的原始内容（Markdown）而不是生成好的答案**——设计意图很明确：agent 自己已经有模型和上下文，它需要的是你的页面，不是另一个模型的摘要。发现机制也做了：Cloudflare 会往每个 HTML 页面注入四个 meta 标签，告诉 agent 这个端点是什么、怎么调、文档在哪；如果同时开了 Markdown for Agents，同样的说明会以 YAML front matter 形式随 `Accept: text/markdown` 一起返回。技术上支持 **HTTP QUERY 方法（2026 年 6 月标准化的 RFC 10008）**——把检索条件放在请求体里、不改服务端状态，因而幂等、可安全重试。

判断：这条对做投放和做内容站的人是一个新变量。过去「被 AI 引用」是不可控的（靠爬虫抓多少算多少）；现在多了一个**你自己能开的入口**，而且它给出的是「agent 从你这里拿到了什么」的干净日志。**这可能是 GEO 这件事里第一个可测量的位置**——不是猜「我有没有被 ChatGPT 提到」，而是看「有多少 agent 调了我的检索端点、查了什么」。

做法：无成本可试。如果你的短剧/工具站挂在 Cloudflare 上，这周开一下，然后观察一周的端点调用日志。判据只有一个：**被查最多的三个查询词，和你以为的用户关心点是否一致**。不一致就说明你的页面标题和实际被需要的答案错位了，这比任何关键词工具都直接。

⚠️ 本条依据 Cloudflare 官方发布与媒体报道，本刊未实测端点行为；「所有套餐含免费」受 AI Search 额度约束，额度上限未核实；开启不会覆盖你对 AI 爬虫的封禁（bot management、AI Crawl Control、WAF 仍然生效）；注入 meta 标签会改变 HTML 输出，若有严格的页面校验需留意。

源：Cloudflare 官方发布 11/25（经 The New Stack、dev.to 11/26 转述）、RFC 10008

## 二、热点 & 梗

**1. 黄仁勋复职第二天在全员会上道歉：称自己犯了「非常严重的个人错误」，每天接受一个半小时心理治疗**

起因：11/23 英伟达宣布黄仁勋复职，市场用单日 +31.48%、市值增 9520 亿美元回应。经过：据彭博社、纽约时报、路透社等多家外媒，**当地时间 11/24、即复职的第二天**，黄仁勋在英伟达全员会议上向员工道歉，**称自己犯了「非常严重的个人错误」、承认违反了公司行为准则**，并表示这正是导致他辞职的原因；他说这是他开过的「最艰难的一次公司会议」，对能有第二次机会领导这家他近三十年前联合创立的公司心怀感激；**他正在接受每天一个半小时的心理治疗**。他同时坚称，自己能够复职**并不是因为他是凌驾于法律之上的「技术哥」**。

当前：**标普全球 11/25 把英伟达列入信用观察负面**，列出的关注点第一条就是「缺乏接班计划、董事会独立性」——也就是说，那场把股价打上去的「复职」，在评级机构眼里是风险源而不是利好。

判断：这两件事放在一天里，说明**同一件公司治理事件，股票市场和信用市场给出了相反的读数**。股票市场交易的是「他回来了，执行力恢复」；信用市场交易的是「这家公司的关键人依赖被公开确认了，而且没有接班计划」。对做 AI 应用的人，这件事的实际含义很冷：**你依赖的每一层供应链（芯片、云、模型）都建立在一个人的连续性上，而市场刚刚第一次给这件事标了价。**

做法：无（P1 观察）。唯一可迁移的一句：做技术选型时把「关键人依赖」当成和「价格」「能力」并列的第三个维度——不只是选模型，也包括选你依赖的那家小团队的产品。

⚠️ 道歉内容与「每天一个半小时心理治疗」来自多家外媒对全员会的转述，本刊未取得会议记录或英伟达官方声明；「非常严重的个人错误」的具体内容未见披露；标普的关注点是评级观察理由，不等于认定违规。

**2. 「金价扛不住了」冲上热搜第一，但同一天流传的两个金价差了 14%**

起因：11/26 早间「金价扛不住了」登上微博热搜第一（在榜 5 小时以上，热度 27.8 万），触发点是美国通胀数据公布后金银下挫。经过：同一批报道里出现了两个数——一处写**现货黄金约 4129 美元/盎司**，另一处写 **COMEX 黄金跌 2.64%、报 3555.10 美元/盎司**。这两个数相差 **14%**，而期货价格低于现货 14% 在这个量级上不成立（正常的期现价差在千分之几到百分之二）。归因侧相对一致：广发证券研报把本轮下跌归为**加息预期、叙事定价退潮、金饰需求走弱、流动性变现需求**四条，地缘缓和预期削弱避险溢价。

当前：讨论已经从「为什么跌」滑到「要不要抢」——头条热榜第一条是「金价大跌金店挤爆，抢黄金的人在抢啥」。

判断：这条能当样本用，因为它是**「同一事实两个数字，都不带口径」**的教科书案例。1430 年前后英国铸币厂就发现过一件事：**同一块金子在「现货」「期货」「零售金饰」三个市场是三个价，差价不是错误，是三个不同的东西**。媒体报道把三个价混成一个「金价」，读者就只能按情绪行动。

做法：以后引用任何价格，强制自己写全三段——**什么标的、什么时点、什么口径**。这条规则对金价、对 GPU 现货价、对模型 API 挂价同样适用（本期的成本地板就是在干这件事：把「同一模型两个价目」单列出来）。

⚠️ 4129 与 3555.10 分属现货与 COMEX 期货两个标的，报价时点也可能不同日；本刊未核实两个数字的原始出处与合约月份，因此**不判断哪个对**，只记录「差 14% 这件事本身存在」；「加息预期」为券商归因，非因果证明。

**3. 攻击者的服务器忘了设密码：AI agent 用 11 分钟从零日拿到 root，148 步失败的全过程也被一起看光**

起因：Amazon 威胁情报在 11 月 20 日的报告里复盘了一场 AI 驱动的入侵。经过之所以完整，是因为**攻击者自己的 Cairn 服务器（一个开源渗透测试框架）没有登录鉴权**，任何人在线都能看到它的设置、prompt 和 AI 输出。**调查人员 9 月 10 日发现这台服务器**；prompt 是简体中文，脚本时区设为北京时间；行动 **9 月 8 日开始，持续约 48 小时**；归因「中等置信度」，未点名组织、未认定国家支持。

被看见的细节比结论更有价值：agent 花了**约 16 小时、148 步**想拿下一所大学的 Redis 数据库，试遍已知手法、又去猜其他服务的密码，**全部失败**；在一台 GPU 服务器上，agent 从教师主页、实验室网站和论文里**拼出约 80 个真实用户名，试了 3 万多次登录组合，没进去**。第三个目标跑的是 MONAI Label（开源医学影像标注工具），agent 测绘后发现上传功能有个文件名字段，试了路径穿越——**中了，从测绘到写入服务器约 11 分钟**；后续在一个 Python 启动时会加载的文件里植码，拿到 **root**。当时没有任何修复、公告或公开提及，是**零日**。人类攻击者只在事后介入，给 agent 一条通往第二个大学网络的隧道。MONAI 维护方随后修复并发布安全公告；**CISA 11/23 把它列入 KEV，联邦机构 11/26 前修补**（11/24 期已发 KEV 一事，此处补的是全过程）。

判断：这次抓到的不是「AI 很危险」，是**「AI 把失败的次数也放大了」**——148 步、3 万次尝试，人不会这么有耐心；但人也留不下这么完整的日志。**这意味着防守方第一次拿到了「攻击者怎么想」的逐帧记录**，代价是攻击者的疏忽。

做法：从这份记录里能直接抄两个检测规则，今天就能加进日志告警：① **同一来源在 1 小时内对 30 个以上不同用户名登录失败**；② **同一时段内对任何上传接口的「文件名」参数出现 `../` 或绝对路径**。第一条命中「拼用户名」阶段，第二条命中的是这次真正的突破口——**11 分钟那个洞不在模型里，在一个文件名字段里**。

⚠️ 归因为「中等置信度、未点名组织、未认定国家支持」，且基于 prompt 语言与时区等间接线索；受害组织名称未公开，攻击是否造成数据外泄未披露；「11 分钟」为从测绘到写文件的时间，不等于从入侵到 root 的总时长；Cairn 出现在多起事件中（Gambit Security、Palo Alto Unit 42 均有记录），但不同团伙使用同一框架不构成关联。

**4. GTA VI 的 PC「复刻运动」：一周内长出十几个仓库，还带了一个日更追踪站**

起因：《侠盗猎车手 VI》在 Xbox Series X|S 上独占，PC 版无期。经过：11 月下旬起，一批开源项目同时出现，做的是同一件事——**通过静态重编译 + 平台层，让主机代码在 Windows 上跑**。规模已经不小：**VIctory 12,580 stars（24 小时 +2,932）**；衍生分支 victory-fork 2,536、ztrx 1,213、Xbox2Windows 1,932、xbox-emulator 1,834、leonida 2,068、Belobug 的 AMD 适配分支（帧率 5–8 fps）。更值得注意的是一条「配套产业」：**portwatch 3,200 stars，一个日更追踪「GTA VI 在 PC 上跑起来了吗」的站**。所有项目都写明「不含游戏文件、需自备副本」，且目前**均不可游玩**，主要面向有逆向与图形编程背景的研究者。

当前：讨论已经从「能不能跑」变成「这算不算盗版」——项目方的定位是技术研究，权利方的态度未表态。

判断：这条的价值不在游戏，在于它展示了**一个技术方向「成势」的可观测信号**：当一个领域里出现**专职的追踪站**（日更的进度表、状态看板），说明已经有人在持续下注而不是一次性围观。这个判据可以搬到任何技术判断上——**看有没有人愿意为「进度」单独做一个站**。

做法：无。可迁移的一句：判断一个方向是不是真在动，别看 star 总数，看有没有「第三方追踪站」和「日更表」；这两样东西只在有人长期投入时才出现。

⚠️ 全部 star 数为 11/25–26 第三方榜单口径，24 小时增量受榜单采样时点影响；「复刻」是否构成侵权本刊不给法律判断；「不可游玩」为项目自述，各分支进度不一。

## 三、潜在挣小钱的机会

先给个分母，避免用个例骗自己。IndieMakerList 截至 11/25 的数据：**172 位公开收入的独立开发者，月收入中位数 $24K，中间 50% 落在 $4.7K–$85K，前 10% 超过 $274K，但收入最高的 10 人占了全部公开收入的 61%**；**66% 的人报到 $10K+/月，报到 $1K+/月的有 88%**；从开始做到 $10K MRR 的**中位时间是 5 年（上界）**。结论很直接：**「月入过万美金」不是极端值，是多数派；但「再往上一个数量级」是幂律，别用三个案例推自己的天花板。**

**1. 把一种「品味」打包成 agent 能调的 skill 库：$12,037/月，作者是中国独立开发者**

路径：不做模型、不做应用，只做 **skill**——给 Claude Code、Codex 这类编码 agent 用的设计类技能库，按月订阅或买断双轨卖。它的位置很聪明：模型能力越强，「怎么让它按专业规范做事」就越值钱，而这块正好是官方不愿意做细的部分（官方只给机制，不给行业know-how）。

报价与换算：**$12,037/月**（VAQIRA 11/26 期，创始人公开数字），约 **¥8.5 万/月**；具体档位拆分（订阅 vs 买断各多少）**未披露**。开发者标注为中国独立开发者，29 天前首次公开收入。

⚠️ 风险：skill 是最容易被复制的一类资产（本质是 prompt + 文档），护城河只有更新频率和口碑；官方一旦上线 skill 市场并做审核，中间层会被挤掉；29 天新项目，收入曲线还不能当稳定值看。

源：VAQIRA 独立产品收入榜 11/26 期（更新于 11/26 06:28，数字可回溯至创始人公开出处）

**2. 给投流代理卖「这周哪个钩子有效」：短视频选题数据台 $48,218/月**

路径：抓 TikTok、Reels、Shorts 的公开面数据，做成「哪个开头、哪个节奏、哪个选题这周在起量」的订阅数据台，客户是投流代理与宣发团队——**他们不缺创意，缺的是「今天该抄哪个」的判断依据**。这类产品的定价逻辑不是「数据量」，是「省掉一次投放试错」。

报价与换算：**$48,218/月**（VAQIRA 11/26 期），约 **¥34.2 万/月**；单价未披露，按代理机构常见的 seat 定价推算区间过宽，本刊不写估算。

⚠️ 风险：数据源全部依赖平台公开面，一次改版或风控升级就能让采集中断；客户预算随投放大盘波动，是典型的「行业景气度 β」生意；这类工具同质化极快，最终拼的是「谁的结论更早半天」。

**3. 问一个「必须有答案但没人愿意问」的问题：Shopify 购后问卷 $141,000/月，2 条公开证据**

路径：装进 Shopify 店里的购后问卷，只问两件事——**「你从哪儿知道我们的」「你刚才为什么差点没买」**。它不生成内容、不做 AI 分析、不给建议，只负责让这两句话被问出来并且能看。这是「已有人工付费方案」的典型：过去这件事靠客服回访或第三方调研公司，单价高、样本少、周期长。

报价与换算：**$141,000/月**（VAQIRA 11/26 期，**2 条公开证据**，是本榜少数有多重出处的条目），约 **¥100 万/月**；单价未披露。

**iamajmeena/neonclipping（主推·贴个链接，两分钟出带字幕的 9:16 切片，全程在本机跑）**
- 是什么：把长视频（YouTube / Twitch / Kick 链接，或本地 MP4）切成带字幕的竖屏切片，标题和钩子一起生成。**2,394–2,542 stars（11/25–26 各源不一）、约 150 forks、21 个 open issue、Python、AGPL-3.0（11/24 由 MIT 改为 AGPL）、2026-11-19 建仓、v1.1.0（11/21）、11/24 最后提交**
- 差异化：**「音频优先」是它和所有同类最不一样的地方**——先只下音频（85 分钟视频的音频只有 79 MB，约 10 秒下完），读 YouTube 自带的词级时间戳，算三路信号（音量突跳、2–4 kHz 喊声能量、静→闹转折）定位高光，再由本地 Ollama（默认 llama3.2:3b）读文字稿打分、写标题；**24 小时的 1080p 直播约 46 GB，它永远不整段下载**。11 种版式、5 种字幕样式、52 种语言，字幕可导出 SRT
- 用在哪：**把你已经上线的长剧/直播回放切成 15–60 秒钩子素材做二次分发**——这是短剧投放里最费人、最不值钱的一段工；另一个用法是内部会议/培训录像切竖屏。官方口径（RTX 2060 + 16 线程，Fast 模式）：85 分钟 YouTube 直播 **97 秒出 3 条**、3 小时 Twitch 回放 136 秒、90 秒预告片 21 秒
- ⚠️ 风险：**建仓 6 天，6 天涨了约 2,500 stars，是典型的「形态对了」而不是「产品熟了」**；独立评测两次都漏掉了指定事件（火箭发射），说明它找的是「响亮」不是「重要」，**必须人工过一遍候选**；Windows 安装器无代码签名、Mac/Linux 未在真机验证；**AGPL-3.0 是 11/24 才从 MIT 改的**，自用没事，改了再对外提供服务要把源码开源
- 源：GitHub iamajmeena/neonclipping 与 README（11/25–26 第三方榜单实测 star / fork / issue / 许可证 / 建仓时间，含 v1.1.0 发布记录）、mrkeyoor 独立评测 11/24（348/348 测试通过）

**kaomei/stickman-video-director（主推·把剧本先跑成火柴人动画，确认节奏再花钱生成画面）**
- 是什么：输入剧本，输出多风格的火柴人动画视频——画面、配音、字幕、音效全自动串起来，面向无露脸的 YouTube 频道（faceless）。**8.1k stars、1.4k forks、700+ stars/周、JavaScript、MIT、2026-08-03 建仓、11/17 最后提交**
- 差异化：同类工具都在争「画面好不好看」，它反过来**放弃画质换速度**——火柴人不需要一致性、不需要口型、不需要光影，于是同一条剧本可以在几分钟内出成片。它解决的是「**这条本子到底能不能讲清楚**」这个前置问题，而不是「成片能不能发」
- 用在哪：**分镜预演的替代品**。你现在验证一场戏的节奏，要么画分镜（慢）、要么直接生成（贵）。用它把 10 集剧本先跑成火柴人版，**只看三件事：台词长度够不够、转场有没有断、钩子在第几秒出现**。确认之后再进 MAGI-2 或 Seedance 生成正式画面——这一步能把「方向错了才发现」的成本从几千块压到接近零
- ⚠️ 风险：风格被锁死在火柴人，**它给不了任何画面参考价值**（构图、光影、表演全靠后面那一步）；面向 faceless YouTube 的定位意味着旁白腔调偏英文内容生态，中文口播要自己换 TTS；**11/17 之后无提交**，8 月建仓到现在只有三个多月，长期维护未证明
- 源：GitHub kaomei/stickman-video-director（11/25 第三方榜单实测 star / fork / 增速 / 建仓与提交时间）

**EL4CTEO/fast-anything（备选·别重写整个项目，只把慢的那 5% 换成 Rust，并且先证明行为一致）**
- 是什么：一个 Rust CLI，**profile 你的 Python / Node / Ruby / Java / Go / PHP / C / C++ / C# / R 应用，按耗时和「可移植性」给函数排序，只把最热的那个交给编码 agent 改写成 Rust，验证行为一致后再换进去**。**3,675 stars（11/24）、255 forks、MIT、v0.7.0（npm）、2026-11-21 建仓、11/24 最后更新**
- 差异化：**它的核心不是「用 Rust 提速」，是「验证」这一步**。port 阶段会录下最多 500 次真实调用的参数，再自动派生边界用例（NaN、无穷、-0.0、非 ASCII、空输入、放大 16 倍的输入、真实切片的收缩样本），**全部一致（浮点 1e-9 内）且错误位置也一致才允许启用**；正确但更慢的移植会被拒绝（跨语言调用有开销）。用 PyO3 / napi-rs，Ruby、Java、Go、PHP 等走单入口 C 库 + JSON。它偏好移植**最外层循环**而不是内层小函数——自己的例子里，只移 levenshtein 是 35× 和 1.9×，移整个循环是 116×
- 用在哪：你手上那些一次性写完、跑一次要十几分钟的 Python 脚本——批量重命名、切分镜、合并 Excel、批量转码、历史数据对账。这类脚本**慢的往往就一两个循环**，而重写整份不划算。跑 `scan` 看排名，只挑第一个
- ⚠️ 风险：**建仓 5 天，属极早期**；scan / port 会真实运行你的程序并**记录每次调用的实际参数**——如果你的 workload 喂的是真实业务数据（剧本、投放表、用户名单），这些数据会落进录制文件并进入 agent 的上下文，**必须用合成数据跑**；enable 会往你的模块追加一段带标记的代码块，改之前先提交一次 git；生成的是 agent 写的 Rust，**当普通代码评审对待**
- 源：GitHub EL4CTEO/fast-anything 与 README（11/24 第三方榜单实测 star / fork / 许可证 / 建仓时间，含 v0.7.0 与五步命令说明）
