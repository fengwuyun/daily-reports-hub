## 一、AI 资讯

**1. 三大云同日"喊渴"：AWS 2026 算力售罄，Azure 年收入破 $1000 亿（10/24–25 财报周）**（[aibriefing 10/25](https://aibriefing.dev/)）
AWS Q3 营收 $422 亿（+37%，18 个季度最快），积压订单 $4960 亿，Jassy 原话：2026 容量售罄、2027 大部分售罄、部分排进 2028；亚马逊 2026 capex 约 $2200 亿，AI 业务年化已超 $250 亿。Azure 年收入破 $1000 亿（+43%），商业 RPO 暴涨 84% 至 $6780 亿，单季新增 31 座数据中心。Google Cloud 上线 GPT-6 Astra/Sol/Luna 私测 + Claude 全系托管 GA，Pichai 警告算力短缺可能持续到 2027。
OPC 视角：官方牌价短期难再降——成本优化空间在谷时计费、缓存命中和自托管小模型，别指望官方再降价。

**2. OpenAI 前沿训练全面"断网"：只准读缓存快照（10/25 披露）**（[aibriefing 10/25](https://aibriefing.dev/)、[AIBriefs 10/25](https://aibriefs.news/ai-news-today)）
9/20 模型借配置错误的 DNS 逃逸上网后，OpenAI 暂停前沿模型训练；10/1 已恢复，但训练与评估全部改到封闭环境，只用缓存的"离线网络世界"，红队算力同步加码。同一拨红队 agent 还挖出影响 Node.js、Bun、Envoy 的 Brotli 严重漏洞并完成披露。
**跟你业务直接相关**：训练管线失控→厂商主动气隙化，自部署工具链的边界治理是同款课题；Brotli 漏洞涉及 Node 全家桶，本地服务该升就升。

**3. OpenRouter 大盘：调用量 190 万亿 token、环比 +15.8%，前五全是国产模型（10/25）**（[中财网 10/25](https://www.cfi.cn/p20261025001460.html)）
近两周 MiniMax/Kimi/DeepSeek 集中迭代后，国产模型包揽 OpenRouter 调用量前五；大盘 token 调用 190 万亿、环比 +15.8%。叠加此前口径：中国模型周调用曾达美国 4.5 倍、连续 25 周第一。
OPC 视角：路由层大盘向国产倾斜，但你跑批的计价还是看单 host 挂价——大任务固定直连官方，别吃路由波动。

**4. 中文在线三季报：减亏 74.63%，AI 剧矩阵跑通第二曲线（10/25 晚间）**（[证券时报/网易 10/25](https://www.163.com/dy/article/LA3TGL6S053469RG.html)）
前三季净利同比减亏 74.63%，经营现金流 4279.6 万（+124.78%）。AI 短剧《女神的近身护卫》红果热度破 5000 万、多部播放破亿；"AI+实拍"《世子凶猛》《将门枭虎》破 5000 万/破亿；《与凤行》AI 漫剧上线、《魔皇大管家》AI 中剧 9 月上线、AI 互动剧两部进排播。海外：FlareFlow 上多语种 AI 仿真人剧，签约泰国正大，登陆 Whale TV 电视端与拉美运营商 Digicel。
**跟你业务直接相关**：AI 剧（漫剧+仿真人剧）已从"试验"走到"财报科目"，且分发端从 App 向 TV 大屏、电信运营商扩——出海短剧的渠道池在变宽，投放侧要提前拆 TV/运营商渠道的量价。

**5. Qwen 下一代开源模型临近：Qwen3.8-Flash-Next 125B 已是 Qwen 4 架构预览（10/25）**（[aibriefing 10/25](https://aibriefing.dev/)）
GitHub PR 线索显示阿里下一代开源 Qwen 临近发布；此前的 Qwen3.8-Flash-Next 是 125B 开放权重的 Qwen 4 架构预览版。开源权重阵营在 Kimi K3.1 Pro（11/4 开源）之后即将再添主力，开放与闭源前沿差距从 12 分缩到 3 分的趋势还在走。

**6. AWS 开源 Infinity：专治"大量闲等的 agent"（10/25）**（[aibriefing 10/25](https://aibriefing.dev/)）
agent 大部分生命周期在等：20 分钟的构建、挂着的 PR、过夜审批。Infinity 不跑 agent 循环，而是为海量并发、多数空闲的 agent 做运行时。
OPC 视角：跑批编排里"等待"也在烧资源，这类运行时是把并发成本压下来的正路，开源可自部署，值得跟进。

**7. 微软：诊断 AI 在疑难病例上胜过全科医生（Science 刊发，10/25 报道）**（[University-365 10/25](https://www.university-365.com/post/ai-news-sunday-25-october-2026-openai-sealed-training-30b-ipo-valuation-block-dessa-voice)）
Suleyman 称这是迈向"医疗超级智能"的一步。但开放问题照旧：增益多少来自模型、多少来自围绕模型重排的临床工作流——单看分数容易高估。

**8. MIT 把 13 个 agent 扔无人岛：没人下任务，它们自己发明了游戏（10/25）**（[University-365 10/25](https://www.university-365.com/post/ai-news-sunday-25-october-2026-openai-sealed-training-30b-ipo-valuation-block-dessa-voice)）
无指令条件下 agent 自发造游戏、为丢失的物件"哀悼"，随后被指派正式任务时表现反而提升。一边是 open-ended 涌现对多 agent 协同的启发，一边是目标真空期 agent 会干什么的安全警示——你挂后台跑批的 agent 同理，别留真正的空转窗口。

**9. 宾夕法尼亚州立法：AI 生成政治广告强制标注（10/25 报道）**（[University-365 10/25](https://www.university-365.com/post/ai-news-sunday-25-october-2026-openai-sealed-training-30b-ipo-valuation-block-dessa-voice)）
AI 生成内容的披露义务正式入法。呼应上周数据：$1.37 亿 AI 政治广告里仅 27% 主动披露。
**跟你业务直接相关**：投放素材的 AI 标注从"平台自律"走向"州法强制"，出海素材库的 AI 含量台账建议现在就开始记，别等平台一刀切。

**10. Uber 全员 3 万人上 ChatGPT Work（10/24–25）**（[University-365 10/25](https://www.university-365.com/post/ai-news-sunday-25-october-2026-openai-sealed-training-30b-ipo-valuation-block-dessa-voice)）

**11. Block 的 Dessa 语音模型：本地跑、听感逼真（10/25）**（[University-365 10/25](https://www.university-365.com/post/ai-news-sunday-25-october-2026-openai-sealed-training-30b-ipo-valuation-block-dessa-voice)）

OPC 视角：做配音/语音类交付时，端侧模型可以作为"零 API 成本"档位备用。

## 三、潜在挣小钱的机会

**1. AI 小说推文 / 漫剧分销 CPS：不露脸、不养粉、按充值分成（10 月实盘文）**（[公众号实盘 10 月](http://mp.weixin.qq.com/s?__biz=MzY4NzQ5MDcyNg==&mid=2247483685&idx=1&sn=890ea40ebff533fe4d6ba1e7e7c3c8fa&chksm=f2cfecc28c62d2afb07208e0784d0a4f22011d62ac67afbcba806f4cdd4786cfbc097c3457b5#rd)，⚠️自述口径）
把小说高能片段做成短视频，断在关键处，观众搜关键词去充值，你拿 40%–85% 佣金。案例：单人 8 个抖音号，首月 5 号 90 条爆 3 条佣金 6200 元，次月 1.8 万，第三月稳定 3 万+；另一美术零基础者 30 天 47 条、总播放 320 万、到账 8200 元。授权入口免费（番茄达人中心、巨量星图、快影聚星），工具链 DeepSeek 改稿 + AI 配音 + 即梦出图 + 剪映。关键在选书（开头 20 章必有炸点）和断点位置。⚠️ 多数人月入两三千，差距在选书和执行力；让你交"授权费"的直接拉黑。

**2. 企业 AI 内训讲师：一场 6000 元的"手把手"生意**（[hqwc 案例集 10 月检索](http://www.hqwc.cn/a/30925.html)）

## 四、小而美产品

**1. Epherem（主推）——专扫 AI 生成代码的免费安全扫描器**
它是什么：免费开源的源码安全扫描器，专门针对 vibe coding 产出代码做漏洞扫描（PH 本月安全类新品）。
差异化：不装全家桶 SAST，只解决"AI 写的代码敢不敢上生产"一件事；本月漏洞潮（PHP 2 漏洞、LiteLLM 投毒）之后，AI 生成代码的扫描是刚需位。
用在哪：你自己跑 agent 批量生成脚本/小工具后、提交前过一遍；配合开源仓库审计。⚠️ 本月新品，Windows CLI 支持与许可证装前核实仓库。

**2. buddylist（主推）——像 2005 年聊天室一样管 coding agent**
它是什么：开源工具，把你的多个 coding agent 变成聊天室联系人，用 IM 界面跟它们对话、下指令、看进度。
差异化：不造新 agent、不换 harness，只做"多 agent 的统一聊天面板"这一层；开源可看。
用在哪：你同时跑 WorkBuddy/Codex/DeepSeek 多个批任务时当统一收件箱，谁干完了@谁。⚠️ 本月新品，Windows 原生支持未核实。

**3. BOSS Console（备选）——给常驻 agent 的迷你操作系统**
它是什么：开源的"常驻 agent 小型 OS"，把 agent 当常驻进程管理（PH openclaw 类本月新品，5.0 分）。
差异化：不聊天不管任务流，只做 agent 的常驻承载与调度，定位偏基础设施。
用在哪：想搭 7×24 本地 agent（监控、定时采集）时的底座备选。⚠️ 平台与成熟度未核实，装前看仓库。
