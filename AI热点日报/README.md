# AI 热点日报

三段式每日简报：**AI 资讯**（大模型 API 发布与价格变动优先）＋ **热点梗与热点新闻** ＋ **小而美产品推荐**。

## 产出模板

每期固定三段：

1. **AI 资讯（5–12 条）**：优先级为「大模型 API 新发布与价格变动 > OPC 一人公司可直接用的工具与变现路径 > 已验证的冷启动单人变现路径 > AI 行业动向（开源/榜单/融资/收购/诉讼）> 大牛动态与安全事件 > 短剧行业 > 互联网行业动向 > 招聘求职」。每条带具体数字；限时价标到期日；峰时加倍计费等隐藏成本用 ⚠️ 单列。
2. **热点梗与热点新闻（约 5 条）**：不收娱乐圈/影视圈/明星/文娱新闻；梗讲清来龙去脉；最后一条做「今日要闻速览」。涉及短剧、出海、投放、AI 内容生产标注「跟你业务直接相关」。
3. **小而美产品（1–2 主推 + 1 备选）**：独立开发者或小团队作品，功能克制、免费或买断、数据可自持；写清「是什么 / 差异化 / 具体用在哪」，并同步写入 `products.csv`。
