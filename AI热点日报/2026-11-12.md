## 一、AI 资讯

**1. Stripe 正式并购 OpenRouter：75 亿美元交割完成（P0·并购，跟你工具链直接相关）**
11/11 Stripe 官宣、11/10 交割完成。价格按《纽约时报》口径 75 亿美元（彭博口径「超 70 亿」），而 OpenRouter 今年 5 月 B 轮估值才 13 亿美元——半年翻近 6 倍。平台数据：10 月处理约 790 万亿 Token、环比 +37%，其中 76% 来自 agent 相关调用；接入 80+ 供应商 400+ 模型、服务超 1000 万开发者。Stripe 已有 Token Billing 计费产品，并购后打通「选模型→跑调用→按 token 结算」全链路。
⚠️ 你的 OP- 前缀免费模型走的就是 OpenRouter 网关：并购后路由策略、免费上游渠道（OpenCode Zen / Kilo AI）是否调整要盯，改了就换通道。
OPC 视角：790 万亿 token/月里 76% 是 agent 产生的——agent 的 token 消耗已是聚合平台的主体营收，「给 agent 省 token」本身就是生意（billion-context、ProtoMap 这类工具吃的就是这条缝）。
源：Stripe 博文/IT之家/网易 DoNews，11/11–11/12，news.qq.com/rain/a/20261112A0373O00

**2. Gemini 4 Carbon 全面开放：$2/$10 限时，12/1 起翻倍（P0·价格）**
11/10 谷歌官宣，从 10/28 只对网安防御团队白名单开放到全面可用不到两周。API、AI Studio、Gemini for business、AI Ultra 订阅全渠道铺开；1M 上下文、最大输出 65,536（LongDecode 可扩到 1M）。首发价 $2/$10 每百万 token，与 Argon 持平，**优惠到 11/30，12/1 起翻倍为 $4/$20**。榜单：AutomationBench 53.9%（Argon 51.3%、Opus 5.5 42.5%、GPT-6 Astra 41.4%）、Terminal-Bench 65.2%、CWE-bench 漏洞修复 71%，官方称完成任务成本比次优外部模型低一半以上。同步在 Antigravity 预览 /swarm：一条指令拉起架构/编码/验证 agent 蜂群；配合 AlphaProof Code，四周生成 650 万行形式化证明验证 Signal 加密协议编译代码正确性。
⚠️ 单价低 ≠ 账单低：Carbon 会在复杂任务上多烧推理 token，谷歌自己都承认深度推理可能把总费用推高到与单价不匹配的水平。按「每个成功任务的成本」比价，别按 token 单价。
OPC 视角：11 月内把难活（多步调试、安全审计、长程 agent）丢 Carbon 限时档试，跑通的任务记下实际 token 消耗，12/1 翻倍前算清它对你的真实单价再决定留不留。
源：谷歌官方博客/腾讯新闻 AI 早报/凤凰网科技，11/10–11/11

**3. Qwen4-Max 预览版上线 Token Plan：限时 8 折，按量价未开（P0·发布）**
11/11 阿里官宣 Qwen4 代，qwen4-max-preview 直接进 Token Plan 订阅、标 New 限时 8 折，覆盖文本/推理/视觉理解；QwenWork、Qoder、千问 App、QwenStudio 同日拿到早期入口。发布活动订阅价：Lite $3/月（2 万积分，原 $8）到 Pro $43/月（20 万积分，原 $51）。

**5. MiniMax 开源 H3-Image：4K 图 10 秒内出（P0·开源，跟你业务直接相关）**

## 四、小而美产品

**meta/astryx（主推·Meta 内部设计系统开源，150+ 组件）**
- 是什么：Meta 内部养了八年的设计系统开源 beta：150+ 无障碍 React 组件（React 19 + StyleX）、七套主题靠 CSS 变量换肤、带文档/脚手架/codemod CLI；装出来就是纯 CSS + 类型化组件，无构建插件依赖。11/11 GitHub 日榜 +1,584
- 差异化：组件形状按「人和 agent 都能直接用」设计——coding agent 拿它当现成积木库，不用从零拼样式；⚠️ Meta 大厂出品，不是严格意义的独立开发者作品，如实标注
- 用在哪：你出 HTML Demo 评审时的组件底座——产品原型页直接引用，风格统一还不用手调间距
- 源：ghtrends.dev 11/11 日榜

**stablyai/orca（主推·AI 代理编排桌面环境）**
- 是什么：面向高效开发者的桌面编排环境（ADE），同时并行跑多个 CLI 编码 agent（Claude Code、Codex 等），每个 agent 独立 Git worktree 隔离，统一界面追踪进度。121,402 stars、11/11 日增 +1,079
- 差异化：worktree 隔离解决多 agent 互踩工作区的问题，比 T3 Code 的控制面板层更重、比 worktrunk 的 CLI 形态有 GUI；⚠️ Stably AI 公司作品，非独立开发者小团队
- 用在哪：夜间批量跑任务时开多 agent 并行（一个改数据脚本、一个写周报分析、一个跑抓取），互不干扰
- 源：博客园 GitHub 日榜速报 11/11

**craft-anything（备选·clean-room 复刻引擎）**
- 是什么：纯 Rust 的 clean-room 引擎，指向任意网站/应用/游戏，先用真实检查工具研究原作行为，再让 coding agent 用你指定的技术栈重建并对照迭代。GitHub 11/11 +972
- 差异化：只从「可见行为」反向构建、不碰源码，规避版权灰区的姿势比较干净；⚠️ 构建走你自己的 Claude Code 订阅，token 消耗大，复杂应用成功率存疑
- 用在哪：把竞品的某个交互形态快速复刻成自己 Demo 的起点
- 源：ghtrends.dev 11/11 日榜
