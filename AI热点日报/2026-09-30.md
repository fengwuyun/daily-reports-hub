## 一、AI 资讯

**1. OpenAI DevDay 2026：GPT-6.1 Sol + Agents/Decisions API + Ultrafast 速度档（9/29）｜价格与 OPC 工具双主线**
- GPT-6.1 Sol 发布：API 价 $2/M 输入、$10/M 输出（与上代 Sol 同价），OpenAI 称接近 Astra 质量、仅其 1/5 价格；比上代 Sol 更快。消费者端头条产品是「Dots」（AI 助手）。
- Agents API 上线 computer use：agent 能直接操作软件 UI（不再只调 API），9/11 起已公有 beta，跑在 Codex/ChatGPT 同套基础设施，含多 agent、Tool Search、Context Compaction。
- Decisions API（限量预览）：基于 GPT-6 Luna，给你一个固定选项集返回单一决策，比 Luna 常规 API 快 10 倍——适合路由、审批、护栏。
- Codex in the cloud：关笔记本也能跑任务，手机可启停、可查进度。
- ⚠️ Ultrafast 峰时加倍计费：Astra Ultrafast 6 倍标准价，即 $60/M 输入、$300/M 输出（Sol Ultrafast 数日后上线）。常态跑量别碰这个档。
- OPC 视角：Decisions API 是「强模型规划 + 小模型决策」双模型架构的廉价半边，你的 agent 路由/护栏用 Luna 档（$0.10/$0.50）即可；Agents API 的 computer use 可直接把投放后台、报表导出这类重复操作自动化。
- 来源：nocode.mba/articles/openai-devday-2026-recap（9/29）；The Decoder；Axios

**2. 「每个完成任务的成本」成新核算轴，GPT-6 时代单价失真（9/29）**
- BenchLM 9/29 统计：177 个模型 API 价中位数 $0.95/M 输入、$3.75/M 输出；开放权重模型比闭源便宜 78%（$0.53 vs $2.41）；最便宜的「前沿质量」模型是 MiMo-V2.6-Pro（$0.43/$0.87）；前沿 token 价较 GPT-4 时代低 81.3%，但过去 12 个月前沿价格不降反升。
- Artificial Analysis 发现：Google 保持 Gemini token 单价不变，但模型多干了一截活，导致「完成同一任务」成本涨约 40%。结论：盯 $/M token 已经失真，该盯「每个成功任务的成本（含重试与人工补救）」。
- OPC 视角：你 WorkBuddy/dsh 跑批量任务、日报、邮件，别只看 $/M token；便宜模型频繁重试反而更贵，按「成功任务单价」选型。
- 来源：benchlm.ai/stats/llm-pricing（9/29）；capitalandcompute.net/ai-model-releases（9/29）

**8. 研究：AI 摘要的「主错误」是遗漏而非幻觉（Georgetown/UW，9/29）**
- 20 份事故报告 AI 摘要中，「漏掉关键信息」是主导错误（不是编造）；328 人实验里，误导性摘要把关键细节正确回忆率从 83.6% 拉到 44.8%。
- OPC 视角：审 AI 输出要查「漏了什么」，不只查「错了什么」——你让 agent 出日报/报表/PRD，对照源头核「有没有少字段、少维度」，比只看错别字重要。

## 三、小而美产品

**主推 1 ｜ Everything**
- 是什么：Windows 本地文件秒搜工具，免费、无遥测。
- 差异化：NTFS MFT 直接读，百万级文件输入即出结果，不建云端索引、不碰你的数据。
- 具体用在哪：你的工作区/本地素材库（短剧素材、CSV、飞书文档导出）文件极多，秒定位比系统搜索快一个量级；数据全留本机。
- 偏差：voidtools 小团队商业免费软件，非开源，但无订阅、无遥测、纯本地。
- 来源：voidtools.com

**主推 2 ｜ Flow Launcher**
- 是什么：Windows 开源启动器（Launcher），一键拉起文件、应用、本地脚本、浏览器书签。
- 差异化：插件化、可写自己的命令，本地优先，数据不出机。
- 具体用在哪：local-first 工作流统一入口——敲几个键直接跑 Python 脚本、开工作区、唤 OBS/本地模型，少切窗口。
- 偏差：社区开源项目，非单人，但完全本地、可自持。
- 来源：github.com/Flow-Launcher/Flow.Launcher

**备选 ｜ Cronhq**
- 是什么：托管式 cron 服务，「确实能跑」的定时任务（9/29–30 Product Hunt 新鲜上榜）。
- 具体用在哪：你已有日报/邮件自动化，用它补一层可靠性兜底（比裸 crontab 稳、有执行记录）。
- ⚠️ 偏差：是托管服务、数据在云端，非「数据可自持」；仅作自动化可靠性备选，关键链路仍走本地。
- 来源：producthunt.com（9/30 榜单）
