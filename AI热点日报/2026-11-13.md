## 三、潜在挣小钱的机会

**1. 钻进行业群「听人骂」，把重复劳动写成 AI 脚本：2000–8000 元/单**
新浪财经「副业观察」拆的真实案例：一位失业 90 后程序员不投一分钱，潜入代账公司、外贸公司的行业群潜水，专门看谁在抱怨「又加班做表」「数据手工核到什么时候」，私聊摸清对方每天重复的动作，用 AI 编程工具把流程写成脚本——原本几天的活几小时交付，报价 2000–8000 元看复杂度，月接 5–8 单、月入 5 万上下。卖的不是代码，是「每天早下班两小时」。关键能力只有一个：知道去哪听人骂。你有数据+SQL 背景，代账/电商/投放公司的报表自动化就是现成靶子。
⚠️ 单案例口径（新浪财经 11/9），停手即停收，现金流生意无存量。
源：新浪财经《副业观察》，11/9

**2. 海外 Chrome 插件窄需求订阅：成本一顿饭钱，月入 $500–5000 起步**
同篇报道的两个已验证案例：① 一人做跨境卖家竞品数据抓取插件，350 个付费客户、月费 $49–199 分档，月入 3.5 万美元；② 23 岁美国小伙不会写代码，14 天用 AI 做出「查集体诉讼索赔资格」的 App，上线 4 个月月入 5 万美元。启动成本：Chrome 开发者账号 $5 一次性 + AI 工具订阅 $20/月，首月投入不到 200 元人民币。两人共同点不是技术，是「窄」——一个只服务跨境卖家看竞品，一个只回答「我能不能拿这笔钱」。按月付费的订阅生意，估值比项目制高得多。
⚠️ 头部与均值差距大：普通水平月 $500–5000，月入 $1 万属前一成。
源：新浪财经《副业观察》，11/9

有人把 AI 提示词整理成合集，19.9 元一份在小红书一个月卖 3000 多份；另有大学生整理垂直领域模板包，单月两万多份。买的人买的不是提示词本身，是不想自己花时间试错。做法：选一个小领域（如「小红书爆款文案提示词 100 条」）、定价 9.9–29.9 低价走量、免费试读引流到店铺，边际成本为零做一次卖多次。

源：新浪财经《副业观察》，11/9

## 四、小而美产品

**Lee-xeo/Claude-Cage（主推·给 Claude Code 套隔离笼子）**
- 是什么：桌面工作台，把 Claude Code 和 Claude Desktop 关进隔离虚拟机里跑——独立代理网络出口、按出口节点自动配时区语言、只共享你指定的项目文件夹。支持管多个 Claude Code 订阅、按账号看配额余量，出门用手机继续会话或批批准。GitHub 11/11 日增 +1,413
- 差异化：别的工具管 agent 的「干活效率」，它管 agent 的「越界风险」——网络出口隔离+文件夹白名单，正好接住上期 UpGuard 泄露、密钥外泄这类安全主线的解法
- 用在哪：让 agent 批量跑抓取/改脚本这类有外发动作的任务时，关笼子里跑；多订阅配额面板顺便治「额度烧在哪了看不清」
- ⚠️ Windows 原生支持装前看 Release；开源许可未核实
- 源：ghtrends.dev 11/12 日榜

**Downvid/downvid（主推·开源跨平台视频下载器）**
- 是什么：基于 yt-dlp + FFmpeg 的现代化开源视频下载 GUI，一键保存全网高清视频、支持无水印，跨平台含 Windows，15.9k stars、11/12 在榜
- 差异化：给 yt-dlp 这把命令行瑞士军刀套了个正经 GUI，不用记参数；数据全走本机，无账号无订阅
- 用在哪：下载投放素材参考、竞品短剧样片、行业案例视频到本地做拆解归档；配合 HandBrake 转码、LosslessCut 切片正好一条流水线
- ⚠️ 下载版权内容自用可以，二次分发注意边界
